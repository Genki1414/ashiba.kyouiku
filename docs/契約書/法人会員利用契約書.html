法人会員利用契約書

東北三上機材株式会社（以下「当社」）と、末尾に記名した事業者（以下「会員」）は、当社が運営する教育サービス（足場屋革命ー教育／特別教育ドットコム。以下「本サービス」）の法人会員制度について、次のとおり契約します。本契約に定めのない事項は、本サービスの利用規約によります。

第1条（目的）

会員は、月額の会費を支払うことにより、本サービスの受講コードの申込みに用いることができるチケットを毎月受け取ります。会員の社員等の受講、名簿、受講の記録、修了証の発行は、利用規約に定める事業者としての取扱いと同じです。

第2条（プランと会費）

  1. 会員は、申込み時に当社が示すプランのうち一つを選びます。プランごとの月額会費（税抜）と毎月付与するチケットの額は、申込みの画面および特定商取引法に基づく表記に掲示します。
  2. 会費には別途消費税がかかります。
  3. 当社がプランの内容を変える場合、既に契約しているプランの会費およびチケットの額は、次に起こす請求から変わります。会員に不利な変更は、1か月前までに通知します。

第3条（契約期間と更新）

  1. 契約期間は、初月の会費の入金を当社が確認した月の1日から12か月とします。
  2. 満了日の1か月前までに、会員から解約の申し出がない場合、本契約は同じ条件で12か月更新され、以後も同様とします。

第4条（会費の支払い）

  1. 会費は前払いとし、当社が毎月発行する請求書に記載した振込先へ、請求書の発行から7日以内に銀行振込で支払います。振込手数料は会員の負担とします。
  2. 当社は、翌月分の請求書を当該月の前に発行します。
  3. 支払期限を14日過ぎても入金が確認できない場合、当社は入金が確認できるまで、会員のチケットの利用を停止します。入金の確認により停止は解除されます。
  4. 支払期限を過ぎて2か月分以上の未払いがある場合、当社は本契約を解除することができます。

第5条（チケット）

  1. 当社は、各月の会費の入金を確認したとき、プランに定める額のチケットを会員に付与します。
  2. チケットは、本サービスの受講コードの申込みにおいて、受講コードの通常価格（税抜）相当額を差し引くために用いるものです。消費税相当額は、チケットで支払う申込みには発生しません。
  3. チケットは、付与の日から6か月を経過したときに失効します。失効したチケットは復活しません。
  4. チケットは、現金への払戻し、他の事業者への譲渡、第三者への販売はできません。
  5. チケットの残額が申込みの額に足りないときは、足りない分を請求書払いまたは当社が認めるその他の方法で支払うことができます。
  6. 当社は、チケットの付与・消費・失効の履歴を会員の画面に表示します。会員はこれにより残額を確認します。

第6条（途中解約）

  1. 会員は、いつでも本サービスの画面または当社への連絡により、解約を申し出ることができます。
  2. 解約の申し出があった場合、本契約は、申し出のあった月の翌月末日に終了します。申し出の翌月以降の会費は請求しません。申し出の時点で未払いの請求は取り消します。
  3. 解約の申し出の後も、終了日までは、既に付与されたチケットをその失効日まで使うことができます。

第7条（契約の終了と残ったチケット）

  1. 本契約が終了したとき（期間満了・解約・解除を問いません）、終了の時点で残っているチケットは失効します。
  2. 既に支払われた会費は、理由を問わず返金しません。ただし、当社の責めに帰すべき事由により本サービスを提供できなかった月については、当社は当該月の会費を返金し、またはチケットの有効期間を延ばす等の措置をとります。

第8条（受講コードと受講）

チケットで申し込んだ受講コードの取扱い（1名につき1枚、譲渡の禁止、発行から1年の有効期限、修了証の発行の要件、受講中の本人確認、記録の保存）は、利用規約の定めによります。

第9条（紹介）

会員が当社の営業パートナーの紹介により申し込んだ場合、当社は当該営業パートナーに対し、会員の会費に応じた報酬を支払います。これにより会員の会費が変わることはありません。紹介元は契約成立の時点で固定され、会員がこれを変えることはできません。

第10条（当社による解除）

会員が、利用規約の禁止事項に反したとき、第4条第4項に該当したとき、または支払いの停止もしくは破産等の手続の開始があったときは、当社は、通知により本契約を解除することができます。この場合も第7条を適用します。

第11条（通知）

当社から会員への通知は、本サービスの画面への表示、会員の教育担当者が登録したメールアドレスまたは LINE への送信により行います。

第12条（規約の適用と変更）

本契約と利用規約の内容が異なるときは、本契約が優先します。当社は、利用規約の定めに従い本契約の内容を変更することがあります。変更後の内容は、本サービスの画面に掲示した日から効力を生じます。

第13条（準拠法と管轄）

本契約は日本法に準拠します。本契約に関して争いが生じた場合は、当社の本店所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。

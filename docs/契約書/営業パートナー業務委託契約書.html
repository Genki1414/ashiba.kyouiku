営業パートナー業務委託契約書

東北三上機材株式会社（以下「甲」）と、末尾に記名した者（以下「乙」）は、甲が運営する教育サービス（足場屋革命ー教育／特別教育ドットコム。以下「本サービス」）の法人会員制度に関する紹介業務について、次のとおり契約します。

第1条（委託する業務）

  1. 甲は乙に対し、本サービスの法人会員制度を事業者に案内し、申込みを紹介する業務（以下「本業務」）を委託し、乙はこれを受託します。
  2. 乙は、甲が発行する紹介コードおよび紹介 URL を用いて紹介します。事業者が紹介 URL を経由して、または申込み画面で紹介コードを入力して申し込んだとき、その事業者を乙の紹介によるもの（以下「紹介先」）とします。
  3. 乙は、甲に代わって契約を締結する権限、代金を受け取る権限、本サービスの内容や条件を変える権限を持ちません。

第2条（登録と承認）

  1. 乙は、本サービスの画面から営業パートナーの登録を行い、甲の承認を受けたときから紹介を始めることができます。
  2. 甲は、承認の可否を自らの判断で決めることができ、理由を示す義務を負いません。
  3. 乙は、乙自身または乙が所属する事業者を紹介先とすることはできません。これに反する申込みに対して報酬は発生しません。

第3条（報酬）

  1. 甲は乙に対し、紹介先が法人会員として甲に支払った月額会費（税抜）の 30% を報酬として支払います。報酬の率は、甲が乙ごとに別に定めることがあり、その場合は本サービスの画面に表示する率によります。
  2. 報酬は、紹介先の各月の会費の入金を甲が確認した時点で、当該月の分として確定します。入金のない月の報酬は発生しません。
  3. 報酬は、紹介先が法人会員であり会費を支払い続ける限り、毎月発生します。
  4. 紹介先の紹介による他の事業者の申込み（多段の紹介）に対して報酬は発生しません。
  5. 報酬の額は、消費税を含む額とします。
  6. 紹介先の会費が返金されたときは、対応する報酬は取り消され、既に支払済みの場合は次回以降の報酬から差し引きます。

第4条（報酬の支払い）

  1. 報酬は、月末締め・翌月末払いとし、乙が本サービスの画面に登録した銀行口座へ振り込みます。振込手数料は甲の負担とします。
  2. 当月に確定した報酬の合計が 5,000円 に満たないときは、支払いを翌月に繰り越し、合計が5,000円以上になった月の翌月末に支払います。
  3. 甲は、乙への報酬について源泉徴収を行いません。乙は、報酬に係る税務申告を自ら行います。甲は、法令により必要な場合、支払調書を作成し提出します。
  4. 乙が適格請求書発行事業者であるときは、その登録番号を本サービスの画面に登録します。

第5条（紹介元の固定）

紹介先の紹介元は、紹介先の契約が成立した時点で固定され、以後変わりません。ただし、紹介に不正があったとき、または紹介先から申し出があり甲が相当と認めたときは、甲は理由を記録のうえ紹介元を変えることができます。

第6条（禁止事項）

乙は、次の行為をしてはなりません。

  1. 本サービスの内容・料金・条件について、甲が示す案内と異なる説明をすること
  2. 甲の承諾なく甲の名称・ロゴを用いて広告・勧誘を行うこと
  3. 紹介先に対し、報酬の分配や金品の提供を約束して申込みを促すこと
  4. 紹介先の情報を本業務以外の目的に用い、または第三者に提供すること
  5. 法令または公序良俗に反する方法で勧誘すること

第7条（情報の取扱い）

乙は、本業務により知った甲および紹介先の情報を秘密として扱い、本契約の終了後も第三者に漏らしません。甲が乙の画面に表示するのは、紹介先の事業者名・契約の状態・報酬の計算に要する会費の額に限り、紹介先の社員の氏名や受講の記録は表示しません。

第8条（契約期間）

本契約は、甲が乙の登録を承認した日から1年間とし、期間満了の1か月前までにいずれからも申し出がないときは、同じ条件で1年間更新され、以後も同様とします。

第9条（解約・解除）

  1. 甲および乙は、1か月前までに相手方に通知して、本契約を解約することができます。
  2. 乙が第6条に反したとき、または乙に支払いの停止・破産等の事由があったときは、甲は通知により直ちに本契約を解除し、乙の登録を停止することができます。この場合、不正に係る報酬は発生せず、支払済みのものは返還を求めることがあります。

第10条（終了後の報酬）

  1. 本契約が終了したとき、甲は、終了の月までに確定した報酬を第4条に従って支払います。
  2. 終了の翌月以降、紹介先が会費を支払い続けても、新たな報酬は発生しません。

第11条（独立の事業者）

乙は、自らの判断と費用で本業務を行う独立の事業者であり、甲との間に雇用関係はありません。本業務に要する費用は乙の負担とします。

第12条（権利義務の譲渡の禁止）

乙は、甲の書面による承諾なく、本契約上の地位、権利または義務を第三者に譲渡し、または担保に供することはできません。

第13条（条件の変更）

甲は、報酬の率、締め日、支払日、最低支払額その他の条件を、1か月前までに乙に通知して変えることができます。変更は、通知した日の翌月以降に確定する報酬から適用し、既に確定した報酬には適用しません。

第14条（準拠法と管轄）

本契約は日本法に準拠します。本契約に関して争いが生じた場合は、甲の本店所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。

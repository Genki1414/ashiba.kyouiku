# 第2章「高所作業」の判定仕様

`HANDOFF.md` 3章の「現場のルール　第2章 高所作業」を、そのままコードにしたものの対応表です。
第1章と同じ作りにしてあります（工程キュー → 判定 → 描画）。

| ファイル | 役割 |
|---|---|
| `src/training/ch2/layout.ts` | 割り付け（柱4本・スパン3本・内柱・筋交の位置・転落防止手摺の高さ） |
| `src/training/ch2/queue.ts` | 工程キュー。全33手 |
| `src/training/ch2/rules.ts` | 判定 |
| `src/training/ch2/state.ts` | 状態と進行 |

検査は `npm run test:ch2`（56件）。

## 現場

戸建の一側足場、南面だけ。柱4本（出隅・南①・南②・南端）、3スパン。
**内柱は南②と南端**。昇降階段は出隅〜南①。**荷揚げは出隅側**。

## 作業の順序

`HANDOFF.md` の並びをそのままキューにしています。

```
地上から筋交 → 昇降階段で1段目 → 安全帯を支柱に
→ 1段目の手摺（荷揚げ側から）→ 安全帯を手摺へ
→ 支柱・内柱を継ぐ（奥から）→ ブラケット／踏板手摺
→ 壁当てジャッキ → 踏板 → 1段目から筋交
→ 2段目へ → 2段目の手摺 → 2段目から筋交
→ 屋根 → 転落防止手摺（中さん2,250 → 上さん2,700）
```

**向きが2種類ある**のがこの章の要点です。

| 何を | どちら向きに |
|---|---|
| 手摺 | 荷揚げ側（出隅）から |
| 支柱・受け材・踏板 | 奥（南端）から |

## ルールと実装の対応

| HANDOFF 3章 | 判定 | 分類（tag） |
|---|---|---|
| 安全帯は支柱に取る（コマは駄目） | 1段目に上がった直後に選ばせる。コマ・踏板の枠はファール（−10） | 安全帯の取り付け位置の誤り |
| 1本目の手摺が入ったら手摺へ掛け替え | 1段目の1本目を入れた直後に選ばせる | 同上 |
| 手摺は荷揚げ側から | 順が違うとファール | 取付順序 |
| 支柱は奥から手前へ | 手前から継ぐとファール | 建てる順序 |
| 内柱の箇所は踏板手摺、それ以外はブラケット | 逆にするとファール | 取付位置の誤り |
| **壁当てジャッキは踏板ではなく踏板手摺に付く** | 踏板手摺が入る前だとファール。内柱の箇所以外もファール | 手順の飛ばし／取付位置の誤り |
| 筋交は下端＝南端側、上端＝出隅側の一方向のみ | スパンが違うとファール | 取付位置の誤り |
| 筋交は1段につき1本（地上・1段目・2段目から1本ずつ） | 入れる段が違うとファール | 作業位置の誤り |
| 転落防止手摺は中さん2,250 → 上さん2,700 | 上さんが先だとファール | 取付順序 |
| 囲いの無い床には上がらない | 2段目の手摺が揃う前に屋根へ上がるとファール（−10） | 手摺の無い床に上がる |

## 筋交が一直線に揃うこと

1段につき1本、段を上がるごとに1スパン寄せます。

| 本目 | どこから入れる | スパン |
|---|---|---|
| 1本目 | 地上 | 南②〜南端 |
| 2本目 | 1段目 | 南①〜南② |
| 3本目 | 2段目 | 出隅〜南① |

3本が斜めに繋がって一直線になります。

## 守りとして置いてあるだけの判定

次の2つは、工程キューが先に止めるため通常は起きません。念のための守りです。

- 2段目の踏板が揃う前に2段目へ上がる
- 2段目の手摺が揃う前に屋根へ上がる

検査では、キューをその場面まで進めた状態を作って直接確かめています。

## まだやっていないこと

- **描画**。盤面（立面）・親方・場面（安全帯／筋交／壁当てジャッキ）は次の作業です
- 壁当てジャッキを**斜め（奥行き方向）に描く**こと（`HANDOFF.md` 4章）。判定には影響しません

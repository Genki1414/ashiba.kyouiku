# ずい道等の掘削等の作業に係る業務に係る特別教育 — 根拠と裏取り

作った日：2026年9月3日
講座の目印：`zuidou`
仕様の正本：`src/content/zuidou.ts`

---

## 1. 何という教育か

**ずい道等の掘削等の作業に係る業務に係る特別教育**

対象は、安衛則第36条第30号に掲げる業務
（ずい道等の掘削の作業、**これに伴うずり・資材等の運搬**、**覆工のコンクリートの打設等**の作業）。

**掘る人だけではない。** ずりをダンプで運ぶ人も、覆工のコンクリートを打つ人も対象。
坑内に入って働く人は、ほとんど全員が受ける。

**学科7時間のみ。実技はない。**

---

## 2. 根拠

| 何 | 条 | 確かめたか |
|---|---|---|
| 特別教育を行う義務 | 労働安全衛生法 **第59条第3項** | ○ |
| この業務が対象だと決めている所 | 労働安全衛生規則 **第36条第30号** | ○（告示第17条の本文が引用している） |
| 科目・範囲・時間 | 安全衛生特別教育規程（昭和47年労働省告示第92号） **第17条** | ○（全文で確認） |

条文の全文は、げんきさんが送ってくれたものを 2026年9月3日に確認した。
条文の末尾に **「(昭五六労告三六・追加)」** とある。昭和56年労働省告示第36号で追加。

**第17条第1項は「学科教育により行うものとする」**で、第3項（実技）が無い。
だから `gate` を付けていない。粉じん（`funjin`）・酸欠（`sanketsu`）と同じ作り。

---

## 3. 科目と時間（告示第17条第2項・学科）

告示の表そのまま。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| 掘削、覆工等に関する知識 | 掘削工法の概要　坑内における作業の種類　地質の種類及び性質 | 一・五時間 |
| 工事用設備に関する知識 | 掘削設備　ずり積み設備　運搬設備　覆工設備 | 一・五時間 |
| 労働災害の防止に関する知識 | 落盤又は肌落ちの防止のための措置　爆発又は火災の防止のための措置　工事用設備による労働災害の防止のための措置　作業環境改善の方法　事故発生時の措置　保護具の使用方法 | 三時間 |
| 関係法令 | 法、令及び安衛則中の関係条項 | 一時間 |

**合計 7時間（420分）。**

条文では「肌落ち」の「肌」にルビ（はだ）が振ってある。中欄の字はそのまま写した。

---

## 4. 実技

**無い。** 第17条に実技の項が無い。
学科を通して修了試験に受かれば、修了証が出る。それがそのまま教育の記録になる。

---

## 5. 単元の割り付け

**中欄の項目の数だけ単元を作った。**

- 科目1（90分・**3単元**）… 掘削工法の概要40／坑内における作業の種類25／地質の種類及び性質25
- 科目2（90分・**4単元**）… 掘削設備30／ずり積み設備20／運搬設備20／覆工設備20
- 科目3（180分・**6単元**）… 落盤又は肌落ち45／爆発又は火災35／工事用設備による災害30／作業環境改善30／事故発生時25／保護具15
- 科目4（60分・**1単元**）

合計 **14単元・420分**。

---

## 6. 講座の軸にした四つ

1. **落盤と肌落ちは別。事故の数は肌落ちが多い。** 当たり（浮石落とし）が終わるまで切羽に近づかない。掘ってから支えるまでが、いちばん危ない時間
2. **地質が変わるところで事故は起きる。** 色・水・落ちてくる物・割れ目・音・支保工の変形。気付いたら退避する（科目1と科目3で二度）
3. **坑内は狭い・暗い・うるさい・逃げ場がない。** 待避所の位置を全員が知る。後進警報を切らない。煙と同じ方向に逃げることになる
4. **二人目を出さない。** 倒れた人を助けに入る前に、測って、保護具を着ける

---

## 7. 条番号を書いていないところ

docs/19 の決めごとどおり、**条文で確かめた番号だけ書く。**
書いたのは **法第59条第3項／安衛則第36条第30号／規程第17条** の三つだけ。

**番号を書かずに中身だけ教えているもの**（主に科目4）：

- 安衛則のずい道等の建設の作業の各条
  - **調査及び記録**（地質・地層・湧水・可燃性ガス）
  - **施工計画**（掘削の方法、支保工、換気、避難の設備）
  - **観察及び記録**（毎日の地山の観察）
  - **ずい道支保工**（設置、点検、補強・補修）
  - **可燃性ガスの濃度の測定**（毎日、作業の前と定期的に）
  - **自動警報装置**
  - **火気等の使用禁止**
  - **換気**
  - **避難用器具**（自己救命器を人数分）
  - **警報設備・通話設備**
  - **照明**
  - **退避**（落盤・出水・ガスの危険があるとき）
- **特別教育の記録の3年保存**
- **ずい道等の掘削等作業主任者・ずい道等の覆工作業主任者**（技能講習）の条
- **粉じん障害防止規則**（ずい道の粉じんの測定、呼吸用保護具、換気）
- **酸素欠乏症等防止規則**
- **火薬類取締法**（取扱保安責任者、発破技士）
- **じん肺法**
- **軌道装置の動力車の運転の特別教育**（規程の別の条）

いずれも、労働局・中災防・建設業労働災害防止協会の資料と実務で通っている中身に合わせて書いた。
**条番号が確かめられたら、ここに足して、単元の中でも番号を出す。**

## 8. 値段

**7,000円（税抜）＝ 7,700円（税込）。**
コードの既定値（`src/lib/pricing.ts`）に置いただけで、Vercel の環境変数は触っていない。

- **よその値段はまだ調べていない。**
- 学科7時間は低圧電気・小型車両系・機械研削と同じ長さ。**7時間の講座はみな 7,000円**にそろえた。
- 実技が無いので、この学科の修了証がそのまま教育の記録になる。
- よその相場が分かったら、ここを見直す。

## 9. 例の書き方（docs/19 ⑤）

**足場屋の例は1つも入れていない。**
土木の中でも専門の工種で、全部トンネル工事の中の話になる。業種の幅より、**作業の幅**で散らした。

- 掘削（発破、機械掘削）
- ずりの運搬（ダンプ、軌道装置）
- 覆工（セントル、セグメント）
- 測量（横坑）
- 換気・ガスの測定
- 教育・選任・備えの管理

### 入れた事例（10件）

| 単元 | 事例 | 作業 |
|---|---|---|
| 1-1 | 運搬だけだから教育は要らないと思っていた | ずりの搬出 |
| 1-3 | 「昨日まで硬かった」で掘り進めた | 掘削 |
| 2-3 | 待避所に入らず、車両と壁に挟まれた | 坑内の運搬 |
| 3-1 | 当たりの前に切羽へ入り、肌落ちに当たった | 発破後の確認 |
| 3-1 | 支保工の変形に気付きながら掘り続けた | 掘削 |
| 3-2 | ガスの濃度が上がっていたのに続けた | 掘削 |
| 3-5 | 倒れた同僚を助けに入り、自分も倒れた | 横坑の測量 |
| 4-1 | 作業主任者を選任せずに掘削していた | 掘削 |
| 4-1 | 地山の観察を記録せず、変化を見逃した | 掘削 |
| 4-1 | 自己救命器が人数分なかった | 長いトンネル |

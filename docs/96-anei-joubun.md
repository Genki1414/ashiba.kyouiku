## 2　安衛則に無いと分かったもの

**チェーンソーの規格**は安衛則に無い。全文を引いて、チェーンソーが出てくるのは
**第36条（特別教育を必要とする業務）と第485条（下肢の切創防止用保護衣の着用）の
2か所だけ**だった。規格は別の告示。
docs/38 に「条番号を確かめていないので書いていない」と書いてあったが、
**そもそも安衛則には無かった。**書けなかったのは正しい判断だった。

## 3　講座の中身は変えていない

確かめた条番号を、講座の台本に入れる作業はしていない。
いまも**中身だけ**教えている（docs/19 の決めごと。番号を覚えても現場では使わない）。

**番号を書いていないことは、間違いではない。**
ここに記録したのは「確かめたかどうか」であって、「書くかどうか」は別の話。
入れるなら、げんきさんが決めてから。

## 4　まだ引いていないもの

**ローラー・フォークリフト・小型車両系建設機械は §1-2 で引き終えた。**

安衛則では引けないもの。それぞれの省令が要る。

- 酸欠 … 酸素欠乏症等防止規則
- クレーン・移動式クレーン・デリック・建設用リフト・玉掛け … クレーン等安全規則
- ゴンドラ … ゴンドラ安全規則（告示は確かめ済み）
- 高気圧の6本 … 高気圧作業安全衛生規則
- 電離・核燃料・除染 … 電離放射線障害防止規則、除染電離則
- 小型ボイラー … ボイラー及び圧力容器安全規則
- 石綿 … 石綿障害予防規則
- 粉じん … 粉じん障害防止規則
- 四アルキル鉛 … 四アルキル鉛中毒予防規則

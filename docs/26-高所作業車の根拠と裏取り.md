# 高所作業車の特別教育：根拠と裏取り

docs/19 の手順①の記録。**確かめたことと、まだ確かめていないことを分けて書く。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | **高所作業車の運転の業務に係る特別教育** |
| 対象 | **作業床の高さが10メートル未満**の高所作業車 |
| 学科 | **6時間** |
| 実技 | **3時間** |
| 合計 | 9時間 |

10メートル以上は技能講習（別の制度）。ここは10メートル未満だけ。

## 根拠

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 **第36条第10号の5** |
| 科目と時間 | 安全衛生特別教育規程 **第13条** |

渡された一覧（`special_education_course_master_20260901.csv`）は
「安全衛生特別教育規程」までで、**どの条かが入っていなかった。**
石綿と同じで、条番号まで無いと突き合わせられない。

## 石綿と決定的に違うところ

> ### 実技が3時間ある。**この仕組みだけでは修了しない。**
>
> 石綿は学科だけだったので、見終わって試験に受かれば修了証が出せた。
> 高所作業車は違う。学科6時間のあとに、実技3時間が残る。
>
> 実技は**事業者が自社で行う**。実機が要るので、こちらではできない。
>
> だから講座の作りは `gate: "drill"`（`src/content/courses.ts`）。
>
> - 学科が終わっても、その場では修了証を出さない
> - 本人が**発行申請**を出す。そのとき**実技の実施日と実施者**を書く
> - 本部がそれを見て通す。そこではじめて修了
>
> **ここを間違えると、実技を受けていない人に修了証が出る。**
> 学科だけで修了証を出せば、その紙は無効なうえ、
> 持っている本人は「資格がある」と思って高所作業車に乗る。

`gate: "drill"` の仕組みは 0023 で作ってあり、
`src/lib/issue.ts` と `/api/issue`、`/api/owner/issue` に入っている。
**ただし、この仕組みを実際に使う講座はこれが初めて。**
通しで確かめてから公開すること。

## まだ確かめていないこと

> ### 科目ごとの時間の割り振り
>
> **ここが決まらないと、単元を割れない。**
>
> よく見る形は 学科が
> 「作業に関する装置の構造及び取扱いの方法に関する知識」
> 「原動機に関する知識」
> 「運転に必要な一般的事項に関する知識」
> 「関係法令」
> の4科目だが、**それぞれ何時間かは web から取れなかった。**
>
> 石綿のとき、合計は合っているのに内訳が違っていた
> （保護具が0.5時間と1時間で食い違い、正しくは1時間）。
> **「合計が合っているから大丈夫」は通らない。関門は科目ごとに掛かる。**
>
> 規程 第13条 の表を見て、手で入れること。
> https://www.mhlw.go.jp/web/t_doc?dataId=74085000&dataType=0

実技の科目と時間も同じ。表に載っている。

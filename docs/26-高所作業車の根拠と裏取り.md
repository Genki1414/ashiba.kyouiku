# 高所作業車の特別教育：根拠と裏取り

docs/19 の手順①の記録。**確かめたことと、まだ確かめていないことを分けて書く。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | **高所作業車の運転の業務に係る特別教育** |
| 対象 | **作業床の高さが10メートル未満**の高所作業車 |
| 学科 | **6時間** |
| 実技 | **3時間** |
| 合計 | 9時間 |

10メートル以上は技能講習（別の制度）。ここは10メートル未満だけ。

## 根拠

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 **第36条第10号の5** |
| 科目と時間 | 安全衛生特別教育規程 **第13条** |

渡された一覧（`special_education_course_master_20260901.csv`）は
「安全衛生特別教育規程」までで、**どの条かが入っていなかった。**
石綿と同じで、条番号まで無いと突き合わせられない。

安衛則第36条第10号の5にも、施行令第20条第15号にも
**「道路上を走行させる運転を除く」**と入っている。
公道を走るのは道路交通法の運転免許の話で、この教育の対象ではない。
教材でもそこを分けて書いた（1-1／4-1）。

## 石綿と決定的に違うところ

> ### 実技が3時間ある。**この仕組みだけでは修了しない。**
>
> 石綿は学科だけだったので、見終わって試験に受かれば修了証が出せた。
> 高所作業車は違う。学科6時間のあとに、実技3時間が残る。
>
> 実技は**事業者が自社で行う**。実機が要るので、こちらではできない。
>
> だから講座の作りは `gate: "drill"`（`src/content/courses.ts`）。
>
> - 学科が終わっても、その場では修了証を出さない
> - 本人が**発行申請**を出す。そのとき**実技の実施日と実施者**を書く
> - 本部がそれを見て通す。そこではじめて修了
>
> **ここを間違えると、実技を受けていない人に修了証が出る。**
> 学科だけで修了証を出せば、その紙は無効なうえ、
> 持っている本人は「資格がある」と思って高所作業車に乗る。

`gate: "drill"` の仕組みは 0023 で作ってあり、
`src/lib/issue.ts` と `/api/issue`、`/api/owner/issue` に入っている。
**この仕組みを実際に使う講座は、これが初めて。**
`COURSE=kousho node tests/e2e-prep-exam.mjs` で通しを見ている。

そのまま `src/content/kousho.ts` に入れた。

### 学科（6時間）

| # | 科目 | 範囲 | 時間 |
| --- | --- | --- | --- |
| 1 | 高所作業車の作業に関する装置の構造及び取扱いの方法に関する知識 | 高所作業車の種類及び用途／作業装置及び作業に関する附属装置の構造及び取扱いの方法 | **3時間** |

| 科目 | 範囲 | 時間 |
| --- | --- | --- |
| 高所作業車の作業のための装置の操作 | 基本操作／定められた方法による作業床の昇降等 | **3時間** |

> ### 送ってもらう前に、こちらは逆に想像していた
>
> 「装置1時間・原動機3時間」だと思っていた。実際は逆で、
> **装置が3時間、原動機が1時間**。
> 当てずっぽうで書いていたら、いちばん大きい科目を
> 法定の3分の1の中身で作っていた。
>
> docs/19 のとおり、**表を見てから割る。**

## 単元の割り付け

範囲（告示の中欄）に1つずつ当てる。`scripts/build-course.ts` が突き合わせるので、
当たっていない範囲があれば組み立てが止まる。

| 単元 | 範囲 | 分 |
| --- | --- | --- |
| 1-1 高所作業車の種類及び用途 | 高所作業車の種類及び用途 | 60 |
| 1-2 作業装置の構造及び取扱いの方法 | 作業装置及び作業に関する附属装置の構造及び取扱いの方法 | 60 |
| 1-3 附属装置の構造及び取扱いの方法 | 同上 | 60 |
| 2-1 内燃機関の構造及び取扱いの方法 | 内燃機関の構造及び取扱いの方法 | 30 |
| 2-2 動力伝達装置及び走行装置の種類 | 動力伝達装置及び走行装置の種類 | 30 |
| 3-1 運転に必要な力学 | 高所作業車の運転に必要な力学 | 30 |
| 3-2 感電による危険性 | 感電による危険性 | 30 |
| 4-1 法、令及び安衛則中の関係条項 | 法、令及び安衛則中の関係条項 | 60 |

科目1だけ範囲が2つで時間が180分なので、
「種類及び用途」に60分、「装置及び附属装置」に120分（2単元）を割った。

## 条文（4-1 で番号まで出したもの）

**題名まで確かめたものだけ番号を出している。** 確かめていない条は、
中身は教えるが番号を出していない（誤った番号は、無いより悪い）。

| 条 | 何の定めか |
| --- | --- |
| 法 第26条 | 労働者の遵守義務 |
| 法 第59条第3項 | 特別教育 |
| 法 第61条 | 就業制限／資格を証する書面の携帯 |
| 施行令 第20条第15号 | 作業床の高さ10メートル以上は技能講習 |
| 安衛則 第36条第10号の5 | 特別教育の対象業務 |
| 安衛則 第38条 | 特別教育の記録の**3年保存** |
| 安衛則 第194条の9 | 作業計画 |
| 安衛則 第194条の10 | 作業指揮者 |
| 安衛則 第194条の15 | 搭乗の制限 |
| 安衛則 第194条の17 | 主たる用途以外の使用の制限 |
| 安衛則 第194条の22 | 墜落制止用器具等 |
| 安衛則 第194条の23 | 定期自主検査（1年以内ごとに1回） |
| 安衛則 第194条の27 | 作業開始前点検 |

> ### 194条の22 の括弧書きを落とさない
>
> 条文には
> **「（作業床が接地面に対し垂直にのみ上昇し、又は下降する構造のものを除く。）」**
> という括弧書きがある。シザースやマストのような**垂直昇降型は対象から外れる。**
>
> ここを落として「作業床では必ず器具」と教えると、条文と違うことを教えることになる。
> かといって「垂直昇降型なら要らない」と読ませてもいけない。
> **条文が求めていない、ということと、着けなくてよい、は別**だと書いた（4-1）。

番号を出していないもの：転落等の防止（誘導者・地盤・アウトリガー）、合図、
立入禁止、運転位置から離れる場合の措置、移送、修理等（安全支柱）。
中身は 4-1 の図解 K4-1-8 で扱っている。

**この環境からは mhlw.go.jp・e-Gov・rodo.co.jp のどれにも出られない**
（プロキシが CONNECT を拒む）。検索の要約だけで番号を書かない。
番号を足すなら、条文そのものを見てから。

## 値段（2026年9月2日に調べた。オンライン受講・税込）

| | |
| --- | --- |
| CIC日本建設情報センター Web講座 | **11,000円**（修了証付き 11,500円） |
| 別のオンライン講習 | **10,500円**（カード式修了証付き 11,550円） |
| 学科＋実技を通しでやる講習所 | **13,000円**ほど（学科だけ約10,000円／実技だけ約3,000円） |
| **ここ** | **7,000円（税抜）＝ 7,700円（税込）** |

**よそも、オンラインで売っているのは学科だけ。**
実技3時間は、どこも事業者が自社でやる。うちと同じ作り。
だから 11,000円は学科だけの値段で、比べる相手として正しい。

はじめ足場・石綿と同じ 4,500円に置いたが、げんきさんが「安すぎる」と
**7,000円**に決めた（2026年9月2日）。よそが学科の動画だけなのに対して、
こちらは**実技の手引きと実施記録の様式**が付く（`/edu/kousho/drill`）。
変えるときは環境変数
`SEAT_UNIT_PRICE_KOUSHO`（Vercel）で。`src/lib/pricing.ts` を
書き換えると、上げ直すまで直らない。

## 例の書き方

docs/19 ⑤。**どの職種が受けるかを先に数える。**

高所作業車に乗るのは、
電気、設備、空調、看板、外装、塗装、防水、内装、造園、
物流の倉庫、工場の保全、ビル管理、通信、道路の照明・標識。
**建設業だけでもない。**

石綿で足場屋に寄せて書き直した。同じことをしない。
例はこの範囲から散らして出す。

16件の事例の場面：
倉庫の照明交換／工場の天井クレーン点検／立体駐車場の照明／
街路樹の剪定／店舗の天井照明／倉庫の外壁点検／ビルの看板取付け／
工場の配管点検／工場の外壁パネル／道路沿いの看板照明／
ビル外壁の防水／ビル管理の共用部照明／倉庫の設備工事。

`content/courses/kousho.json` に「足場」は4か所しか出ない。
どれも「足場を組むほどではない」「隣に組んである足場」で、
**足場屋に向けた書き方ではない**（物としての足場）。

# 109　動線を整理した記録

2026-09-10。げんきさん「全部やろう」「UIも動線が分かりにくいから整理して欲しいな」。

4つまとめて直した記録。

## 1　押した札と、着いた先の名前が違った

ホームの札は4枚とも `/join` へ行く。

| 押した札 | 着いた先の見出し（前） |
| --- | --- |
| 会社とつなぐ | 会社とつなぐ |
| 承認待ち | 会社とつなぐ |
| 受講するには（受講コードを入れる） | 会社とつなぐ |
| 受けたい講座をリクエストする | 会社とつなぐ |

**押した札と違う名前が出る。**別の所へ来てしまったのかと思う。

番号も合っていなかった。「①会社を検索」「②会社を登録」は在籍している人には
出さないのに、その下は「③受講コードを入力する」「④受講コードをお持ちでない場合」
のまま。**在籍者には③から始まる画面**になっていた。

### 直したこと

`/join` を、**その人がどこに立っているかで組み替える**（`src/lib/nav.ts` と同じ考え。
決める所を1つにして、画面はそれに従う）。

| いる所 | 画面の名前 | 上から順に |
| --- | --- | --- |
| 在籍している | 受講をはじめる | 受講コードを入れる／受講リクエストを送る／いまの所属 |
| 承認待ち | 承認を待っています | 申し込んだ会社／受講コードを入れる／さがす・登録する |
| まだどこにも | 会社とつなぐ | さがす／登録する／受講コードを入れる |

- **番号はやめた。**出ない節があるので、必ず飛ぶ
- 在籍している人には、**受講コードをいちばん上**に置いた。
  その人の用はそれで、所属はもう済んでいる
- 分かる前に「会社とつなぐ」と決め打ちで出さない。
  あとから名前が変わるのが、いちばん紛らわしい。高さだけ取って、分かってから書く
- 押す釦も「この会社に登録する」から「この受講コードを使う」に。
  すでに入っている人に「登録する」は嘘になる

## 2　受講する人の画面に「席」と書いていた

「席」は帳簿の言葉。売り物の数を数えるときは要るが、**受講する人には
「受講コード」と言う**（前からの決まり）。2か所に残っていた。

- 「担当者が席（受講コード）を用意して渡してくれます」
- 講座の行の「席あり」

`tests/api-shape.mts` が、受講する人の画面（運営と受講管理を除く）を全部見て、
注釈の外に「席」があれば止める。「在席確認」は別の言葉なので通す。

## 3　「受講不要」が残っていた

げんきさん（2026-09-09）「受講不要がまだ表示されてる」。
マイページからは消したが、**講座を開いた所には残っていた。**

受けるか受けないかを決めるのは本人と会社であって、こちらが「要らない」と
言い切る筋合いではない。持っていることだけ伝える。

> この講座は取得済みです
> 取得済みとして登録されています。もう一度受けることもできます。

こちらも見張りを置いた（画面のどこにも「受講不要」と書かない）。

## 4　畳んだ見出しに、取得済みの件数を出す

特別教育ドットコムは73講座を畳んである。足場屋革命の「その他特別教育」も同じ。
**開かないと、自分がどれを持っているか分からない。**
畳んだままだと、何も取っていない人と20件取った人の画面が、そっくり同じに見える。

見出しに「◯件取得済み」を出す（`src/components/HeldCount.tsx`）。

- 一覧は作り置きなので、人の情報は後から `/api/me` に聞いて付ける（札の「取得済」と同じ作り）
- **0件のときは出さない。**まだ何もしていない人に「0」と言うだけになる
- 畳んだ見出しは3か所ある（ホームの2つと、講座の一覧の中の1つ）。
  1つ入れ忘れると、その画面だけ分からないままになるので、見張りで3つとも見る

## 5　お知らせの差出人を分けた

前は本人あてを全部「運営からのお知らせ」にしていた。
ところが**受講コードを配ったのも、修了証を出したのも、会社の教育担当者**であって、
運営ではない。

| 差出人 | 知らせ |
| --- | --- |
| 教育担当者 | 会社とつながりました／参加申込が断られました／修了証が出ました／受講コードが届きました |
| 運営 | 受講コードが出ました（入金の確認）／実務トレーニング／討議の候補日・入り口・確認／発行申請が断られました |

「断られました」が届いたときに、**会社に聞くのか運営に問い合わせるのか**で
動きが変わる。そこを取り違えさせない。

- 画面（ホームとマイページのお知らせ）には、見出しの横に差出人の札
- LINE は1行目が「【店名】教育担当者からのお知らせ」または「【店名】運営からのお知らせ」
- 決めるのは `src/lib/noticeText.ts` の1か所。画面と LINE で言い方が割れない
- 古い返事（差出人が入っていない行）でも落ちない。そのときは札を出さない

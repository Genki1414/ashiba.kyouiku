# 機械研削用といし：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 機械研削用といしの取替え又は取替え時の試運転の業務に係る特別教育 |
| 対象 | 平面研削盤、円筒研削盤、内面研削盤、心なし研削盤、工具研削盤など、**工作物を機械に固定して機械が送る**研削盤のといしを取り替える、取り替えたあと試運転をする業務 |
| 学科 | **7時間**（3科目12単元） |
| 実技 | **3時間**（事業者が自社で行う） |
| 合計 | 10時間 |

**自由研削（グラインダー・規程第2条・学科4時間＋実技2時間）とは別の教育。**
両方やるなら両方受ける。docs/34（自由研削）と対になる。

**削る作業そのものには、この教育は要らない**（取り替える人・試運転をする人に要る）。

| # | 科目（左欄） | 範囲（中欄） | 時間 |
| --- | --- | --- | --- |
| 1 | 機械研削用研削盤、機械研削用といし、取付け具等に関する知識 | 機械研削用研削盤の種類及び構造並びにその取扱い方法　機械研削用といしの種類、構成、表示及び安全度並びにその取扱い方法　取付け具　覆い　保護具　**研削液** | **4時間** |
| 2 | 機械研削用といしの取付け方法及び試運転の方法に関する知識 | 機械研削用研削盤と機械研削用といしとの適合確認　機械研削用といしの外観検査及び打音検査　取付け具の締付け方法及び締付け力　バランスの取り方　試運転の方法 | **2時間** |
| 3 | 関係法令 | 法、労働安全衛生法施行令（昭和四十七年政令第三百十八号。以下「令」という。）及び安衛則中の関係条項 | **1時間** |

> ### 自由研削（第2条）との違い
>
> - 科目1に**「研削液」**がある（自由研削には無い）
> - 科目1の時間が**4時間**（自由研削は2時間）
> - 科目2の時間が**2時間**（自由研削は1時間）
> - 中欄の項目は科目2は同じ5つ

> ### 告示の字
>
> 「覆い」には「おおい」の振り仮名が付いている。scope は「覆い」で持つ。
> 科目3の中欄は施行令の定義の括弧が入っているので、**定義の括弧を除いた
> 「法、労働安全衛生法施行令及び安衛則中の関係条項」**で scope を持つ（他の講座と同じ扱い）。
> 画面の単元名は「法、令及び安衛則中の関係条項」にしてある。

## 実技（告示第1条第3項）

「機械研削用といしの取付け方法及び試運転の方法について、**三時間以上**」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/kikaitoishi/drill`）。3つの段取り（50／70／60）は**うちの案であって告示ではない。**
手引きの最初を**「主電源に施錠して札を掛ける（ロックアウト・タグアウト）」**にした。
自動運転の機械で、取替え中に他の人が起動する事故があるため。

## 条番号を書いていないところ

安衛則の**研削といしの各条**（覆い、試運転＝取替え後3分以上・作業開始前1分以上、最高使用周速度、
側面使用の禁止）と、**機械の一般則**（危険な部分の覆い、掃除・給油・検査・修理時の停止、誤起動の防止）は、
**条番号を条文で確かめていないので書いていない。**科目3は中身で教えている。
**研削といしの構造規格**（告示）も名前だけ出し、条番号は書いていない。

教材の中の数字で、原文で確かめていないもの：
- 覆いの露出角度の上限が「研削盤の種類ごとに違う」こと、具体の角度（構造規格）
- フランジの径「といしの外径の1/3以上」（構造規格）
- 破壊回転試験「最高使用周速度の1.5倍」（構造規格）
- 試運転「取替え後3分以上・作業開始前1分以上」（安衛則。**自由研削と同じ**）
- 機械研削で使う周速度「30〜60 m/s あたり」（一般に使われる範囲）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。
docs/34（自由研削）に挙げた未確認事項と重なるので、**条文が手に入れば両方まとめて直す。**

## 例の書き方

docs/19 ⑤。機械研削用研削盤を使うのは、
機械加工、金型、工具の製造と再研磨、自動車部品、軸受、精密部品、鉄道の車輪、
製鉄・製鋼のロール、刃物、ガラス・セラミックス、学校の実習。
**工場の中の仕事。**建設現場のグラインダーは自由研削（規程第2条）で別。足場屋の例は入れていない。

事例14件：施錠せず他の人が起動（機械加工）／インターロックを無効化（自動車部品）／
外径違いで周速度超過（軸受）／液が下側にたまってアンバランス（金型）／
フランジの流用（精密部品）／覆いを外して大径といし（金型）／手袋のまま回転部へ（工具の再研磨）／
腐敗した研削液で皮膚炎（精密部品）／濡れたといしの打音（軸受）／運搬で縁を打ったといし（機械加工）／
バランス取りをせず主軸損傷（軸受）／試運転を30秒で切り上げ（金型）／
自由研削の教育だけで機械研削（機械加工）／覆いを外し続けて使用停止命令（金型）。

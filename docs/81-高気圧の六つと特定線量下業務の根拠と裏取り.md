# 高気圧の六つと特定線量下業務の根拠と裏取り

## 1. なぜ7本まとめてか

**六つは、同じ一つの条から出ている。**

高気圧作業安全衛生規則（昭和47年労働省令第40号）**第11条第1項**は、
特別教育の要る業務を**六つ**並べている。

| 号 | 業務 | 講座ID | 目録 |
|---|---|---|---|
| 第1号 | 作業室及び気こう室へ送気するための空気圧縮機を運転する業務 | `compressor` | 38 |
| 第2号 | 作業室への送気の調節を行うためのバルブ又はコツクを操作する業務 | `soukiroom` | 39 |
| 第3号 | 気こう室への送気又は気こう室からの排気の調節を行うためのバルブ又はコツクを操作する業務 | `kikoushitsu` | 40 |
| 第4号 | 潜水作業者への送気の調節を行うためのバルブ又はコツクを操作する業務 | `soukisensui` | 41 |
| 第5号 | 再圧室を操作する業務 | `saiatsushitsu` | 66 |
| 第6号 | 高圧室内業務 | `kouatsushitsu` | 42 |

そして**高気圧業務特別教育規程（昭和47年労働省告示第129号）**が、
**第1条から第6条まで**、この六つに一つずつ科目と時間を割り当てている。
**条の番号と、号の番号が、そのまま対応している。**

**七本目の `senryouka`（特定線量下業務）は別系統。**
除染則から出ている。ただ、四アルキル鉛（docs/80）と同じ日に告示を読んでいるので、
裏取りの記録としてここに一緒に置いた。

## 4. 告示が教えてくれたこと

### 関係法令の中欄が「労働基準法」から始まる

高気圧の六つは、**全部**そうなっている。

クレーン・玉掛け・ゴンドラ・ボイラーの規程には、労働基準法は入っていない。
**高気圧業務だけ入っている。**

理由は、**この仕事が労働時間そのものを法で縛られているから。**
「何時間働いてよいか」が、ふつうの仕事とは別に決まっている。
**体が圧に耐えられる時間には、限りがある。**

だから六本とも、関係法令の単元をそこから始めた。

### 持ち場が違えば、条も科目も時間も違う

六つのうち一つを受けても、**ほかの持ち場には就けない。**
「同じ現場だから」で持ち場を替えることが、いちばん危ない。

これを六本とも、関係法令の単元で**同じ言い方で**言っている。
（`$SP/kagen/parts.py` の `houki1` で、六本が同じ文を持つようにしてある。）

### 「緊急時の減圧法」が中欄に名指しである

第2号・第3号・第4号の科目2に入っている。
**その場で決めるものではなく、決めてある表のとおりにやるもの**だと教えた。

### 特定線量下業務は、除染をしない

除染等業務（目録61）は「汚れた土などを、除染する・集める・運ぶ」仕事。
**特定線量下業務は、除染をしない。**
**決められた線量より高い場所で、ふつうの仕事をする**業務。
建物を建てる、道を直す、店を開ける、電気やガスを引く——
**仕事の中身は変わらない。場所の線量が高いだけ。**

だから、この講座は「その場所で働くこと」を教えた。
**除染の機械の話も、汚染を落とす話も、告示の中欄に入っていない。**

**そして61と違って、業務区分が無い。**61 は五つの区分で時間が変わるが、62 は一本。
そのままひとつの講座にできた。

## 5. うちが決めたこと（告示に無いところ）

### 単元の割り方

告示は科目と時間しか決めていない。**中を何単元に割るかは、うちの裁量。**

**60分を超える単元は作らない**と決めた。
90分・100分の単元は、話す中身が薄くなるか、聞く方が持たないかのどちらかになる。
だから科目2（240分）は4単元に、科目3（180分）は3単元に割った。

**割るときは、中欄の項目の切れ目で割る。**
勝手な切れ目で割ると、修了証に載る科目名と、中で教えていることがずれる。

### 実技の段

法定は2〜3時間。**段の分け方はうちの案**で、告示ではない。
実技のある五本は、**手引きと実施記録の様式**を付けた（`src/content/drill.ts`）。
**うちが出すのは学科だけ。実技は事業者が自社で行う。**

第1号・第2号・第4号（いずれも実技2時間）は、
**「見る（60分）」「操作する（30分）」「異常のときと止め方（30分）」の3段**にした。

### 六本で同じ中欄は、同じ教え方にした

「圧気工法の概要」「圧気工法による業務の危険性」「事故発生時の措置」
「高気圧障害の病理、症状及び予防方法」「関係法令」——
**中欄が同じなら、教える中身も同じでなければおかしい。**

だから共通の作りを一つ用意して、**持ち場のところだけ差し替えた**
（`$SP/kagen/parts.py`）。
たとえば「事故発生時の措置」の締めは、六本それぞれ違う：

- 第1号 → **「自分の持ち場は、まず送気を切らさないこと」**
- 第2号 → **「自分の持ち場は、圧を保つこと」**
- 第3号 → **「自分の持ち場は、人を通す部屋の担当。人数と時刻の記録がそのまま証拠になる」**
- 第4号 → **「自分の持ち場は、送気を切らさないこと。上げるのは表のとおり」**
- 第5号 → **「あなたは、これを治す部屋を操作する」**
- 第6号 → **「あなた自身の体の話。症状が出るのは、あなた」**

## 6. 条文で確かめていないもの

**確かめた番号だけを書く**という決まりのとおり、次は**番号を書かず、中身だけ**教えている。

### 高気圧の六つ

- 作業主任者（高圧室内作業主任者・潜水士）の選任 — **この特別教育とは別の資格**
- 作業時間の限り（圧と、その日にすでに入った時間で決まること）
- 減圧の速さと、減圧表
- 再圧室を設けること、その点検
- 送気設備の点検、空気清浄装置
- 自動警報装置、連絡の手段
- 立入禁止と表示
- 健康診断と、その記録
- 労働安全衛生規則第37条・第38条（特別教育の記録の3年保存）

**高圧則の全条文が手に入ったら、番号を入れる。**
とくに**作業時間の限りの数字**と**減圧の速さの数字**は、
条文を見るまで**この講座では数字を言わない。**「会社と表に確かめる」と言っている。

### 特定線量下業務

- 特定線量下業務の線（どれだけの線量から対象になるか）
- 被ばく限度の数字（年ごと・期間ごと・女性の別）
- 線量の測定と記録、その保存期間
- 健康診断と、その記録
- 保護具
- 労働安全衛生規則第37条・第38条

**除染則の全条文が手に入ったら、番号を入れる。**
被ばく限度の数字は、いま**言っていない。**「あなたの限度は、会社に確かめる」と言っている。

## 8. 隣の資格

- **高圧室内作業主任者** → 免許。この特別教育とは別

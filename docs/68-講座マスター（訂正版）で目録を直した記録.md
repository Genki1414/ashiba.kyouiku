# 講座マスター（訂正版）で目録を直した記録

直した日：2026年9月5日
直した先：`src/content/tokubetsu.ts`（目録）／`tests/tokubetsu.ts`（見張り）

---

## 1. 決めたこと（これが今後の順番）

**法定教育時間は、次の順で決める。**

| 順 | 何 |
|---|---|
| 1 | **現行の労働安全衛生関係省令**（安衛則、クレーン則、電離則、高気圧作業安全衛生規則…） |
| 2 | **省令から委任された現行の告示**（○○特別教育規程） |
| 3 | 厚生労働省・労働局などの**公式のまとめ** |

**民間サイトの一覧表は、法定時間の根拠にしない。**

うちの目録は、もともと 3（労働局のまとめ）が出どころだった。
1・2 と食い違ったら、**1・2 を採る。**
ただし**うちがまだ告示の全文を見ていないうちは、`checked` を付けない。**
（外に出る通信が組織の決まりで止まっていて、e-Gov も厚生労働省も開けない。docs/65）

## 2. 目録に足した項目

げんきさんの「各講座マスターには最低でも以下を保持する」に合わせて、
`Tokubetsu` に次を足した。

| 足した項目 | 何 |
|---|---|
| `gakka` | **学科の科目と、科目ごとの法定最低時間（分）** |
| `jitsugi` | **実技の科目と、科目ごとの法定最低時間（分）** |
| `variants` | **業務区分。**ここが入っている行を、一つの固定時間で実装しない |
| `fromMaster` | 時間の出どころが講座マスター（2026年9月5日）である印 |
| `checkedOn` | **法令を確かめた日** |

時間は**すべて「分」で持っている。**時間・分への直しは表示のときだけ
（`hoursText`）。これは前からそうしてある。

**見張り（tests/tokubetsu.ts）も足した。**

- **学科の科目の合計 ＝ 学科の法定時間**（ずれたら落ちる）
- **実技の科目の合計 ＝ 実技の法定時間**
- 実技がある行は、実技の科目も書いてある
- **業務区分を持つ行は、講座にしていない**（一律の時間で修了証を出さないため）
- **業務区分を持つ行に `checked` を付けない**
- 高圧室内は420分・実技0（前の版の540分＋180分を使っていない）
- 除染等業務は通常区分で240分＋90分、かつ業務区分を持っている

### no.32 跨線テルハについて（げんきさんの確定事項）

**跨線テルハ専用の条があるわけではない。**

**法令の上ではクレーンの特別教育に含まれる。**
うちのシステムでは、**対象業務をはっきりさせるために no.32 として別の行にする。**

講座は `crane` 1本で、目録の**31行目と32行目の両方が同じ講座を指している。**
講座の名前に両方を書いてある（docs/67）。

### no.42 高圧室内業務 — 前の版を取り消し

**学科420分・実技なし**が正しい。

元からあった目録の420分と、訂正版の講座マスターが一致したので `checked` を付けた。

科目（規程第6条）：圧気工法の知識60／圧気工法に係る設備60／
急激な圧力の低下、火災等を防止するための措置**180**／高気圧障害60／関係法令60。

**一つだけ、げんきさんに確かめたいことがある。**

### no.48〜51（電離則）— 時間が分かった

**電離則の本文には科目しか書いていないが、時間が無いわけではない。**
それぞれ別の特別教育規程に、範囲と最低時間がある。

|---|---|---|---|---|---|
| 48 加工施設等 | 電離則52条の6／核燃料物質等取扱業務特別教育規程1条 | **330** | **120** | 690／360 | **付けない** |

### no.61 除染等業務 — 一律の時間にしない

**元の690分＋390分を、一律の法定最低時間として使わない。**

**通常区分：学科240分（60／60／60／60）＋実技90分＝330分。**

**ただし業務区分で中身と時間が変わる。**

- 土壌等の除染等
- 除去土壌の収集等
- 汚染廃棄物の収集等
- 特定汚染土壌等取扱業務

`variants` に入れた。**`「除染等業務＝全員一律330分」` という実装をしない。**
見張りで、**業務区分を持つ行は講座にできない**ようにしてある。
講座にするときは、先に業務区分（variant）の持ち方を作る。

## 4. まだやっていないこと

**修了証への「法令バージョンのスナップショット」。**

げんきさんの設計ルールに、

> 法令改正時に既存修了者の履歴まで書き換わらないように、
> 講座マスターには法令バージョンを持たせる。
> 修了時点の講座名・科目・法定時間・根拠法令・根拠告示・法令バージョンを
> enrollment/certificate 側へスナップショット保存すること。

とある。**いまの `certificates` は、これを持っていない。**
（`enrollment_id` と `cert_no` と発行日しか無い。修了証の中身は、
発行のたびに `courses.ts` の**そのときの値**から作っている。）

**つまり今のままだと、法令が変わって講座を直した日に、
前に出した修了証の中身も変わってしまう。**
これは次にやる。docs に上げておく。

## 5. 直していないもの

**時間を直したのは、講座マスターに数字が書いてあった行だけ。**
書いていない行は触っていない（docs/24 の決まり：条文が出るまで直さない）。

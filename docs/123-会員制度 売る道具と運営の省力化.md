## 本番での通しの試験（げんきさんが 15 分で）

1. 運営でログイン → /owner「会員と報酬」でプランを確認
2. 自社（東北三上機材）の担当者でホーム「法人会員」→ ライトで申込み → マイページのお知らせに「月額の請求書が届いています」
3. /owner「会員と報酬」の入金待ちに出る。「請求書を発行する」で中身を見る → 「入金を確認した」→ 担当者に「チケットが付きました」
4. /order で講座を選び「チケットで払う」→ 受講コードが出る。残高が減る
5. /member で「解約を申し出る」→ 翌月末の日付が出る
6. 試験の契約は /owner で「終了」（残高は失効、履歴は残る）。試験の注文はそのまま（受講コードは自社で使える）

# 特定粉じん作業の特別教育：根拠と裏取り

docs/19 の手順①の記録。**確かめたことと、まだ確かめていないことを分けて書く。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | **特定粉じん作業に係る業務に係る特別教育** |
| 対象 | 常時**特定粉じん作業**（粉じん則別表第2に掲げる作業）に係る業務 |
| 学科 | **4時間30分** |
| 実技 | **無い** |

> ### 実技が無い
>
> 石綿と同じで、**この仕組みだけで修了証まで出せる。** 学科を見終わって試験に受かれば修了。
> `gate` は付けない。

## 根拠

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 第36条第29号 |
| 義務づけ | **粉じん障害防止規則 第22条** |
| 科目と時間 | **粉じん作業特別教育規程（昭和54年労働省告示第68号）** |

渡された一覧は「安全衛生特別教育規程」と書いてあったが、**粉じんの告示は別**
（粉じん作業特別教育規程）。直した。石綿の「第3条」と同じ種類の取り違え。

## 科目と時間（規程 第2条）

| # | 科目 | 範囲 | 時間 | 範囲の確認 |
| --- | --- | --- | --- | --- |
| 1 | 粉じんの発散防止及び作業場の換気の方法 | 粉じんの発散防止対策の種類及び概要／換気の種類及び概要 | **1時間** | **未確認** |
| 2 | 作業場の管理 | 粉じんの発散防止対策に係る設備及び換気のための設備の保守点検の方法／作業環境の点検の方法／清掃の方法 | **1時間** | **未確認** |
| 3 | 呼吸用保護具の使用の方法 | 呼吸用保護具の種類、性能、使用方法及び管理 | **30分** | 確認（複数一致） |
| 4 | 粉じんに係る疾病及び健康管理 | 粉じんの有害性／粉じんによる疾病の病理及び症状／健康管理の方法 | **1時間** | 確認（複数一致） |
| 5 | 関係法令 | 労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則及び粉じん障害防止規則中の関係条項 | **1時間** | **未確認** |

科目名5つと時間（1／1／0.5／1／1＝4時間30分）は、中小建設業特別教育協会・CIC・
東京技能講習協会・労働技能講習協会・産業技能センターで一致。

> ### 食い違いが1つあった
>
> 検索の要約の1つが「学科3時間＋実技1時間」と言った。
> ほかの5者と、科目ごとの時間の合計（4時間30分）が一致しているので、そちらを取った。
> **告示の表の写真が撮れたら、科目1・2・5の中欄と、実技が無いことを突き合わせる。**

## 例の書き方

docs/19 ⑤。特定粉じん作業をするのは、トンネル掘削、はつり・研磨・切断、鋳物（砂型・ばり取り・
ショットブラスト）、溶接、窯業・セメント・耐火物、金属研磨、木工、解体の破砕、道路カッター、石材加工。
**建設だけでもない。製造業（鋳物・窯業・金属加工）が大きい。**

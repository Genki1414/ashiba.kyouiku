# 自由研削用といし：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 自由研削用といしの取替え又は取替え時の試運転の業務に係る特別教育 |
| 対象 | グラインダー（卓上・両頭・携帯用ディスクグラインダー・切断機・エアグラインダー）のといしを取り替える、取り替えたあと試運転をする業務 |
| 学科 | **4時間**（3科目11単元） |
| 実技 | **2時間**（事業者が自社で行う） |
| 合計 | 6時間 |

**自由研削**＝といしか工作物を手で持って行う研削。工作物を機械に固定して送る**機械研削**（平面研削盤・円筒研削盤）は規程第1条の別の教育（学科7時間＋実技3時間）で、この講座では扱わない。

## 実技（告示第2条第3項）

「自由研削用といしの取付け方法及び試運転の方法について、**二時間以上**」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/toishi/drill`）。3つの段取り（30／50／40）は**うちの案であって告示ではない。**

## 単元の割り付け（学科240分・11単元）

| 科目 | 単元 | 分 |
| --- | --- | --- |
| 1（120分） | 1-1 研削盤の種類及び構造並びにその取扱い方法／1-2 といしの種類、構成、表示及び安全度並びにその取扱い方法／1-3 取付け具／1-4 覆い／1-5 保護具 | 35／40／15／15／15 |
| 2（60分） | 2-1 研削盤とといしとの適合確認／2-2 といしの外観検査及び打音検査／2-3 取付け具の締付け方法及び締付け力／2-4 バランスの取り方／2-5 試運転の方法 | 10／15／12／8／15 |
| 3（60分） | 3-1 法、令及び安衛則中の関係条項 | 60 |

中欄の項目をそのまま単元にした（5＋5＋1）。短い単元は図解2〜3枚と確認問題で組み、事例の無い単元もある。

## 条番号を書いていないところ

安衛則の**研削といしの各条**（覆い、試運転＝取替え後3分以上・作業開始前1分以上、最高使用周速度、
側面使用の禁止）は、**条番号を条文で確かめていないので書いていない。**科目3は中身で教えている。
**研削といしの構造規格**（告示）は名前だけ出し、条番号は書いていない。

教材の中の数字で、告示・構造規格の原文で確かめていないもの：
- 携帯用研削盤の覆いの露出角度「180度まで」（構造規格）
- 色帯（青50・黄63・赤80・緑100 m/s）（JIS）
- 破壊回転試験「最高使用周速度の1.5倍」（構造規格）
- ワークレストのすき間「3mm以内」（構造規格）
- レジノイドといしの使用期限「製造から3年が目安」（業界の慣行）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。

特別教育の記録の3年保存も、同じ理由で条番号を書いていない。

## 例の書き方

docs/19 ⑤。グラインダーを使うのは、
鉄工・製缶、建設（鉄筋・型枠・設備・内装・解体）、自動車整備、造船、農機の修理、木工、石材、
金属加工、設備の保守、学校の実習。**工場でも現場でも整備場でも、グラインダーのある所ぜんぶ。**足場屋の例は入れていない。

事例12件：ワークレストのすき間（鉄工）／切断といしの側面使用（設備工事）／回転数超え（自動車整備）／
濡れたといし（石材）／片側だけ小さいフランジ（農機の修理）／覆いを外した（解体）／保護めがね無し（学校の実習）／
落としたといし（造船）／正面に立った試運転（金属加工）／教育を受けていない新人（内装）／
覆いの無い研削盤を使わせ続けた（製缶）／記録が無かった（木工）。

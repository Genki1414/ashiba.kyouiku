# 教育担当者の画面

誰がどこまで進んだかを見て、修了証を出す画面です。`/admin` にあります。

---

## 1. 先にやること（1回だけ）

### ① データベースを新しくする

`supabase/apply-all.sql` を **もう一度** Supabase の SQL Editor に貼って実行してください。
今回、実務トレーニングの成績を残す表（`training_attempts`）が増えています。

流したかどうかは `/setup` で分かります。
「SQLを流したか」が赤いままなら、まだ入っていません。

### ② 最初の教育担当者を決める

`/admin` を開きます。まだ担当者が誰も居なければ、
**いまログインしている人が最初の担当者になります**。
事業者名（会社名）を入れて「この事業者で始める」を押してください。

このとき、まだどこにも所属していない人が全員その会社に入ります。
以降に登録した人も、会社が1社だけなら自動でそこに入ります。

> 事業者名は修了証には出ません。修了証の名義は Vercel の
> `CERT_ISSUER_NAME` / `CERT_ISSUER_RESPONSIBLE` で決めます（docs/08）。

### ③ 2人目からは画面で任命

一覧の各人の下にある「この人を教育担当者にする」で増やせます。
担当者が1人しか居ないときは、その人を降ろせません（誰も開けなくなるので）。

---

## 2. 画面の見かた

上に4つの数字が出ます。

| | 意味 |
|---|---|
| 受講者 | 自社に登録している人 |
| 学科修了 | 全13単元と修了試験に合格した人 |
| 修了証 | すでに修了証を出した人 |
| **未発行** | 出せるのに、まだ出していない人 ← **担当者がやることはここ** |

一覧は **未発行の人が上** に来ます。その下が学科修了、いちばん下がまだ途中の人です。

1人ぶんの中身：

- **学科** … 合格した単元 / 全13単元
- **修了試験** … 点数と合否（受けていなければ「まだ」）
- **実務** … 第1〜3章の **本番の最高技能点**。80点以上が緑。
  チュートリアルは数えません。2回以上通していれば回数も出ます
- **修了証** … 証明番号と発行日。まだなら「修了証を発行する」

---

## 3. 修了証を出す・取り消す

「修了証を発行する」で出ます。出せる条件は本人が出すときと同じで、
**全13単元の合格＋修了試験の合格**です。画面から頼まれても、
条件を満たしていなければサーバが断ります。

間違えて出したときは「取り消す」。行は消えず、取り消した印が付きます。
取り消したあとは、もう一度出せます（番号は新しくなります）。
出した記録・取り消した記録はどちらも残ります。

---

## 4. 見える範囲

担当者に見えるのは **自社の受講者だけ** です。
これは画面の出し分けではなく、サーバ側（`/api/admin/*`）と
データベースの行レベルセキュリティの両方で止めています。

担当者でない人が `/admin` を開くと「教育担当者だけが見られる画面です」と出て、
中身は何も出ません。

---

## 5. 実務トレーニングの成績はどこに残るか

- **端末**（いままでどおり）… 章の一覧の成績と間違いノートはこちらを見ます。圏外でも動きます
- **サーバ**（今回から）… 教育担当者が見るのはこちら

1章を通し終えるたびに、両方へ1件ずつ残ります。
サーバへ送れなかったとき（圏外・未設定）でも、端末の記録は残り、画面は止まりません。

合否（80点）は**サーバ側でもう一度計算**します。端末の言い分では決めません。

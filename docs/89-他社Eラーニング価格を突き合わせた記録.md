# 89 他社Eラーニング価格を突き合わせた記録（2026年9月7日）

うちの73講座と、Eラーニングで同じ特別教育を売っているところの値段を並べた記録。

## どうやって集めたか

**この環境からは、講習会社のページが開けない。**
プロキシが CONNECT に 403 を返す（組織の egress ポリシー）。
`www.cic-ct.co.jp` `www.tokubetu.or.jp` `k-k-k.jp` を実際に叩いて確かめた記録：

```
CONNECT www.cic-ct.co.jp:443 HTTP/1.1
< HTTP/1.1 403 Forbidden
"kind": "connect_rejected", "detail": "gateway answered 403 to CONNECT (policy denial)"
```

検索（WebSearch）は Anthropic 側で走って結果の文だけが返るので通る。だから
**「検索の抜粋から拾う」ことしかできなかった**。抜粋は通学講習の値段・講師養成コースの
値段・技能講習の値段が平気で混ざる。混ざっているとわかったものを落として、
業者名と金額が一緒に出ているものだけ拾って20講座。

そこで、げんきさんがGPTに調べさせた（2026年9月7日）。
指示は `docs/nedan/` の元CSVと同じ形で、こちらが踏んだ落とし穴を全部「やるな」として渡した。

- 生データ　`docs/nedan/2026-09-07-他社Eラーニング価格.csv`（GPTが返したまま）
- 突き合わせ後　`docs/nedan/2026-09-07-突き合わせ.tsv`（うちの講座IDに割り付けたもの）

## GPTの答えの裏取り

**信用できる。** 中小建設業特別教育協会の4件が、8月にこちらで調べた数字と一円も違わず一致した。

| 講座 | こちら（8月） | GPT（9月7日） |
| --- | --- | --- |
| 足場 | 10,505 | 10,505 |
| 石綿 | 8,525 | 8,525 |
| 酸欠 | 9,515 | 9,515 |
| 粉じん | 9,900 | 9,900 |

**そして、こちらの数字が1件まちがっていた。**
テールゲートリフターのCICを、検索の抜粋から16,500円と拾っていた。
GPTがページで見たのは**11,000円**（税抜10,000）。ページを見たほうを採った。
抜粋から拾った数字は当てにならない、という見立てがそのまま出た形。

## いちばん大事なところ：建設業教育協会の4,950円

**建設業教育協会（k-k-k.jp）だけ、20講座ぜんぶが4,950円ちょうどで、ばらつきがゼロ。**

| 業者 | 件数 | 出てきた値段の種類 |
| --- | --- | --- |
| 建設業教育協会 | 20 | **4,950 のみ** |
| 助太刀学院 | 11 | 9,400／10,500／11,600／12,500 |
| 安全・技能推進協会 | 9 | 9,396〜12,990（8種類） |
| 中小建設業特別教育協会 | 8 | 8,525／9,515／9,900／10,505 |
| 東京技能講習協会 | 7 | 10,000／11,000／14,000 |
| CIC日本建設情報センター | 1 | 11,000 |

ほかは全部ばらけているのに、ここだけ一律。**本当に一律なのか、確かめられていない。**
（GPTは講座ごとに別のURLを返しているので、ページは見ているらしい。ただ確認はできていない）

ここが本当かどうかで、結論が正反対になる。

| | うちが高い | 同じ | うちが安い | 差のまん中 |
| --- | --- | --- | --- | --- |
| **建設業教育協会を入れる** | **20講座** | 0 | 13 | — |
| **除く** | **0講座** | 1 | 23 | 4,400円 安い |

入れた場合にいちばん開くのは高圧・特別高圧電気で、**うち13,200 に対して 4,950。8,250円 高い**。

## 決着（2026年9月7日）

**げんきさんが確かめた。20講座は本当に一律4,500円だった。**
そして**あちらも実技は事業者が自社でやる形で、うちと同じ**。
つまり「うちは実技の手引きが付くぶん高い」は、この会社には通らない。

**「合わせる」と決めて、20講座を4,500円（税込4,950円）に下げた。**

| もとの値段 | 講座 |
| --- | --- |
| 12,000 → 4,500 | 高圧・特別高圧電気 |
| 9,000 → 4,500 | アーク溶接 |
| 8,000 → 4,500 | チェーンソー／移動式クレーン |
| 7,000 → 4,500 | 低圧電気／エックス線・ガンマ線（両方）／小型ボイラー／電気自動車の整備 |
| 6,000 → 4,500 | フルハーネス／ロープ高所／フォークリフト／巻上げ機 |
| 5,500 → 4,500 | エックス線／ガンマ線／建設用リフト／玉掛け／タイヤ空気充てん |
| 5,000 → 4,500 | テールゲートリフター／自由研削といし／ダイオキシン類 |

これで、**よその値段が付いた33講座のうち、うちのほうが高いものは0になった**
（20講座が並び、13講座がうちのほうが安い）。

**あちらが売っていない53講座は、動かしていない。** 比べる相手がいないので下げる理由が無い。
そのうち40講座は、どこもEラーニングを売っていない。

見張りは `tests/pricing.mts` の「建設業教育協会に合わせた20講座」。
1本でも4,500円から外れると止まる。**53講座はこの関門の外**。

## 次に確かめること

1. ~~建設業教育協会の4,500円が本当に一律か~~　→ **一律だった（2026年9月7日、げんきさんが確認）**
2. **4,500円で何が付いてくるのか。** うちは事例・図解・実技の手引き・実施記録の様式まで入っている。
   中身で差が付いているなら、いつか値段を戻す話も出てくる。いまは合わせておく。
3. **あちらが売っていない53講座の値段。** いまは動かしていないが、
   40講座はどこも売っていない（比べる相手がいない）。ここをどうするかは別の判断。

## 数字の状況

  職長は特別教育ではないので入っていないのが正しい。

## 比べるときの前提

うちが出すのは**どこも学科だけ**で、実技は事業者が自社でやる。よそのEラーニングも同じ。
だから他社の金額も学科ぶんの値段として並べてある。
グッドラーニングのテールゲート22,000円は**1事業者の年間契約**でひとり分ではないので、
比べる相手から外した。

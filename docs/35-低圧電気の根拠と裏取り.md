# 低圧電気取扱：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 低圧電気取扱業務に係る特別教育 |
| 対象 | 低圧（直流750V以下・交流600V以下）の充電電路の敷設・修理の業務。配電盤室・変電室など区画された場所に設置する低圧の電路のうち、充電部分が露出している開閉器の操作の業務 |
| 学科 | **7時間**（5科目23単元） |
| 実技 | **7時間**（開閉器の操作の業務のみを行う者は**1時間**）。事業者が自社で行う |
| 合計 | 14時間（開閉器のみは8時間） |

**電気工事士の資格があっても別に要る**（電気工事士法と安衛法は別）。高圧・特別高圧は規程第5条、電気自動車等の整備は第6条の2で、別の教育。

| 5 | 関係法令 | 法、令及び安衛則中の関係条項 | **1時間** |

## 実技（告示第6条第3項）

「低圧の活線作業及び活線近接作業の方法について、**七時間以上**（開閉器の操作の業務のみを行なう者については、**一時間以上**）」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/teiatsu/drill`）。4つの段取り（60／90／150／120）は**うちの案であって告示ではない。**
様式に「業務の区分」欄（敷設・修理＝7時間以上／開閉器の操作のみ＝1時間以上）を置いた。
開閉器のみの人は、段取り3の「露出した開閉器の操作」を中心に1時間、と手引きに書いてある。

## 条番号を書いていないところ

安衛則の**電気の各条**（電気機械器具の囲い、漏電遮断器、停電作業の措置、低圧活線作業、低圧活線近接作業、
絶縁用保護具等の定期自主検査、使用前点検、操作部分の照度）は、**条番号を条文で確かめていないので書いていない。**科目5は中身で教えている。

教材の中の数字で、安衛則・電技の原文で確かめていないもの：
- 絶縁用保護具等の定期自主検査「6か月以内ごとに1回」、記録「3年」（安衛則）
- 人を守る漏電遮断器「30mA・0.1秒以内」（JIS・電技解釈）
- 接地抵抗 D種「100Ω以下（0.5秒以内に切れる漏電遮断器があれば500Ω以下）」、C種「10Ω以下」（電技解釈）
- 絶縁抵抗の下限「0.1／0.2／0.4MΩ」（電技）
- 感電の電流の目安「1／5／10〜20／50／100mA」（講習で広く使われる値）
- 絶縁工具の表示「1000V」（IEC）
- 胸骨圧迫「5cm・100〜120回／分」（救急蘇生ガイドライン）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。

## 例の書き方

docs/19 ⑤。低圧の電気を扱うのは、
電気工事、設備の保守、ビル管理、工場の保全、製造ラインの機械保守、太陽光の施工、空調・給排水の設備工事、
看板・照明の工事、通信・LANの工事、自動車の整備場、農業の施設、食品工場、学校の実習、イベントの電源。
**電気屋だけではない。分電盤を開ける仕事ぜんぶ。**足場屋の例は入れていない。

事例15件：汗をかいた手で100V（農業の施設）／主幹の一次側（設備工事）／露出した開閉器のアーク（食品工場の保全）／
緩んだ端子の火災（ビル管理）／洗車場のポンプ（自動車の整備場）／活線で端子を触った点検（製造ラインの保守）／
隣の母線に肘（電気工事）／金属のはしごで感電して墜落（看板・照明工事）／施錠せずに別の人が入れた（工場の保全）／
別の班が終わる前に開閉器（ビル管理）／感電した同僚を素手でつかんだ（電気工事）／応援の人に触らせた（イベントの電源）／
電気工事士だから不要とした（電気工事）／検査していない絶縁手袋（設備の保守）／開閉器の操作だけの人（製造）。

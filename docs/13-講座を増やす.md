# 講座（特別教育）を増やす

特別教育は種類が増えていきます。増やすたびに作り直さなくて済むよう、
**講座** という単位で分けてあります（0011）。

---

## 1. 決めたこと

| | 決まり |
| --- | --- |
| 単元ID | `講座:番号`（例 `ashiba:1-1`）。講座ごとに 1-1 が重なるため |
| 受講 | **1人・1講座につき1件**（`enrollments.course_id`） |
| 受講コード（席） | **1講座ぶん**。注文が講座を持ち、席はそれを継ぐ |
| 修了証 | 受講に紐づくので、自然と講座ごと。表題に講座名が載る |
| URL | `/edu/<講座>/…`（例 `/edu/ashiba/1-1`） |

受講コードは1講座ぶんです。足場のコードで高所作業車は受けられません。
修了証を出すときも、**その講座の席が入金済みか**を見ています
（別の講座の席では出ません。`certificates_require_paid()`）。

---

## 2. 増やす手順

### ① 教材を置く

`content/courses/<講座>.json`。中身の形は既存のものと同じです
（`src/types/curriculum.ts` の `CurriculumSchema` で検証されます）。

### ② 一覧に1行足す

`src/content/courses.ts`：

```ts
{
  id: "kousho",                       // URL と単元IDに使う。あとから変えない
  name: "高所作業車の運転の業務に係る特別教育",   // 修了証に載る正式名称
  short: "高所作業車",                  // 画面で使う短い呼び名
  basis: "労働安全衛生法第59条第3項／…",
  totalMin: 540,
  file: "kousho.json",
  ready: true,                        // 教材がまだなら false（「準備中」と出る）
}
```

`ready: false` にしておくと、ホームと講座の一覧に**名前だけ**が出ます。
何が来るのか分かるので、教材を作っているあいだはこれで置いておけます。

### ③ SQL を流す

```bash
npm run build:sql
```

で `supabase/apply-all.sql` を作り直し、SQL Editor で実行します。
`courses` と `lessons` に新しい講座が入ります。何度流しても壊れません。

**これだけです。**画面もAPIも触りません。

---

## 3. 触らなくてよい所（すでに講座ごとになっている）

- ホーム … 受けられる講座を並べる
- `/edu` … 講座が2つ以上あるときだけ一覧を出す（1つなら素通し）
- 教育担当者の画面 … 上に講座の切り替えが出る。名簿・受講コードは講座ごと
- 申込み（`/order`）… どの講座の席を買うかを選ぶ
- 照合の記録 … 単元は番号だけ出る（講座の頭は外して表示）

---

## 4. 実務トレーニングについて

足場を組むゲームは、いまのところ足場の講座のものです。
`src/content/courses.ts` の `TRAINING_COURSE` で結びつけてあります。
ほかの講座に実務を作ったときは、ここを増やしてください。

---

## 5. 総合問題

`content/exam-extra.json` は、いまは足場のぶんだけです。
講座を増やすときは、教材と同じように講座ごとに分けてください
（`src/lib/examPool.ts`）。

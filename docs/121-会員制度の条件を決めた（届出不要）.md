## 決めた条件と、その理由

| 項目 | 決めたこと | 理由 |
|---|---|---|
| **チケットの有効期間** | **付与から6か月**。プランの設定で6を超えられない（SQL の check・運営の画面の両方） | 資金決済法 第4条第2号。発行から6か月内に限り使えるものは前払式支払手段の届出・供託の対象外。12か月だと基準日の未使用残高が1,000万円を超えた時点で届出と供託が要る。代理店の分（第三者型に見える）も同じ条文で除外になる |
| 契約期間 | 12か月。満了の1か月前までに申し出が無ければ同じ条件で12か月自動更新 | 指示書どおり。毎朝の処理（renew_contracts）が満了30日前に延ばす |
| 途中解約 | **申し出の月の翌月末で終了**。以後の会費は請求しない。払った月のチケットは失効日まで使える | 「12か月分を払え」と縛ると売りにくい。月額の性質に合わせて、翌月末で切る。担当者は /member から、運営は本部の画面から申し出を受けられる（cancel_contract） |
| 契約終了時の残高 | **失効**（返金なし） | チケットは現金に戻せないもの、と規約に書く。end_contract が残りを 0 にして履歴に「契約終了」と残す |
| 会費の返金 | **なし**（役務の提供を始めたもの）。運営が例外で返金あつかいにする口は残す | 前払い・月ごとの役務。返金あつかい（refund_contract_payment）はその月のチケットを消し、報酬を打ち消す |
| 支払期限 | 請求書の発行から7日（受講コードの注文と同じ） | 画面ごとに違うことを言わない |
| 滞納 | 期限を**14日**過ぎたら停止（チケットが使えない）。入金で自動的に再開 | 止めないと払わずに使える。pay_contract_payment が active に戻すので、運営の手は要らない |
| チャージバック | 対象外 | 月額はいま請求書払いだけ（カードの自動引落は後ろへ） |
| 報酬の支払い | **月末締め・翌月末払い**。最低支払額 **5,000円**（未達は翌月に繰越）。振込手数料は当社負担 | 月1回でまとめる。少額の振込を毎月やらない |
| 報酬の税 | **消費税込みの額**として払う。**源泉徴収はしない**（紹介手数料は所得税法204条の列挙に当たらない）。支払調書は要件に応じて当社が出す。インボイス登録番号は振込先の欄に任意で書ける | 個人パートナーが多いと見込む。源泉を引くと手続きが増える。**税理士に一度見てもらうこと**（下の「確かめてほしいこと」） |
| パートナー契約終了後 | 終了月までの確定分は払う。以後の継続報酬は無し | pay_contract_payment は承認済み（approved）のパートナーにしか報酬を立てない。停止すればそこで止まる |
| 紹介した会社が解約 | 最後の入金の月まで確定。以後なし | 入金1件に報酬1行、の作りそのまま |
| 協力会社の修了記録 | 協力会社自身の名簿（companies.parent_id で親に付く） | docs/119 の提案どおり。フェーズ2 |
| 月額の払い方 | 請求書払い（運営の入金確認）だけ。カードは後ろへ | docs/119 §9 |

## 何が変わったか（0041）

- `plans.ticket_months` の既定を 6 に、check を 1〜6 に。もう入っている行も 6 に直す
- `contracts` に `cancel_requested_on`・`renewed_at`
- `cancel_contract(契約, 誰)`：終了日＝翌月末、次回の請求を消す、入金待ちを取消。二度目は何もしない。入金待ちのままの契約はその日で終わり
- `end_contract(契約, 誰, 注記)`：残りのチケットを失効（履歴「契約終了」）、入金待ちを取消、ended。二度呼んでも二度は消さない
- `renew_contracts()`：満了30日以内・申し出なし・有効、を12か月のばす
- 日次処理 `runDaily`（毎朝の Cron と、本部の「日次処理を回す」）：失効 → 自動更新 → 解約の終了 → 滞納の停止 → 翌月の起票
- 画面：/member に「解約を申し出る」、本部に「解約を受ける」、プランの編集は6か月まで。案内3枚・申込み・パートナーの画面に条件を書いた
- 規約：第5条「法人会員（月額プラン）とチケット」、第6条「営業パートナー」（**制度を開けている店だけ**。あとの条番号はそのぶんずれる）
- 特商法の表記：「法人会員（月額プラン）」の欄（同じく開けている店だけ。値段は plans の表から）
- 試験：SQL 4件（6か月の縛り・解約・終了・自動更新）、`tests/members.ts` 176件

## 確かめてほしいこと（人に）

決めたが、専門家の目を通してから本番で売るほうがよいもの。

1. **税理士**：パートナー報酬の源泉徴収なし・消費税込み・支払調書の要否。個人への「紹介手数料」は列挙外という整理で進めている
2. **行政書士か弁護士**：規約 第5条・第6条と業務委託契約書の文。チケットを「通常価格相当額を差し引く権利」と書き、6か月で失効させている
3. 6か月で売れるか（営業上の判断）。12か月に戻すなら届出・供託の準備が要る（docs/119 §8）

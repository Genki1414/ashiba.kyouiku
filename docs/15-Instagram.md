# Instagram（ashiba.kakumei）— 投稿とストーリーの台本

足場屋革命のアカウントを、そのまま足場トレーニングに使う。
フォロワーは足場屋。相手は変わっていないので、作り直さずに中身だけ入れ替える。

このファイルは **そのまま写して貼れる文** で書いてある。
考える所は「何を撮るか」だけにしてある。

---

## 0. 先に決まっていること（言っていい／言ってはいけない）

言っていいこと

- 特別教育（足場の組立て等の業務／安衛則第36条）の **学科6時間** をスマホで受けられる
- 受講中は **顔の照合** で本人確認をしている。人が入れ替わったら止まる
- 修了証は **東北三上機材株式会社** の名前で出る（どこの事業者の人でも同じ）
- 受講の記録は **3年** 残る
- 実務トレーニングは **第1章だけ無料**（ログインだけで遊べる）
- 第2章から先と特別教育は有料。**個人でも会社でも買える**
- いまの支払いは **請求書払いのみ**

言ってはいけないこと

- 「これだけで職長になれる」「資格が全部取れる」— 取れるのは足場の特別教育
- 「実技はいらない」— 特別教育の話であって、現場の実技を否定しない
- 「必ず組めるようになる」— 覚えられるのは **手順・段取り・なぜ駄目かの判断**。
  単管を担ぐ体の使い方は現場でしか身につかない。ここは正直に言った方が売れる。

## 1. 最初の投稿（切り替えの1本）

いまのフォロワーは「足場屋革命」として付いた人。
黙って中身が変わると外れるので、1本だけ断りを入れる。

### 撮るもの
第1章を遊んでいる画面録画（15〜20秒）。
割り付けを置く→ジャッキを合わせる→根がらみを入れる、まで。

### 文（そのまま貼る）

```
このアカウント、中身を変えます。

足場屋向けのポータルはたたみました。
かわりに、足場の「教育」をやります。

・足場の組立て等 特別教育（学科6時間）をスマホで
・組む手順を覚える実務トレーニング

新人に「見て覚えろ」と言わなくて済むようにする。
それだけのために作りました。

つづきは順番に出していきます。

#足場 #足場屋 #特別教育 #安全教育 #建設業 #職人 #新人教育
```

## 2. 投稿の順番（最初の5本）

上から順に出す。1本ずつ、間を1〜3日あける。

### ① リール｜第1章の画面録画（掴み）

最初の3秒に文字を出す。**「これ、ゲームじゃないです」**
次に **「足場の組み方を覚えるアプリです」**

```
第1章「段取りと根がらみ」

割り付け・内柱・ジャッキ合わせ・建方の基準。
最初にここを外すと、上まで全部ずれる。

1コマ450mm、1段1,800mm。
寸法もそのまま合わせてあります。

第1章はログインだけで無料で遊べます。

#足場 #足場屋 #新人教育 #建設業 #足場組立
```

### ② リール｜「なぜ駄目か、言えますか？」（コメントを取る）

間違った状態の場面を5秒見せて、止める。答えは最後に出す。

```
これ、なぜ駄目か言えますか？

答えはコメントで。

「駄目だ」と言うのは簡単でも、
「なぜ駄目か」を言えないと、新人は同じ事をやります。

このアプリは、間違えると親方に叱られます。
そのとき **なぜ駄目か** まで言います。

#足場 #足場屋 #安全 #職長 #新人教育
```

> コメントが付いたら全部返す。ここが一番フォローに繋がる。

### ③ カルーセル｜特別教育の話（買う人向け）

画像は6枚。文字だけでいい。

1. 「足場の特別教育、まだ人を出して受けてますか？」
2. 「学科6時間。スマホで受けられます」
3. 「受講中は顔の照合で本人確認。人が入れ替わったら止まります」
4. 「修了証は東北三上機材株式会社の名前で出ます」
5. 「記録は3年残ります。監督署に聞かれても出せます」
6. 「1人から申し込めます。請求書払い」

```
足場の組立て等 特別教育（安衛則第36条）の学科6時間を、
スマホで受けられるようにしました。

・顔の照合で本人確認（他人が座ったら止まる）

```

## 3. ストーリーで事前登録を取る（本命）

投稿は見つけてもらうため。**登録はストーリーで取る。**

5枚ひと組で流す。1枚目から5枚目まで、続けて上げる。

| 枚 | 出すもの | 文字 | スティッカー |
|---|---|---|---|
| 1 | 第1章の画面録画3秒 | これ、足場を組むアプリです | なし |
| 2 | 章の一覧 | 第1〜3章。手順と段取りをここで覚える | なし |
| 3 | 修了証の画像 | 特別教育の学科6時間もスマホで | なし |
| 4 | 背景だけ | 気になるのはどっち？ | **アンケート** |
| 5 | 背景だけ | 先行のご案内、送ります | **質問** |

### 4枚目・アンケートの選択肢

```
気になるのはどっち？

 [ 実務トレーニング ]   [ 特別教育 ]
```

> 押すだけなので手が動く。ここで反応した人が5枚目に進む。
> 誰が押したかは自分の画面で見えるので、後でその人にDMできる。

### 5枚目・質問スティッカーの文（ここが事前登録）

```
先行のご案内を送ります。
会社名とお名前を入れてください。
（個人の方はお名前だけで大丈夫です）
```

> 質問スティッカーの回答は、自分の画面では **誰が送ったか分かる**。
> 回答が来たら、その人へDMで返す。これが事前登録の受け口になる。

### 事前登録に来た人へのDM（そのまま貼る）

```
ご登録ありがとうございます。
足場トレーニングの中川です。

・実務トレーニング 第1章は、いまログインするだけで遊べます
・第2章から先と、特別教育（学科6時間）は有料です
・支払いは請求書払いです。個人宛の請求書も出せます

始められるようになったら、こちらから改めてご連絡します。
先に触ってみたい方はこのリンクからどうぞ。
→（アプリのURL）

人数や、受けさせたい人の名前が決まっていれば
そのまま送ってください。こちらで用意しておきます。
```

### 注意

- 質問スティッカーの回答を **名前ごと再シェアしない**。会社名が出る。
  紹介したい時は名前を隠すか、本人に断ってから。
- 回答はInstagramの中にしか残らない。**その日のうちにメモへ写す。**
  ストーリーは24時間で消える（アーカイブには残るが、取りこぼす）。

## 4. 事前登録をきちんと溜めたくなったら

いまのやり方（ストーリーの質問スティッカー → DM → 手で記録）は、
数十人までなら回る。それ以上になったら手が足りなくなる。

そうなったら、アプリ側に事前登録のページを作る。
プロフィールのリンクをそこへ向ければ、名前とメールがそのまま溜まる。
必要になったら言ってください。作ります。

## 5. プロフィール（決めたら書き換える）

名前（検索に効く欄）

```
足場屋革命｜足場の特別教育と実務トレーニング
```

リンクの欄は、いま空。アプリのURLが決まったら必ず入れる。
入れていないと、投稿を見て「やりたい」と思った人の行き先が無くなる。

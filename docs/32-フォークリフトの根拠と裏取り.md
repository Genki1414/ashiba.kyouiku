# フォークリフト（最大荷重1トン未満）：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | フォークリフト（最大荷重1トン未満）の運転の業務に係る特別教育 |
| 対象 | 最大荷重**1トン未満**のフォークリフトの運転 |
| 学科 | **6時間**（4科目14単元） |
| 実技 | **6時間**（事業者が自社で行う） |
| 合計 | 12時間 |

1トン以上は技能講習（フォークリフト運転技能講習）。この特別教育では乗れない。
**線は銘板の最大荷重で見る。**運ぶ荷の軽さは関係ない。
アタッチメントを付けると許容荷重は減るが、就業制限の線は銘板の最大荷重のまま。

| # | 科目（左欄） | 範囲（中欄） | 時間 |

> ### 告示の字
>
> 告示は「フオークリフト」「ヘツドガード」「バツクレスト」と書く（小さい「ォ」「ッ」を使わない）。
> `src/content/forklift.ts` の scope はその字のまま。画面の題名と台本は「フォークリフト」。

| 科目 | 範囲 | 時間 |

## 単元の割り付け（学科360分・14単元）

| 科目 | 単元 | 分 |

| 2（120分） | 2-1 荷役装置（マスト・フォーク・チェーン）／2-2 油圧装置と安全弁／2-3 ヘッドガード・バックレストと荷役の附属装置・取扱い方法 | 40／40／40 |

短い単元は図解2〜3枚と確認問題で組み、事例は無い。

## 条番号を書いていないところ

安衛則の**フォークリフトの各条**（前照灯・後照灯、ヘッドガード、バックレスト、パレット、
作業計画、作業指揮者、制限速度、転倒防止、接触防止、合図、離れるときの措置、移送、
とう乗の制限、用途外使用の制限、修理時の措置、定期自主検査・特定自主検査・作業開始前点検）は、
**条番号を条文で確かめていないので書いていない。**科目4は中身で教えている。

同じ理由で、就業制限の条（法第61条）も番号を書かず「就業制限という決まり」と呼んでいる。

## 例の書き方

docs/19 ⑤。1トン未満のフォークリフトを使うのは、
倉庫・物流センター、運送の営業所、製造の工場（部品・食品・印刷・製材）、
小売のバックヤード（ホームセンター・スーパー）、農業の出荷場、卸売市場、港湾、
建設の資材ヤード、リサイクル。**建設だけではない。倉庫・工場・小売・農業が大きい。**

事例13件：冷蔵倉庫の一酸化炭素（物流）／出荷場の充電（農業）／曲がり角の後ろの振れ（物流）／
急ブレーキで荷が落ちた（小売）／前が見えないまま前進（製材）／パレットに人を乗せた（倉庫）／
ストッパーピン（建設の資材ヤード）／ひび割れフォークの溶接（製材）／安全弁の圧を上げた（金属加工）／
ホースを手で探した（市場）／荷重中心（建材店）／割れたパレット（農業）／
技能講習が要る機械に乗せた（倉庫）／計画無しで歩行者と接触（食品工場）／ブレーキ異常を放置（港湾）。

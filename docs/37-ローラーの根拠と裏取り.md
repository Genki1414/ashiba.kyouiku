# ローラー：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | ローラーの運転の業務に係る特別教育 |
| 対象 | ローラーの運転（**道路上を走行させる運転を除く**）の業務 |
| 学科 | **6時間**（3科目9単元） |
| 実技 | **4時間**（事業者が自社で行う） |
| 合計 | 10時間 |

**質量にかかわらず特別教育。**ローラーは施行令別表第7の「締固め用機械」で、
整地・運搬・積込み用／掘削用／基礎工事用／解体用のような**3トン以上＝技能講習の区分が無い**。
現場に「大きいローラーは技能講習」という誤解があるので、教材の科目3で正面から扱っている。

**公道を自走させるのは道路交通法（運転免許）。**安衛則の号が「道路上を走行させる運転を除く」と
書いているので、教材の1-1と3-1で二度、別の法律だと言っている。

| # | 科目（左欄） | 範囲（中欄） | 時間 |

> ### 定義の括弧
>
> 科目名（左欄）の「（安衛則第三十六条第十号の機械をいう。以下同じ。）」は定義の括弧なので、
> `src/content/roller.ts` の科目名からは除いてある（小型車両系・テールゲートリフター・巻上げ機と同じ扱い）。

## 実技（告示第12条第3項）

「ローラーの運転方法について**四時間以上**」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/roller/drill`）。4つの段取り（50／80／70／40）は**うちの案であって告示ではない。**
様式に「**公道は使えません**」と書いた。

## 単元の割り付け（学科360分・9単元）

| 科目 | 単元 | 分 |
| --- | --- | --- |
| 1（240分） | 1-1 ローラーの種類及び用途／1-2 動力伝達装置／1-3 作業装置（ロール・振動装置・散水装置）／1-4 かじ取り装置／1-5 ブレーキ／1-6 電気装置・警報装置・附属装置と取扱いの方法 | 50／35／40／30／35／50 |
| 2（60分） | 2-1 運転に必要な力学／2-2 ローラーによる施工方法 | 30／30 |
| 3（60分） | 3-1 法、令及び安衛則中の関係条項 | 60 |

科目1の中欄は「種類及び用途」と、装置を列挙した長い一文の二つ。装置ごとに5単元に分けた
（作業装置は告示の並びに無いが、ロール・振動・散水を「作業装置」としてまとめた）。

## 条番号を書いていないところ

安衛則の**車両系建設機械の各条**（作業計画、制限速度、転落等の防止、接触の防止、合図、
運転位置から離れる場合の措置、移送、とう乗の制限、用途外使用の制限、修理等の作業指揮者、
定期自主検査、作業開始前点検、前照灯）は、**条番号を条文で確かめていないので書いていない。**科目3は中身で教えている。

施行令別表第7の号番号も、条文で確かめていないので書いていない（「締固め用機械として載っている」と説明）。

教材の中の数字で、原文で確かめていないもの：
- 定期自主検査「1年以内ごとに1回」「1月以内ごとに1回」、記録3年（安衛則）
- 作業開始前点検の項目「ブレーキ・クラッチの機能」（安衛則）
- 技能講習の区分「機体重量3トン以上」（安衛令）
- 転圧の重ね幅「ロール幅の1/3〜1/2」（施工の慣行）
- アスファルトの三段階（初期・二次・仕上げ）と使う機械（施工の慣行）

いずれも講習・施工の現場で広く使われている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。

## 例の書き方

docs/19 ⑤。ローラーを使うのは、
道路工事、造成・宅地、駐車場、グラウンド、堤防・河川、埋立、農地・土地改良、林道、
産廃処分場、空港、公園の維持管理、上下水道の埋戻し。**建設だけではない。自治体・農業・林業でも使う。**足場屋の例は入れていない。

事例22件：公道の自走で無免許（道路工事）／軟らかい埋戻しで横転（上下水道）／粘性土に振動（河川）／
下り坂で中立にして激突（造成）／高圧油を手で探した（造成）／止まったまま振動で波（道路）／
振動で隣家にひび（道路）／スクレーパ外し忘れ（道路）／中折れ部で挟まれ死亡（造成）／
ロックバー無しの整備（機械整備）／駐車ブレーキ無しで逸走（道路）／下り坂で法面から転落（造成）／
後退警報を切って轢過（道路）／ステップから飛び降り（造成）／ヒューズに針金で火災（造成）／
坂を横切って横転（造成）／雨のあとの土をこねた（造成）／高さを見る人を後退で轢過（道路）／
重ね幅を取らずわだち（道路）／技能講習で足りると思い込み（造成）／作業計画も誘導者も無く轢過（外構）／
道板の勾配が急で転落（道路）。

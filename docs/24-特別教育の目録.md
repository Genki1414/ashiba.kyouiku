# 特別教育の目録（65種類）

## これは何か

**教材ではなく、目録。**
労働安全衛生法59条3項で特別教育が要る業務を、学科・実技の法定時間と
根拠とともに並べたもの（`src/content/tokubetsu.ts`）。

受けられる講座は `src/content/courses.ts` が持っている。**別物。**

使い道は3つ。

- 次にどれを作るかを決める材料
- 「この教育はありますか」と聞かれたときに答える元
- 作るときの出発点（時間と根拠から、条文へ辿る）

本部の画面（`/owner` →「特別教育の目録」）から見られる。

## いちばん大事な決まり

### 目録の時間で、修了証を出さない

**目録の時間は「だいたいこれくらい」であって、教材の時間ではない。**

元にした一覧は65件のうち**11件しか条番号が入っておらず**、
残り52件は労働局のまとめページが出典だった。

> ### いったん直して、戻した行がある
>
> **第1種酸素欠乏危険作業**の「学科4時間」を、
> よその講習の頁（CIC・JAC）を根拠に **5時間30分へ「直した」。**
>
> あとで告示の条文が出てきて、**一覧のほうが正しかった。**
>
> - 酸素欠乏危険作業特別教育規程 **第1条**（第1種）… 30分／30分／1時間／1時間／1時間 ＝ **4時間**
> - 同 **第2条**（第2種）… 1時間／1時間／1時間／1時間／1時間30分 ＝ **5時間30分**
>
> よその講習は、どこも**第2種**（酸素欠乏・硫化水素）を売っている。
> その頁の「5時間30分」を、第1種の行に当ててしまった。
>
> **よその講習の頁で目録を直さない。条文が出るまで、直さない。**
> 直すのは、条文を見たときだけ。

いま第1種・第2種の行は、どちらも告示の条文で確かめてある。

確かめた行にだけ `checked` を付けてある。
`trustedHours()` が false の行は、**そのまま講座にしてはいけない。**

講座にするときは docs/19 のとおり、
**規程の条文から科目と細目を取り直す**こと。
取り直したら `checked` を付け、`courseId` でつなぐ。

`npm run test:tokubetsu` が、つないだ行の時間と `courses.ts` の
`totalMin` が一致しているかを見ている。食い違えば、
目録か教材のどちらかが嘘をついている。

### 目録を、修了証の側から読まない

`drawCert.ts` / `cert.ts` / `hours.ts` / `/api/admin/cert` / `/api/issue` は
目録を読まない。読み始めた瞬間、確かめていない時間が紙に載る道ができる。
これも試験が見ている。

### 職長教育は入れない

職長教育は安衛法**60条**で、特別教育（59条3項）とは別の制度。
目録に混ぜると、修了証の表題も根拠も食い違う。

## どこから手を付けるか

**実技の要らないものが13種類ある。**
実技は事業者が自社でやることになるので、学科だけで修了するものは
**この仕組みだけで修了証まで出せる。** そこが先。

| | 種類 | 学科 |
| --- | --- | --- |
| 足場の組立て等 | 63 | 6時間（**作ってある**） |
| 高圧室内作業 | 42 | 7時間 |
| 四アルキル鉛等 | 43 | 6時間 |
| 第1種酸素欠乏 | 44 | 4時間（**条文で確かめた**。告示第1条） |
| 第2種酸素欠乏 | 45 | 5時間30分（**作ってある**。告示第2条） |
| エックス線・ガンマ線 | 47 | 4時間30分（2026-04-01 施行） |

| ダイオキシン類（3種） | 57・58・59 | 各4時間 |

足場屋の現場でそのまま要るのは、**石綿・粉じん・酸欠・ずい道**。
売り先が同じなので、足場を買った会社にそのまま案内できる。

実技のある52種類は、実技を事業者にやってもらう形（`gate: "drill"`）に
なる。学科だけのものより一段手間が増えるので、後回しでよい。

## 受ける人にも見せている

`/edu` の**「その他特別教育」を開くと**、まだ作っていない64件が並ぶ。

**「足場だけの会社」と思われて終わるのがいちばん困る。**
石綿も粉じんも酸欠も、同じ現場で要る。並べておけば気づいてもらえるし、
「入り用のものがあれば連絡してください」と書いてあるので、
**作る順を決める材料**が向こうから来る。

出すときに気を付けたこと。

- **受けられるように見せない。** 「準備中」と出して、押せる札にしない
- **実技の要るものは、そう書く。**「実技は事業者で」。
  黙って並べると「ここで全部済む」と思われる
- 開く前は出さない。64件がいきなり並ぶと、足場を受けに来た人が迷う

### 探せること

64件ある。**探せないと、有るのに無いと思われる。**

法令の名前は現場の言い方と違うものが多い。
「石綿」を「アスベスト」、「酸素欠乏」を「酸欠」、
「小型車両系建設機械」を「ユンボ」と打つ人のほうが多い。
だから `ALIAS` に**探すための言葉**を入れてある。

打ち方の揺れも吸う。

- 大文字小文字・全角半角（NFKC）
- **カタカナをひらがなに寄せる。**「サンケツ」と「さんけつ」で結果が変わらない
- 空白で区切った語は全部を含むもの（AND）。
  絞るために足した語で、かえって増えるのはおかしい

目印（slug）は探す対象に入れない。人が打つものではないうえ、
英字の切れ端が中で当たる（「EV」が `leveling` に当たっていた）。

見つからないときは、空で終わらせずに打ち直しのヒントと連絡先を出す。
打ち方が悪かったのか、本当に無いのかが分からないため。

## 持ち出す

**この目録は、いずれ単体で事業にする。そのとき丸ごと移せること。**

| | どこ |
| --- | --- |
| JSON | `/api/tokubetsu` |
| CSV | `/api/tokubetsu?format=csv` |
| コピー | `/owner` →「特別教育の目録」→「持ち出す」 |

- 列は**渡された一覧と同じ形**にそろえてある。行って戻れる
- CSV には BOM を付けている。無いと Excel が日本語を文字化けさせ、
  開いた人が「壊れている」と思って捨てる
- `src/content/tokubetsu.ts` は**何も import していない**。
  ファイルをコピーすれば、そのまま別の仕組みで動く（試験で見張っている）

### 確かめた印も、一緒に持ち出す

`hours_verified` を必ず付けて出す。

**出した先で「全部裏を取ってある」と誤解されると、
足りない時間の修了証が出る。** いま印が付いているのは2件だけ。

### なぜ誰でも読めるようにしているか

中身は**法令で決まっていて、誰でも読める**もの
（厚生労働省の規程と、労働局の一覧）。隠す理由が無い。
個人の情報も、値段も、社内の事情も入っていない。

## 増やし方

1. `/owner` の目録で、作るものを決める
2. **規程の条文を読む**（目録の「出典」から辿れる）。
   科目・細目・時間をそこから取る。まとめページの数字を写さない
3. `src/content/tokubetsu.ts` のその行に `checked: true` を付ける
4. 教材を `content/courses/` に置き、`courses.ts` に1行足す（docs/13）
5. 目録の行に `courseId` を書いてつなぐ
6. `npm run test:tokubetsu` で、時間が一致することを確かめる

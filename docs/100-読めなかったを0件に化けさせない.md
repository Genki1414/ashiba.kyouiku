# 100　「読めなかった」を「0件」に化けさせない（2026-09-09）

げんきさんの一言。

> 請求書で申し込むを押しても本部画面に請求書が出ない

---

## 1　何が起きていたか

きのう（docs/99）`orders` に `group_id` の列を足した。版は 0029。

**画面のコードは push で Vercel が勝手に出す。SQL は流すまで当たらない。**
つまり、しばらくのあいだ

    画面のコード = 0029 を前提
    データベース  = 0028 のまま

という組み合わせになる。この状態で本部の一覧は無い列を読みに行く。

    ERROR:  column "group_id" does not exist

0028 のままのデータベースを作って再現した。列は本当に無い。

## 2　本当の問題は、そこではない

断られること自体は、版を流せば直る。**悪かったのは、断られたことを
画面が「0件」として出していたこと。**

    const { data: orders } = await supabase.from("orders").select(...)
    //             ^ error を受け取っていない
    const ids = (orders ?? []).map(...)
    //                    ^ null → 空。以降ぜんぶ0件

これで何が起きるか。

| 本当のこと | 画面 |
| --- | --- |
| 売った注文が1件も無い | 0件 |
| データベースが断った | **0件** |

**同じ見え方になる。**だから、新しい請求書が出ないのではなく、
**前からある請求書まで丸ごと消えたように見えた。**
そして画面のどこにも理由が出ない。

### 数えた

`src/app/api` の中で、読み出しの `error` を受け取っていない所は **51か所**。
全部を直すのはやり過ぎなので、**お金の画面から**直した。

    src/app/api/owner/orders   本部の一覧
    src/app/api/owner/invoice  請求書
    src/app/api/owner/ledger   元帳
    src/app/api/order          申込み（版が古いときの直し方を出す）

断られたら、そう言う。直し方まで出す。

    注文を読めませんでした（column "group_id" does not exist）。
    データベースの版が古いときは、Supabase の SQL Editor に
    supabase/apply-all.sql を貼って実行してください。

`tests/api-shape.mts`（501件）に見張りを足した。
お金の画面がエラーを握りつぶしたら止まる。

## 3　げんきさんの操作

**Supabase の SQL Editor に `supabase/apply-all.sql` を貼って実行する。**

確認は `/setup` の「データベースの版」の行。
いま **0028 ／ 要る版 0029** と橙で出ている。流すと 0029 で緑になる。

## 4　あわせて入れたもの（もう一つの依頼）

> リクエストされたら担当者側の申し込み画面でリクエストありと表示
> さらに、講座単位でリクエスト◯件と表示

申込みの画面に出るようにした。

- 上に **「受けたいと送られています（6件）」**
- 講座ごとに **「リクエスト4件」** の札
- **送られている講座を、多い順に上へ出す。**73本あるので、
  下に埋もれると札を付けても見えない
- **押すと、その人数が入る。**1から数え直させない（あとから直せる）

数えるのは、自社宛の、まだ対応していないものだけ。
会社は画面から受け取らない（ログインしている担当者の会社を使う）。

### ここでも1つ落とした

返す側（`/api/order`）に `requests` を足しただけでは、**札が1つも出なかった。**
画面が受け取った返事を組み立て直すところ（`load()`）で落としていた。

    setSt({ company, unitPrice, orders, seats, codes, courses })
    //                                              ^ requests が無い

`api-shape.mts` は**この型の間違いのために作った試験**なので、
両側（返す側・受け取る側）を見る形で足した。

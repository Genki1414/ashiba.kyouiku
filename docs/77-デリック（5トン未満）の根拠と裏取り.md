## 2. 科目・範囲・時間（告示第3条のまま）

学科 **4科目 9時間**。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| デリツクに関する知識 | 種類及び型式／主要構造部分／作動装置／安全装置／ブレーキ機能／取扱い方法 | 3時間 |
| 原動機及び電気に関する知識 | 電気に関する基礎知識／電動機／開閉器、コントローラー等電気を通ずる機械器具／電路の点検及び補修／感電による危険性 | 3時間 |
| デリツクの運転のために必要な力学に関する知識 | 力(合成、分解、つり合い及びモーメント)／重心／荷重／ワイヤロープ、フツク及びつり具の強さ／ワイヤロープの掛け方と荷重との関係 | 2時間 |
| 関係法令 | 労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則及びクレーン則中の関係条項 | 1時間 |

実技 **2科目 4時間**（第3条第3項が第1条第3項を準用。「クレーン」を「デリツク」と読み替える）。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| デリツクの運転 | 重量の確認　荷のつり上げ　定められた経路による運搬　荷の卸し | 3時間 |
| デリツクの運転のための合図 | 合図の方法 | 1時間 |

**実技は事業者が自社で行う。**うちが出すのは学科だけ。
実技の手引きと実施記録の様式は `src/content/drill.ts` と `src/lib/drillRecord.ts` にある。

## 3. 字づかい

- **告示の字は「デリツク」**（大きい「ツ」）。科目名と中欄は告示のまま写した。
- **読み上げの言葉は「デリック」**にした。耳で聞く言葉だから。
- 「力(合成、分解、つり合い及びモーメント)」の括弧は、**告示のまま半角**。
  単元の見出しだけ全角にしてある（画面で読みやすいように）。

## 4. 科目2の中欄が、移動式クレーンと違うところ

ここを間違えると、法定の範囲の外の講座になる。

| | 中欄 |
|---|---|
| クレーン（規程第1条） | 電気に関する基礎知識／電動機／開閉器等／電路の点検及び補修／感電による危険性 |
| **デリック（規程第3条）** | **クレーンと同じ** |
| 移動式クレーン（規程第2条） | 内燃機関／蒸気機関／油圧駆動装置／感電による危険性 |

デリックは、**別置きのウインチを電動機で回す機械**だから電気の側になる（docs/69 §2）。
移動式クレーンの型をそのまま持ってくると、範囲の外になる。

## 5. この講座の軸（クレーンと同じにしなかったところ）

1. **控え索（ガイ）とアンカー。**
   デリックは工場から出てきた形のまま据える機械ではない。**現場で組み上げる。**
   マストを立てているのは控え索とアンカー、またはスチフレッグの脚。
   **だから倒れる。**科目1の「主要構造部分」を45分といちばん厚くしたのは、これが理由。
   力学（3-1）でも、控え索の力の分解を軸にした。
   「寝かせるとアンカーが抜ける／立てるとマストの足が沈む」を、計算ではなく言葉で教えている。

2. **運転する人から荷が見えない。**
   運転位置はウインチの所であって、マストの下ではない。
   だから合図が命になる。3-2（重心の振れ）、3-5（掛け方）、4-1（合図・離脱の禁止）で繰り返している。

3. **数が少ない機械。**
   隣の現場に聞ける人がいない。**自分の現場の一台を、自分で知るしかない。**
   1-1 で最初に、正直にそう言っている。

## 6. 条文で確かめていない番号（講座に書いていないもの）

**確かめた番号だけを書く**という決まりのとおり、次のものは**番号を書かず、中身だけ**教えている。
4-1 のナレーションでも、受講する人に「番号は確かめていない」と言っている。

- 定格荷重の表示等
- 過負荷の制限
- とう乗の制限
- 立入禁止（つり荷の下）
- 運転の合図
- 運転位置からの離脱の禁止
- 作業開始前の点検
- 暴風後等の点検
- 定期自主検査（1年以内ごとに1回・1月以内ごとに1回）
- **デリックの組立て・解体の作業**（作業指揮者、立入禁止、悪天候での中止）
- 就業制限（5トン以上は免許）
- 労働安全衛生規則第37条・第38条（特別教育の記録の3年保存）

**クレーン等安全規則のデリックの章（第2編第3章）の条文が手に入ったら、番号を入れる。**

## 8. 隣の資格

- **5トン以上のデリックの運転** → クレーン・デリック運転士免許
- **荷を掛ける** → 玉掛け（1トン未満は特別教育 `tamakake`、1トン以上は技能講習）
- **組立て・解体を仕切る** → この教育ではない。作業指揮者などの別の決まり
- **マストに登る** → 墜落制止用器具（`harness`）

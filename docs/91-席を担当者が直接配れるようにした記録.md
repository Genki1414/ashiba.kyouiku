# 91 席を担当者が直接配れるようにした記録（2026年9月7日・0028）

げんきさんの「リクエストから購入した席はリクエストを送ったユーザーに担当者が直接
席を配布できる（受講コード入力不要にする）／教育担当者が購入し、受講させるユーザーが
決まってる場合には教育担当者が受講ユーザーを指定することで受講ユーザー側は受講コードの
入力が不要になる／受講コード方式は万が一の為に残す」。

## 何が困っていたか

席を人に渡す道は1本しか無かった。

```
担当者がコードの文字を伝える → 受講者が /join で12文字を打ち込む
```

**誰に受けさせるかが決まっているとき、この打ち込みは要らない手間**で、
しかも間違いのもとになる。12文字を口頭やLINEで伝えれば、打ち間違い・伝え間違いが出る。
出れば「開かない」と言われて、担当者がもう一度調べることになる。

とくに**受講リクエストから買った席は、送ってきた本人に配るのが決まっている**。
そこを人の手で突き合わせる意味は無い。

## 作ったもの（0028 assign_seat）

担当者が「この人に、この講座の席」を選べば、その場で渡る。
受講者の画面には、次に開いたときからその講座が出る。**打ち込みは無い。**

押せる場所は2つ。

1. **受講リクエストの一覧** — 送ってきた人の行に「席を配る」
2. **名簿** — 「◯◯の席を配る（コード入力なし）」

どちらも、席が余っているときだけ出る。余っていなければ
「配れる席がありません。先に申し込んでください」と出して、申し込みへ回す。

## 渡さない相手（DBで止める）

画面の出し分けだけを頼りにしない。`assign_seat` が全部見る。

| 相手 | 理由 |
| --- | --- |
| **その会社に在籍していない人** | よその会社の人・辞めた人に渡ると、席が戻らないまま消える |
| **もうその講座の席を持っている人** | 席が1枚無駄になり、名簿にも同じ講座が2つ並ぶ |
| （よその会社が買った席） | 自社の注文からしか取らない |
| （空きが無い） | 黙って渡ったことにしない |
| （期限切れの席） | 渡した先で開かない |

配ったら、**その人のその講座の受講リクエストは対応済みになる**。
担当者に「対応済みにする」をもう一度押させない。

## 受講コードの方式は、そのまま残した

無くしていない。

- **その場に居ない人、まだ名簿に入っていない人**には、コードを渡すしかない
- **画面が動かないときの逃げ道**になる
- 取り消しも、いままでどおり（`releaseSeat`）。配り間違いで席が1枚死なない

`assign-seat.sql` の⑫で、**配る道とコードの道の両方が生きていること**を一緒に見ている。
`tests/api-shape.mts` でも、`/join` の入力欄・`redeem_seat`・`releaseSeat` が
消えていないかを見張っている。

## 見張り

`supabase/tests/assign-seat.sql`（**22件通過**）
上の表の全部と、「ログインした人から直に呼べない」「戻した席はまた配れる」。

`tests/api-shape.mts`
- `assign_seat` を呼んでいるか。**会社の番号を画面から受け取っていないか**
  （受け取ると、よその会社の席を配れてしまう）
- 断った理由をそのまま画面に出しているか
- 空きがあるときだけ出しているか、辞めた人・持っている人に出していないか
- 受講コードの道が消えていないか

`tests/e2e-admin.mjs`
- 席が2枚あるとき「席を配る」が出て、名簿にも出る。**辞めた人には出ない**
- 押すと「誰に・どの講座を」だけを送る。**会社の番号は送らない**
- 席が無いときは押しどころを出さず、「先に申し込んでください」と出す

## 直したこと

- `seats` に `created_at` は無い。古い順は**注文の日付**で見る（同じ注文の中はコード順）
- 名簿の押しどころは、**サーバが決めた講座（`st.course`）**を見る。
  画面の `courseId` はタブを押すまで空で、**講座が1つの会社ではタブが出ない**ので、
  そちらを見ると永久に出ない。実機で出ずに気づいた
- テスト同士がデータをぶつけていた。人を消す前に席を未使用に戻す
  （本番の道筋も同じ＝`release_seat`）。戻さずに消すと `seats.used_by` だけが
  null になって `seats_used_pair` が崩れ、削除そのものが通らない

# 116　下のタブを、貼り付けるのをやめた

2026-09-11。げんきさん

> また下部タブがずれる
> スクロールするとズレる
> 固定して

前の日に「タブ 固定された」と言ってもらったのに、また戻った。

## 前の当て方が、なぜ足りなかったか

`position: fixed` で画面の下に貼り付け、iOS 対策に描画層を切り出していた
（`translateZ(0)` と `will-change: transform`。2026-09-10）。

ところが iOS の惰性スクロールでは、**貼り付けた札の位置を決めるのが
本体ではなく合成側**になる。指を離したあとの慣性の間、本体の巻き取りに
札が追いつかず、画面の途中に取り残される。

小さくしても、層を切っても、**この道筋そのものは残る。**
当て方を強くしても、いつまた出るか分からない。

（手元のブラウザでは一度も再現できていない。iOS でだけ起きる。
　だから「直った気がする」で終わらせず、道筋ごと無くすことにした）

## 貼り付けるのをやめた

**本体（ページ）を一切スクロールさせない。**

```
外枠（.shell）  … 画面ぴったりの高さの縦並び
  ├ <main>     … ここだけが動く（overflow-y: auto）
  └ <nav>      … 並びのいちばん下に、普通に置く
```

札は動かないものの隣に置いてあるので、**ずれようがない。**
合成側の追いつき待ちも起きない。貼り付けていないので、
`position: fixed` にまつわる話が全部消える。

上に隙間（spacer）を作る必要も無くなった。札は本体の外ではなく、並びの中に居る。

### 効かせるのは、札を出す画面だけ

単元・修了試験・実務トレーニングは札を出さないうえ、
`window.scrollTo` で本体を動かしている（LessonClient・ExamClient）。
本体を止めると、そこが動かなくなる。

だから BottomNav が、出ている間だけ `<html>` に `data-shell="fixed"` を立てる。
画面を移ったら必ず外す。

### 気を付けたこと

- `min-height: 0` を `<main>` に入れる。
  無いと中身の高さぶんまで伸びて、はみ出した先が切れる
- **紙のときは必ず戻す。**画面のために `overflow: hidden` にしてあるので、
  そのまま刷ると請求書が1枚目で切れる

## 確かめたこと

`tests/nav-check.mjs` が4画面で測る。

```
/        position:static  下まで送ったあと 下端844/画面844  固定OK
         印:fixed 札:static 本体:hidden ／ 貼り付けていない OK
         ／ 本体のはみ出し 0px OK ／ 真ん中は最後まで送れた OK
         押す所 98×52px OK ／ 下に空けた分 10px OK ／ 札の高さ 63px
```

長い画面（特商法。73講座の値段が並ぶ、6005px）でも、
いちばん下まで送れて、最後の行が札の下に隠れないことを確かめた。
紙にしたときに本体が戻ることも確かめた。

見張り（api-shape）が、貼り付けに戻したら止める。

## 取得済みの講座を開いたときに、受講を勧めない

同じ日にもう1つ。

> 取得済みでも押すと講座リクエスト可能になるから、
> 取得済み資格はタップで開いたら取得済みの為受講不要などと表示する

一覧には「取得済」と出ていた。ところが押して開くと、受講コードが無いので
断りの画面になり、そこに**受講リクエストを送る札**が出ていた。
もう持っている資格を、会社の教育担当者に「受けたい」と頼めてしまう。
担当者の側では、要らない受講コードを買う話になる。

断りの画面ごと差し替えることにした（HeldInstead）。
「受講コードを入れてください」も出さない。持っている人にはコードの話が要らない。

### 「受講不要」と書く場所を、1つに決めた

2026-09-09 に「受講不要とは書かない」と決めてある。
受けるか受けないかを決めるのは本人と会社であって、こちらが言い切る筋合いではない。

一見ぶつかるが、立っている場所が違う。

| | 書き方 |
| --- | --- |
| 受けられる人（受講コードがある） | 持っていることだけ伝える。「もう一度受けることもできます」 |
| 受けられない人（コードが無い） | はっきり不要と書いて、リクエストを止める |

**HeldInstead だけが書いてよい。**ほかの画面に増えたら見張りが止める。

よそで取った資格は本人が登録するので、押し間違いがある。
黙って行き止まりにせず、マイページへ直しに行けるようにした。

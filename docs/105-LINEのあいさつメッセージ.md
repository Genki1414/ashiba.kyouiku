# 105　LINEのあいさつメッセージ

2026-09-09。げんきさんの依頼。

> あいさつメッセージ作成したい

## どこで設定するか

**アプリからは配れない。**リッチメニューは Messaging API で送れるが、
あいさつメッセージにその口は無い。LINE公式アカウントマネージャーで貼る。

`manager.line.biz` → その公式アカウント → ホーム → あいさつメッセージ

- 吹き出しは5通まで。1通500文字まで
- `{ユーザーのアカウント名}` でLINEの表示名が入る
- **友だち追加した瞬間に届く。**LINEログインのときに友だち追加した人にも届く
  （`bot_prompt=aggressive` で追加を勧めているため）

## 決めたこと

- **押す所を先に書かない。**何ができる所なのかを1通目で言い、
  2通目で下のメニューの使い方を書く。順番が逆だと、
  何の会社か分からないまま押させることになる
- **3つの立場で書き分ける。**コードをもらった人・これから申し込む人・
  続きから受ける人。現場では、この3つが同じトークに混ざって来る
- **修了証は「修了した講座の」と書く。**受ければもらえる、と読める書き方にしない
- 名前は正式なもの（足場屋革命／特別教育ドットコム）。略さない

## 特別教育ドットコム

1通目

```
{ユーザーのアカウント名}さん、友だち追加ありがとうございます。
特別教育ドットコムです。

労働安全衛生法で定められた特別教育と、職長・安全衛生責任者教育を、スマホで受けられます。業種は問いません。

現場の休憩中でも、家に帰ってからでも受けられます。途中でやめても、続きから再開できます。
```

2通目

```
下のメニューから進めます。

▼ 会社から受講コードをもらった方
「受講コード」を押して、コードを入力してください。すぐに始められます。

▼ これから申し込む方
「受講する」を押して、受けたい講座を選んでください。何名分でもまとめて申し込めます。お支払いは請求書（お振込み）です。

▼ 続きから受ける方
「マイページ」に、受けている講座と、修了した講座の修了証が並びます。
```

## 返事をどうするか

あいさつメッセージを出すと、そのまま返信してくる人が必ずいる。

- **応答モードが「Bot」のまま**だと、送られた言葉は自動応答に当たり、
  誰も読まない。読まないなら、あいさつ文に「送ってください」と書かない
- **「チャット」にする**と、LINE公式アカウントマネージャーの受信箱に溜まり、
  スマホのアプリ（LINE Official Account）で返せる。
  返す気があるときだけ、こちらにする

いまのあいさつ文には、返信を促す一文を入れていない。
受信箱を見る形が固まってから足す。

## まだやっていない

- `/api/line/webhook`（署名の確認つき）。これがあると、友だち追加のとき
  **その人に合わせたあいさつ**を出せる（例：受講コードを持っている人だけに
  「コードをお持ちですね」と出す）。いまは誰にでも同じ文
- LINE への通知（受講リクエスト・請求書・受講コード・修了証）

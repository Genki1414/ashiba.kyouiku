# 請求書を1枚に、そして残す

2026-09-09。げんきさんの実機（印刷プレビューの写真）から。
「請求書が1枚になってない」「請求書を発行すると過去の請求書が見れなくなるから、請求書ページ作って残して」

## 1枚に収まらなかった理由

画面は黒地・スマホ幅（`layout.tsx` の外枠 `max-w-md bg-bg`）。請求書の紙面（`.paper`）は
白地にしていたが、**外枠がそのまま紙に出ていた。**黒い枠の中に細長い請求書が縦に伸び、
振込先が2枚目に落ちた。

直し方は `globals.css` の `@media print` 1か所。
- `@page { size: A4; margin: 14mm }`。余白は紙で持つ（画面の padding は 0 に）
- 外枠（`.shell`）の `max-width` を外し、`html/body/.shell` を白地に
- `.tape` と `.noprint` は出さない
- `.paper` は `page-break-inside: avoid`、文字 12px

見張りは `tests/e2e-invoices.mjs`。Playwright で `page.pdf()` を作り、`/Type /Page` を数えて
**1枚**であること、印刷メディアで外枠が白地・幅なしになっていることを見る。

## 残す

ホームの「請求書が届いています」（`unpaidInvoices`）は**払っていないもの**しか出さない。
払った瞬間に開く道が消えた。経理に出すのは払ったあと。

- `/api/invoices`（GET）… ログインした人の注文と、その人の事業者の注文を全部。
  会社は画面から受け取らない。読めなければ 500 でそう言う（docs/100）
- `groupInvoices`（`src/lib/invoiceAccess.ts`）… 講座ごとの行を申込み（group_id）ごとに1件に。
  合計・人数は足す。状態は1行でも入金待ちなら入金待ち。発行日は最古、入金日は最新
- `/invoices` … 1回の申込みが1件。明細（足場3名 23,100円…）、合計、状態。
  **発行済みだけ「請求書を開く」**（`/invoice/<id>`）。未発行は「まだ発行されていません」。
  カード払いは「請求書はありません」
- 入口 … `/order` の「これまでの申込み」、買った側の請求書の画面、ホームの札（2件以上のとき）

本部側は `/owner` が全部の申込みを持っているので、そのまま。

# アーク溶接：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | アーク溶接等の業務に係る特別教育 |
| 対象 | アーク溶接機を用いて行う金属の溶接、溶断等の業務 |
| 学科 | **11時間**（4科目15単元）※**うちでいちばん長い学科** |
| 実技 | **10時間**。事業者が自社で行う |
| 合計 | 21時間 |

被覆アーク溶接（手溶接）、半自動（マグ・ミグ）、ティグ、アークエアガウジング。
**ガス溶接・溶断は別の資格**（ガス溶接技能講習等）。

## 実技（告示第4条第3項）

「アーク溶接装置の取扱い及びアーク溶接等の作業の方法について、**十時間以上**」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/arc/drill`）。5つの段取り（90／150／150／120／90）は**うちの案であって告示ではない。**
手引きに「**一度もアークを出させずに終わるのは実技にならない**」と書いた。

| 科目 | 単元 | 分 |

中欄の項目を単元にした。科目3は6時間あるので、**「溶接、溶断等の方法」を2単元（3-2・3-3）、
「災害防止」を2単元（3-6・3-7）**に分けた（scope は告示の中欄のまま）。

## 条番号を書いていないところ

安衛則の**アーク溶接等の各条**（交流アーク溶接機用自動電撃防止装置、規格に適合した溶接棒等のホルダー、
感電の防止、可燃物と消火設備、通風不十分な場所の換気、遮光保護具等、ガス等の容器の取扱い）は、
**条番号を条文で確かめていないので書いていない。**科目4は中身で教えている。

**特化則（溶接ヒューム）、じん肺法、酸欠則、消防法**も、条番号は書いていない。

教材の中の数字・事実で、原文で確かめていないもの：
- 交流アーク溶接機の無負荷電圧「60〜90ボルト程度」、アーク中「20〜40ボルト程度」（一般に教えられている値）
- 自動電撃防止装置の安全電圧「25ボルト以下」、遅動時間「1秒以内」（構造規格）
- 装置の使用義務の場所「船舶の二重底・ピークタンク等の著しく狭あいな場所」「高さ2m以上で囲い等の無い墜落の危険のある場所」（安衛則）
- アークの温度「数千度」（物理・一般に教えられている値）
- 溶接ヒュームのフィットテスト「1年以内ごとに1回」、金属アーク溶接等作業主任者（特化則。**令和3年4月からの規制、作業主任者は令和6年1月から**とされるが、施行日は未確認）
- 感電の電流の目安「10〜20mAで手が離せない」（一般に教えられている値）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。
**特に溶接ヒュームの規制は新しく、施行日と作業主任者の扱いは条文で確かめる必要がある。**

## 例の書き方

docs/19 ⑤。アーク溶接をするのは、
鉄工・製缶、建設（鉄骨・設備・配管）、造船、自動車の整備と製造、農機の修理、プラントの保全、
橋梁、タンク、金属加工、リサイクル、鉄道の車両、学校の実習、自治体の施設の修繕。
**溶接をする仕事ぜんぶ。**足場屋の例は入れていない。

事例23件：風の中の半自動で内部欠陥（鉄骨）／汗と狭所で感電死（プラント保全）／
エンジン溶接機で一酸化炭素中毒（鉄工）／接地せず漏電した外箱（金属加工）／
装置を外して狭所で感電死（造船）／装置が効かず点検もなし（プラント保全）／
母材の上のホルダーから火災（鉄工）／帰線を足場に取って離れた所で火災（鉄骨）／
鉄板の裏に落ちたスパッタで翌日火災（金属加工）／濡れた手袋で感電（設備）／
塗装の上から溶接して有害ガス（鉄工）／空のドラム缶で爆発（リサイクル）／
ガウジングの火花が下の階へ（鉄骨）／アークストライクから割れ（橋梁）／
湿った溶接棒で二度手間（製缶）／帰ったあとに全焼（設備工事）／
通行者が電気性眼炎（製造）／高所で感電して墜落死（鉄骨）／
めっき鋼材で金属熱（鉄工）／シールドガスでピット酸欠（プラント保全）／
溶接ヒュームの規制を知らず是正勧告（製缶）／ガス溶接の資格なし（鉄工）／
教育なしの応援者が感電（自動車整備）。

## 1. 中身が法定時間に足りない単元が16あった（直した）

教材の見積り（budget）は、教材を作ったときに**手で書いた数**だった。
台本をあとから足したり削ったりすると、その数はずれる。ずれたまま、
**法定時間ぶんの中身が無い単元が16残っていた。**

数え方（もとからの決まり）

| もの | 数え方 |
| --- | --- |
| ナレーション | 1分あたり300字 |
| 図解 | 図解ごとの `min` の合計 |
| 事例 | 1件5分 |
| 確認問題 | 1問0.35分 |

足りなかったのは、**いちばん最初に作った二本だけ**だった。

| 講座 | 単元 | 前 | 法定 | 不足 |
| --- | --- | --- | --- | --- |
| 足場（ashiba） | 1-2 / 1-3 / 1-4 / 3-1 / 3-2 / 3-3 / 4-1 / 4-2 | 19.6〜59.1分 | 20〜60分 | 0.2〜1.2分 |
| 職長（shokucho） | 2-1 / 2-2 / 3-1 / 3-2 / 3-3 / 4-1 / 6-1 / 6-2 | 43.1〜71.9分 | 45〜75分 | 0.8〜4.0分 |

**足りないぶんは、水増しではなく中身で埋めた。**
職長には、教えたことが入ったか確かめる方法、年の離れた人・言葉が通じにくい人への
教え方、指示の出し方と見回りのしかた、危ない時間帯、手の打ち方の順番（無くす→囲う→
決まり→保護具）、残った危なさの伝え方、暫定と恒久、打った手を一か月後に見に行くこと、
異常の四つの出方、連絡の順番、再開を決めるのは誰か、連絡調整の場の回し方、
安全施工サイクルが形だけになる三つの理由——を足した。
足場には、組立図と現物が食い違ったとき、一段ごとの確かめ、点検の順路と記録の五項目、
登り桟橋と朝顔の点検、親綱のたるみ、二次災害、器具の保管、記録を本人にも渡すこと——を足した。

直したあとは、**どの単元も法定＋0.3分以上**の余裕を持たせた。
ぎりぎりだと、あとで一行削っただけでまた割る。

### もう起きないようにしたこと

- `scripts/build-course.ts` と `scripts/build-shokucho.ts` が、**budget を中身から数え直す**。
  手で書いた数は読まない。**法定を割ったら、そこで組み立てを止める。**
- `tests/narration.ts` が、**全73講座905単元**について同じことを見る。
  足場のように、生成器を通さず直に持っている講座も、ここで捕まる。

## 7. 職長の図解を、話に合わせて置き直した

職長の図解182枚は `at` を持っておらず、**単元を図解の数で均等に割って**出していた。

（図解が画面に出ている行数は、最低8行を保つ。2行だと読む前に消える）。

## 8. 職長の実技の関門（drill.sql）

`supabase/tests/drill.sql` の「①単元の合計＝講座の総時間」が、職長だけ通らなかった。
**職長は法定14時間のうち45分が討議**で、これは各自で見る単元ではなく集合でやるもの。
だから 単元795分 ＋ 討議45分 ＝ 総時間840分 になる。
関門を「①**単元の合計＋討議**＝講座の総時間」に直した。
特別教育に討議は無いので、この差が出るのはこの1講座だけ。

## 9. 全部の特別教育を探して突き合わせた——ここまでは言えて、ここからは言えない

**言えること。**
目録66行は、**全部が条文（省令または告示）で時間を確かめてあり、全部が講座になった**。
目録の根拠に出てくる号と、講座の根拠に出てくる号は、**上の1行を直して、すべて一致**した。

**言えないこと。**
**安衛則第36条そのものを、条文で数え直してはいない。**
この環境からは、e-Gov も厚労省も中災防も、**組織の決まりで全部つながらない**
（EGRESS_BLOCKED。回り道はしない）。

うちの目録が根拠に挙げている安衛則第36条の号は、枝番を含めて **35種類**（41行）。
検索で出てきた中災防のまとめは「第36条は**全49業務**」と書いている。
**この差が、本当に抜けなのか、それとも数え方の違いなのかが、条文を見ていないので言えない。**

差の候補（うちの目録がどの行でも挙げていない号）：
**第12号・第14号〜第26号・第28号・第35号・第36号・第38号**

見立て（**まだ確かめていない**）：この多くは、目録が**自分の省令のほうを根拠に挙げている
25行**（クレーン則・ボイラー則・ゴンドラ則・高圧則・電離則・酸欠則・四アルキル鉛則・除染則）
に対応していて、抜けではないのではないか。

**げんきさんへのお願い：安衛則第36条の全文（一条だけ）。**
これがあれば、49（または現行の数）と、うちの66行を一号ずつ突き合わせて、
「本当に全部そろっている」と言い切れる。**それまでは言い切らない。**

## 1. いちばん大事 — 除染等業務の、業務区分ごとの時間が分かった

**「除染等業務＝全員一律」にしてはいけない、と言われていたところ。**
告示第2条（学科）と第3条（実技）に、**区分ごとの行が並んでいた。**

| 業務区分 | 学科 | 実技 | 合計 |
|---|---|---|---|
| 土壌等の除染等 | **240** | **90** | 330 |
| 除去土壌の収集等 | **240** | **90** | 330 |
| 汚染廃棄物の収集等 | **240** | **90** | 330 |
| **特定汚染土壌等取扱業務** | **210** | **60** | **270** |
| **特定汚染土壌等取扱業務（線量管理外）** | **210** | **60** | **270** |

**時間の形は二つしかない。**330分と270分。

### どこで差が付くか

**学科の三つ目「除染等作業に使用する機械等の構造及び取扱いの方法に関する知識」。**

- 土壌等の除染等／除去土壌の収集等／汚染廃棄物の収集等 … **1時間**
  （中欄も「機械等の**構造及び取扱いの方法**」）
- **特定汚染土壌等取扱業務 … 30分**
  （中欄が「機械等の**名称及び用途**」だけ。科目名にも
  「特定汚染土壌等取扱業務に労働者を就かせるときは、
  特定汚染土壌等取扱作業に使用する機械等の名称及び用途に関する知識に限る。」と書いてある）

**実技も、90分と60分で差が付く。**
特定汚染土壌等取扱業務の実技の中欄には、**「機械等の取扱い」が入っていない。**

**理由は分かる。**特定汚染土壌等取扱業務は「汚染された土をさわる仕事」であって、
除染そのものの機械を回す仕事ではない。だから機械のぶんが短い。

### 「線量管理外」とは

**平均空間線量率が2.5マイクロシーベルト毎時以下の場所でだけ、
特定汚染土壌等取扱業務をする人**（告示の言い方で「線量管理外特定汚染土壌等取扱事業者」）。

**時間は同じ210分／60分だが、範囲（中欄）が短い。**

- 科目1：**「被ばく限度」まで。**被ばく線量測定の方法・記録の確認が入らない
  （線量管理をしないから）
- 科目2：**「外部放射線による線量当量率の監視の方法」が入らない**
- 実技：**線量当量率の監視が入らない**

### 目録への入れ方

行そのものの `gakkaMin`／`jitsugiMin` は**240／90**（区分のうちいちばん長いもの）。
**区分ごとの時間は `variants` に5件、全部入れた。**

**短い区分の人に長い教育をしても法定は満たすが、逆は満たさない。**
だから迷ったら長いほうを出す。ただし**修了証には、受けた区分の時間を書くこと。**

**講座にはまだしていない。**区分ごとに組む仕組みがまだ無いため。
テストで「業務区分を持つ行は講座にできない」ようにしてある。

## 2. no.62 特定線量下業務 — 確定（区分は無い）

告示第5条。**学科だけ、3科目で150分。**元の目録と一致。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| 電離放射線の生体に与える影響及び被ばく線量の管理の方法に関する知識 | 電離放射線の種類及び性質　電離放射線が生体の細胞、組織、器官及び全身に与える影響　被ばく限度及び被ばく線量測定の方法　被ばく線量測定の結果の確認及び記録等の方法 | 一時間 |
| 放射線測定の方法等に関する知識 | 放射線測定の方法　外部放射線による線量当量率の監視の方法　異常な事態が発生した場合における応急の措置の方法 | 三十分 |
| 関係法令 | 労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則及び除染則中の関係条項 | 一時間 |

**除染等業務（no.61）と違って、業務区分が無い。**そのまま1本の講座にできる。

根拠は**除染則第25条の8第1項／規程第4条・第5条。**

### 除染則の正式名称

> **東日本大震災により生じた放射性物質により汚染された土壌等を除染するための業務等に係る
> 電離放射線障害防止規則**（平成23年厚生労働省令第152号）

長いので告示は「除染則」と略している。**電離則（電離放射線障害防止規則）とは別の省令。**
うちの目録は、前は告示しか書いていなかったので、省令と条まで入れた。

## 3. no.43 四アルキル鉛等 — 確定

**四アルキル鉛中毒予防規則（昭和47年労働省令第38号）第21条第1項**
**／四アルキル鉛等業務特別教育規程（昭和47年労働省告示第125号）**

**学科だけ。6科目が1時間ずつで360分。**元の目録と一致。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| 四アルキル鉛の毒性 | 四アルキル鉛の性状　四アルキル鉛中毒の病理及び症状 | 一時間 |
| 作業の方法 | 四アルキル鉛等業務に係るドラムかん及び設備の取扱い方法 | 一時間 |
| 保護具の使用方法 | 四アルキル鉛等業務に係る保護具の種類、性能及び使用方法 | 一時間 |
| 洗身等清潔の保持の方法 | 洗身、保護具の洗浄及び身体等の清潔の保持の方法 | 一時間 |
| 事故の場合の退避及び救急処置の方法 | 合図又は警報の内容及び退避の場所　除毒剤、拡散防止剤及び補修剤の使用方法 | 一時間 |
| その他四アルキル鉛中毒の防止に関し必要な事項 | 労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則及び四アルキル鉛中毒予防規則中の関係条項　四アルキル鉛中毒を防止するため当該業務について必要な事項 | 一時間 |

**この告示には条が無い。**一つの表だけでできている。だから根拠に条を書いていない。

### 講座を作るときの軸

**中欄に「洗身」「保護具の洗浄」「身体等の清潔の保持」で丸1時間ある。**
**四アルキル鉛は、皮膚から入る。**だから、作業そのものより「終わったあとの落とし方」に
同じだけ時間を取ってある。ここを軸にする。

**「ドラムかん」が中欄に名指し**なのも、この物質の扱われ方（ドラム缶で運ばれる）を
そのまま書いているため。

## 4. 目録に足した仕組み

`variants` を、名前だけの並びから**時間を持てる形**に変えた。

```
variants?: { name: string; gakkaMin?: number; jitsugiMin?: number; note?: string }[]
```

### 見張り（tests/tokubetsu.ts）

- **区分ごとの時間が分かっていない行**（no.50）は、一つの時間の確かめた印を付けない
- 区分の時間は、**全部入っているか、全部入っていないか**（半分だけは無し）
- **行の学科・実技は、区分のうちいちばん長いもの**（短いほうを書くと足りない紙が出る）
- 区分の学科が0分でない
- **業務区分を持つ行は、まだ講座にしない**

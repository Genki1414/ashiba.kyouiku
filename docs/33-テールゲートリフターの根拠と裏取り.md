# テールゲートリフター：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | テールゲートリフターの操作の業務に係る特別教育 |
| 対象 | 貨物自動車の荷台後部に付いた昇降装置（パワーゲート）を操作して荷を積み卸しする業務 |
| 学科 | **4時間**（3科目7単元） |
| 実技 | **2時間**（事業者が自社で行う） |
| 合計 | 6時間 |
| いつから | **2024年2月1日**（令和5年厚生労働省告示第104号で規程第7条の4を追加。改正文で確認） |

操作する人は全員。ドライバーも、倉庫の人も、配送先でスイッチを押す人も。雇っている形は関係ない。

## 実技（告示第7条の4第3項）

「テールゲートリフターの操作の方法について、**二時間以上**」。科目は1つ、表は無い。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/tailgate/drill`）。3つの段取り（30／50／40）は**うちの案であって告示ではない。**

## 単元の割り付け（学科240分・7単元）

| 科目 | 単元 | 分 |
| --- | --- | --- |
| 1（90分） | 1-1 種類、構造及び取扱い方法／1-2 点検及び整備の方法 | 50／40 |
| 2（120分） | 2-1 荷の種類及び取扱い方法／2-2 台車の種類、構造及び取扱い方法／2-3 保護具の着用／2-4 災害防止 | 35／30／20／35 |
| 3（30分） | 3-1 法、令及び安衛則中の関係条項 | 30 |

中欄の項目をそのまま単元にした（科目1が2つ、科目2が4つ）。

## 条番号を書いていないところ

安衛則の**貨物自動車の荷役の各条**（昇降設備＝最大積載量2トン以上、保護帽＝同、
作業指揮者＝一つの荷が100キロ以上、テールゲートリフター使用時の措置＝人を乗せて昇降させない、
運転者が離れるときの措置）は、**条番号を条文で確かめていないので書いていない。**科目3は中身で教えている。
昇降設備・保護帽の「2トン以上」は2023年の改正で広がった値として教えているが、改正文そのものは未確認。

特別教育の記録の3年保存も、同じ理由で条番号を書いていない。

告示の附則にある経過措置（施行前から業務に就いていた人の科目の省略）は、条文で確かめていないので教材に入れていない。

## 値段（2026年9月2日）

| | |
| --- | --- |
| よその値段 | **まだ調べていない** |
| **ここ** | **5,000円（税抜）＝ 5,500円（税込）** |

学科4時間。足場（3時間・4,500円）より1時間長く、実技の手引きが付く。
宅配・配送の会社が人数分まとめて買う教育なので、フルハーネス（6,000円）より下に置いた。
変えるときは `SEAT_UNIT_PRICE_TAILGATE`。

## 例の書き方

docs/19 ⑤。テールゲートリフターを使うのは、
宅配・路線便、引越し、飲料・食品の配送、家電・家具の配送、リネン、医薬品卸、
建材の配送、廃棄物の収集、農産物の集荷、イベント機材、建設の資材搬入。
**運送だけでもない。荷を運ぶ会社ぜんぶ。**足場屋の例は入れていない。

事例13件：止めていない台車が転がった（飲料）／ほか科目1の3件（宅配・引越し・路線便・宅配の集荷）／
点検表に「良」と書いてホースが破れた（路線便）／止まった機械に手を入れた（宅配）／
重さを確かめずに載せたパレット（建材）／固定しない冷蔵庫（家電）／扉を開けた瞬間に台車（食品）／
ストッパーを上げずに載せた（リネン）／保護帽を被らずに荷台から（引越し）／
プラットフォームに乗って落ちた（廃棄物）／閉じるときに手伝いの手（イベント機材）／
教育を受けていない新人（宅配）。

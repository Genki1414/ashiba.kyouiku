## ① 月別（全体・クーポンごと・支払先ごと）

広告費は**月ぎめで払う。**「今月いくら振り込むのか」が1つの数字で要る。
これまでは、始めてからの通算しか出ていなかった。

3か所に畳んで置いた。

| どこ | 何のため |
| --- | --- |
| 全体 | その月に、広告費がいくら出たか |
| 支払先ごと | **その先に、その月いくら払うか**（請求のもと） |
| クーポン1枚ごと | どのクーポンが、いつ効いたか |

畳んである。開くのは、月を締めるときだけ。

### 月の切れ目は、日本の時計で決める

使った日は、データベースには**世界標準時**でしまってある。
そのまま月で切ると、こうなる。

```
10月1日 0時30分（日本）＝ 9月30日 15時30分（世界標準時）
                          → 9月に入ってしまう
```

1件でも落ちれば、払う額が変わる。`monthKeyJst()` で日本の日付に直して
から切る。境目は tests/coupon.ts が見ている（月初の未明・月末の夜・年またぎ）。

### 数えるのは1か所だけ

サーバ（`/api/owner/coupons`）で数えて、画面はそれを並べるだけ。
画面で足し直すと、**同じ月なのに場所によって違う額**が出る。

並びも1つの部品（`Months`）にした。3か所で同じ形。
別々に書くと、片方だけ列が増えて読み比べられない。

**入金済みと入金待ちは、行を分けたまま。**足した額は、どこにも出さない。
足すと払い過ぎになる。

## ② コードのコピー

クーポンのコードは、LINE や電話で相手に伝えるもの。
打ち直すと `O` と `0`、`I` と `1` で必ず間違える。

`CopyBtn`（新）を1つ置いた。ホーム画面のアプリに入るコードにも
同じものがあったので、そちらと同じ作りに揃えてある。

写せない相手（古いブラウザ・安全でない接続）には、**黙って失敗させない。**
「長押しで選んでください」と出す。

## ③ 配るためのクーポン画像

紹介してくれる団体さんに、LINE やメールでそのまま渡せる絵を作る。

1200 × 630。貼ったときに切られない形。
描くのはブラウザの中だけで、**サーバは通さない**（置いておく必要が無い）。

載せるもの　　… 店の名前・値引き・クーポン名・コード・期限・入れる場所
載せないもの　… **広告費の率と支払先**（こちらの取り分。相手が読む）
　　　　　　　　利用回数の上限（煽る作りにしない。上限はその場で断る）

期限が無いときも「期限なし」と書く。空欄だと「切れているのでは」と
問い合わせが来る。

見張り（api-shape）が、絵に `reward` `partner` `maxUses` の字が
入っていないことを見ている。

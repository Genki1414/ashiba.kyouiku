# 高圧・特別高圧電気取扱業務に係る特別教育 — 根拠と裏取り

作った日：2026年9月3日
講座の目印：`kouatsu`
仕様の正本：`src/content/kouatsu.ts`

---

## 1. 何という教育か

**高圧・特別高圧電気取扱業務に係る特別教育**

対象は、安衛則第36条第4号のうち
**高圧若しくは特別高圧の充電電路又は当該充電電路の支持物の、敷設、点検、修理又は操作の業務**。

「**又は当該充電電路の支持物**」が入っていることに注意。
電柱、鉄塔、がいしを支える物の作業も対象になる。
充電電路そのものを触らなくても、支持物の作業ならこの教育が要る。

**うちで最長の学科（11時間）。実技は15時間で、うちで最長。**

| | 告示 | 学科 | 実技 |
|---|---|---|---|

| 低圧 | 第6条（`teiatsu`） | 7時間 | 7時間（開閉器の操作のみは1時間以上） |

## 4. 実技（告示第5条第3項）

> 第一項の実技教育は、高圧又は特別高圧の活線作業及び活線近接作業の方法について、
> **十五時間以上**（**充電電路の操作の業務のみを行なう者については、一時間以上**）行なうものとする。

**15時間。ただし、充電電路の操作の業務のみを行う者は1時間以上。**
低圧（第6条）の「開閉器の操作の業務のみを行なう者は一時間以上」と同じ作り。

どちらに当たるかは**業務の中身で決まる**。清掃や端子の締付けもするなら15時間。
実技の記録に、**15時間か1時間かと、業務の範囲**を書くようにしている。

事業者が自社で行う。うちが出すのは学科だけ。
実技の手引き（うちの案）と実施記録の様式を `/edu/kouatsu/drill` から印刷できる。

## 5. 低圧（規程第6条）との違い

**単に電圧が高いだけではない。中欄の項目そのものが違う。**

| | 高圧・特別高圧（第5条） | 低圧（第6条） |
|---|---|---|
| 科目1の中欄 | 危険性／**接近限界距離**／短絡／漏電／接地／**静電誘導**／電気絶縁 | 危険性／短絡／漏電／接地／電気絶縁 |
| 科目2の中欄 | **発電設備**／**送電設備**／配電設備／変電設備／**受電設備**／電気使用設備／保守及び点検 | 配電設備／変電設備／配線／電気使用設備／保守及び点検 |
| 科目3の中欄 | 保護具／防具／器具／**活線作業用装置**／検電器／**短絡接地器具**／その他／管理 | 保護具／防具／器具／検電器／その他／管理 |
| 科目4の中欄 | 防護／絶縁保護／**器具及び装置の取扱い**／**安全距離の確保**／停電電路に対する措置／**開閉装置の操作**／作業管理／救急処置／災害防止 | 防護／絶縁保護／停電電路に対する措置／作業管理／救急処置／災害防止 |
| 科目4の時間 | **5時間** | 2時間 |
| 学科の合計 | **11時間** | 7時間 |
| 実技 | **15時間**（操作のみ1時間以上） | 7時間（開閉器の操作のみ1時間以上） |

高圧で足されている項目は、**「触らなくても飛ぶ」ことから来ている**。
接近限界距離、静電誘導、活線作業用装置、短絡接地器具、安全距離の確保。
この五つを講座の軸にした。

## 6. 単元の割り付け

**中欄の項目の数だけ単元を作った。**低圧（`teiatsu`）と同じ作り。

- 科目1（90分・**7単元**）… 危険性20／接近限界距離15／短絡12／漏電11／接地12／静電誘導10／電気絶縁10
- 科目2（120分・**7単元**）… 発電15／送電15／配電20／変電15／受電25／電気使用15／保守及び点検15
- 科目3（90分・**8単元**）… 保護具15／防具12／器具12／装置12／検電器12／短絡接地器具12／その他8／管理7
- 科目4（300分・**9単元**）… 防護40／絶縁保護40／器具及び装置の取扱い40／安全距離35／停電電路45／開閉装置30／作業管理25／救急処置25／災害防止20
- 科目5（60分・**1単元**）

合計 **32単元・660分**。うちでいちばん単元が多い。

### 実技の手引き（うちの案・900分＝15時間）
1. 安全作業用具の点検と、身に着ける順（120分）
2. 接近限界距離と、安全距離の取り方（120分）
3. 充電電路の防護（絶縁用防具の取付けと取外し）（150分）
4. 停電作業（開閉装置の操作から短絡接地まで）（240分）
5. 活線作業用器具・活線作業用装置の取扱い（150分）
6. 作業管理と、感電したときの救急処置（120分）

**充電したままの設備で練習させないこと**を、手引きの「してはいけないこと」に書いた。

## 7. 講座の軸にした四つ

1. **触らなくても飛ぶ** — 接近限界距離が守るもので、手袋が守るものではない
2. **段取りは五つ** — 停電 → 防護 → 距離 → 装置 → **やらない**（五つ目がある）
3. **検電と短絡接地を省かない** — 検電器の「反応しない」は停電か故障か区別できない。
   自己点検 → 検電 → もう一度自己点検。短絡接地は**接地側が先、外すのは電路側が先**
4. **止めたことを責めない現場を作る** — 監視人が止めたら、理由を聞く前に止める

## 8. 条番号を書いていないところ

docs/19 の決めごとどおり、**条文で確かめた番号だけ書く。**
書いたのは **法第59条第3項／安衛則第36条第4号／規程第5条** の三つだけ。

**番号を書かずに中身だけ教えているもの**（科目5）：

- 電気機械器具の**囲い等**（充電部分に人が触れないように囲うか、絶縁で覆う）
- 電気機械器具の**操作部分の照度**
- **停電作業を行う場合の措置**
  - 開路した開閉器に施錠するか、通電禁止の表示をするか、監視人を置く
  - 電力ケーブル・コンデンサを有する場合は残留電荷を確実に放電させる
  - 高圧・特別高圧のときは検電器具で停電を確認し、短絡接地器具で確実に短絡接地する
- **断路器等の開路**（負荷電流を遮断するためのものでない断路器は、負荷電流を遮断した後でなければ開路してはならない）
- **高圧活線作業**（絶縁用保護具の着用、または活線作業用器具・装置の使用）
- **高圧活線近接作業**（絶縁用防具の装着、または絶縁用保護具の着用）
- **特別高圧活線作業・活線近接作業**（接近限界距離の保持、または活線作業用装置の使用）
- **工作物の建設等の作業を行う場合の感電の防止**（移設・囲い・防護具、できないときは監視人）
- **絶縁用保護具等の定期自主検査**（6か月以内ごとに1回の耐電圧試験、記録は3年間保存）
- **電気工事の作業を行う場合の作業指揮者**
- **電気機械器具等の使用前点検**
- **就業制限と特別教育**、**特別教育の記録の3年保存**
- **高圧・特別高圧の区分の数字**（交流600ボルト超／直流750ボルト超〜7000ボルトが高圧、7000ボルト超が特別高圧）
  … 電気設備に関する技術基準の定めによるもので、**安衛則の条番号としては確かめていない**
- **接近限界距離の具体的な数値**（1万ボルト以下20センチ、2万ボルト以下30センチ、6万ボルト以下50センチ）
  … 労働局・中災防の資料に基づく目安として教えている。**条番号は確かめていない**
- 電気事業法（電気主任技術者）、電気工事士法（第一種電気工事士）の各条

**条番号が確かめられたら、ここに足して、単元の中でも番号を出す。**

**12,000円（税抜）＝ 13,200円（税込）。うちでいちばん高い。**

- **よその値段はまだ調べていない。**
- 学科11時間はアーク溶接（9,000円）と同じ長さだが、
  実技が15時間（アーク溶接は10時間）で、扱う設備も器具も別物。
- 低圧（7時間・7,000円）の上に、はっきり置いた。
- **充電電路の操作のみを行う人**は実技1時間だが、**学科は同じ11時間**なので値段は分けていない。

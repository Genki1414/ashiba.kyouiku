# 108　ホームと下の札を重ねない

2026-09-10。げんきさん。

> ホームと下部タブで重複するものはホームに出さない

## 何が重なっていたか

画面の下には、いつも4つまでの札が出ている（`BottomNav`、2026-09-09）。
ホームにも、同じ行き先の札が並んでいた。

| 行き先 | 下の札 | ホーム |
| --- | --- | --- |
| `/me` マイページ | ◉ マイページ | 「マイページ」の札／**帯の名前**も押せた |
| `/admin` 受講管理 | ▦ 受講管理 | 「受講管理」の札 |
| `/owner` 運営 | ▦ 運営 | 「運営管理」の札 |

マイページに至っては、1画面に**3つ**入口があった。
現場の方は、どれを押せばいいのか押すまで分からない。
どれを押しても同じ所に着くのだが、**それは押した人にしか分からない。**

## どう直したか

ホームは、**下の札に出ていないものだけ**を出す。

決める所は `src/lib/nav.ts` の1か所にした。`BottomNav` はそれを並べ、
ホーム（`HomeCards`）は `inNav()` で聞いて消す。
**2か所に書かない。**書くと、片方だけ直したときにまた重なる。

帯（`AccountBar`）の名前は、押せないようにした。
あそこは「いま誰として使っているか」を言う所で、行き先ではない。
ログアウトはそのまま。

## 消さずに、出ていないときだけ出す

立場によって、下の4つ目が変わる。

| 立場 | 下の札の4つ目 | ホームに残る札 |
| --- | --- | --- |
| 受講者 | なし | （なし） |
| 教育担当者 | 受講管理 | なし |
| 本部を兼ねる人 | 運営 | **受講管理** |

本部を兼ねる人の下の札は「運営」だけなので、受講管理は重なっていない。
ここで決め打ちに消すと、**ホームから受講管理へ行く道が無くなる。**

## 講座（`/edu`）はどうか

ホームに `/edu` の札は無い。ホームの札は各講座へ直接飛ぶ
（`/edu/ashiba` など）ので、重なっていない。
一覧そのものは下の札から開く。

## 会社の名前

「マイページ」の札には、在籍している会社の名前が出ていた。
札を消したので、そこは見えなくなる。会社の名前はマイページに出る
（下の札から1タップ）。会社とつながっていない人・許可待ちの人には、
これまでどおりホームに札が出る（`home-join` / `home-pending`）。

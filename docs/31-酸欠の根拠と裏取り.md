# 酸素欠乏・硫化水素危険作業（第2種）の特別教育：根拠と裏取り

docs/19 の手順①の記録。**確かめたことと、まだ確かめていないことを分けて書く。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方（ここでの） | **酸素欠乏・硫化水素危険作業に係る業務に係る特別教育** |
| 一覧での行 | 44 第1種酸素欠乏危険作業に係る業務／45 第2種酸素欠乏危険作業に係る業務 |
| 対象 | 酸素欠乏危険場所（令別表第6）における作業。第2種は硫化水素のおそれもある場所 |
| 学科 | **5時間30分** |
| 実技 | **無い** |

> ### 第2種だけ作る
>
> 酸欠則第12条は、第1種の5科目を第2種に準用し、「酸素欠乏」を「酸素欠乏等」、
> 「酸素欠乏症」を「酸素欠乏症等」と読み替える。科目も時間も同じで、硫化水素が乗るだけ。
> **第2種を受ければ第1種の業務にも就ける**（公開講習は皆「酸素欠乏・硫化水素危険作業特別教育」＝第2種で出している）。
> だから、一覧の 44・45 の両方を、この講座1つに当てる。
>
> ### 実技が無い
>
> 石綿・粉じんと同じで、**この仕組みだけで修了証まで出せる。** `gate` は付けない。

## 根拠

| | | 確認 |
| --- | --- | --- |
| 法 | 労働安全衛生法 第59条第3項 | 済み（他の講座と同じ） |
| 則 | 労働安全衛生規則 第36条（酸素欠乏危険場所における作業に係る業務） | **号番号は未確認**。だから basis に号を書いていない |
| 義務づけ | **酸素欠乏症等防止規則 第12条** | 済み（条文の中身で確認。5科目と第2種への準用・読み替え） |
| 科目と時間 | **酸素欠乏危険作業特別教育規程（昭和47年労働省告示第132号）** | 告示の名前と番号は済み（厚労省の頁の題名）。**条番号（第2条／第3条）は未確認** |

渡された一覧は「安全衛生特別教育規程」と書いてあったが、**酸欠の告示は別**
（酸素欠乏危険作業特別教育規程）。粉じん・石綿と同じ種類の取り違え。直した。

酸欠則の**ほかの条**（測定・換気・作業主任者・退避・救助・診察 など）は条番号を確かめていない。
講座の中では条番号を書かず、**中身だけ**教えている（5-3 で「条番号ではなく中身で覚える」と言っている）。

## 科目と時間

| # | 科目（酸欠則第12条の字） | ここで割った範囲 | 時間 | 範囲の確認 |

| 2 | 酸素欠乏症等の症状 | 酸素欠乏症の症状／硫化水素中毒の症状 | **1時間** | **未確認** |
| 3 | 空気呼吸器等の使用の方法 | 空気呼吸器等の種類及び構造／空気呼吸器等の使用の方法及び点検 | **1時間** | **未確認** |
| 4 | 事故の場合の退避及び救急そ生の方法 | 事故の場合の退避の方法／救急そ生の方法 | **1時間** | **未確認** |
| 5 | その他酸素欠乏症等の防止に関し必要な事項 | 酸素及び硫化水素の濃度の測定の方法／換気の方法／作業の方法及び関係法令 | **1時間30分** | **未確認** |

科目名5つと時間（1／1／1／1／1.5＝5時間30分）は、酸欠則第12条の条文と、
中小建設業特別教育協会・新潟ウェルネス・東京技能講習協会・コマツ教習所・CIC で一致。

> ### 中欄（範囲）は全部うちで割ったもの
>
> 告示の中欄の字は、検索では出てこなかった（検索の回数の上限に当たった）。
> `src/content/sanketsu.ts` の scope は、公開講習の章立てと酸欠則の義務の並びから、うちで割った。
> **告示の表の写真が撮れたら、5科目とも中欄を突き合わせる。食い違えば告示が正しい。**
> 中欄の字が変わっても、単元の中身は変わらない（scope の字と単元の当て方を直すだけ）。

## 例の書き方

docs/19 ⑤。酸欠・硫化水素の教育を受けるのは、下水道・マンホール（土木・上下水道・清掃）、
し尿・汚水槽・浄化槽（ビルメンテナンス・清掃・環境）、タンク・船倉（造船・港湾・運送・水産）、
ケーソン・立坑・地下工事（土木）、醸造・発酵タンク（食品・酒造）、サイロ・堆肥（農業・飼料）、
化学プラント・製鉄（製造）、冷凍倉庫・ドライアイス（物流）、温泉・地熱（観光・掘削）。
**建設だけでもない。下水・ビルメン・食品・農業・製造が大きい。**

事例：船倉（港湾）／汚水槽（ビルメン）／地下室の炭酸ガス消火設備（設備）／立坑（土木）／穀物サイロ（農業）／
下水管（下水道）／魚倉（水産）／醸造タンク（酒造）／鋼製タンク塗装（塗装・プラント）／反応槽（化学）／
マンホール3人（下水道）／ピット（ビルメン）／し尿処理（環境）／汚水ピット（下水道）／温泉貯湯槽（温泉）／
ケーソン（基礎工事）／浄化槽（設備）。

# スマホで使うための作り

現場の職人がスマホで使う前提です。ここに関わる決まりをまとめてあります。

## ホーム画面に置く

`public/manifest.webmanifest` と `src/app/layout.tsx` の `metadata` です。

| | |
|---|---|
| ホーム画面の名前 | 足場教育（12文字まで。長いと省略される） |
| 開き方 | `standalone`。上下のブラウザの帯が出ない |
| 色 | 背景も上の帯も `#14171B` |
| アイコン | `public/icon-*.png`。`/tmp` のスクリプトではなく、その場で描いて作ったもの |

アイコンは3つ要ります。

- `icon-192.png` `icon-512.png` … ふつうのアイコン
- `icon-maskable-512.png` … **まわり2割を余白にしてある**。
  Android は丸や角丸に切るので、余白が無いと絵が欠ける
- `apple-touch-icon.png` … iPhone がホーム画面に置くときに使う

## 圏外でも開ける

`public/sw.js` です。

- **まず網、駄目なら手元**（network first）。直したものがすぐ届くのを優先し、
  電波が無いときだけ手元の写しを出す
- `/api/` は写さない。**古い記録を掴んだまま進むより、失敗が分かる方がよい**
- 開発中は入れない（`src/components/ServiceWorker.tsx`）。
  古い写しを掴むと、直したものが出なくなるため

まだ開いたことのない画面を圏外で開くと `public/offline.html` が出ます。
この1枚は**読み込むものが何も無い素のHTML**にしてあります。
Next の画面を写しても、動かす部品が手元に無ければ真っ白になるためです。

Next は一覧に並んだ先の画面を先に取りに行くので、
一覧を開いた時点でその先まで手元に入ります。これは有り難い性質です。

写しを作り直したいときは `sw.js` の `CACHE` の名前（`ashiba-v1`）を変えます。
古い写しは次に開いたときに捨てられます。

## 押す所の大きさ

**44px** を下回らないようにしています。現場では手袋のまま触るためです。

- 戻るリンクは `.backlink` / `.backlink-bar`（`globals.css`）。字はそのままに的だけ広げる
- 盤面のタップは `docs/02-第1章の判定仕様.md` の「盤面のタップ」を参照

## 試験

| 何を | どこで |
|---|---|
| 横のはみ出し・押す所の大きさ・字の大きさ（全画面） | `npm run test:e2e:fitall` |
| ホーム画面に追加できるか・圏外でも開けるか | `npm run build` のあと `npm run test:e2e:pwa` |

圏外の試験は、**本当にサーバを落として**確かめています。
ブラウザの「オフライン」設定では、仕込みの中からの取りに行きが素通りしてしまい、
確かめたことになりません。

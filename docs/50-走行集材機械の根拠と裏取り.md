## 1. 何という教育か

**走行集材機械の運転の業務に係る特別教育**（目録14行目）

対象は、安衛則第36条第6号の3に掲げる、**走行集材機械の運転（道路上を走行させる運転を除く）**。
走行集材機械は、車両の走行により集材を行う機械で、動力を用い、自走できるもの。
フォワーダ、集材車。荷台とグラップルクレーンが付き、ウインチで木を引き寄せるものもある。

**学科6時間＋実技6時間（走行3時間・作業装置3時間）。実技は事業者が自社で行う。**

伐木等機械（第8条の2）とは別の教育。**この修了でハーベスタは動かせず、チェーンソーの伐倒もできない。**
グラップル付きのフォワーダで集積をするなら、伐木等機械の教育も要る（両方受ける）。

## 6. 講座の軸にした四つ

1. **積車は別の機械。** 荷を載せれば重心が高く後ろに上に動き、止まる距離が伸び、傾きに弱い。積載量（体積×比重で暗算、本数で数える）を守る
2. **傾斜は登り下りまっすぐ。下りは登りと同じ変速でエンジンブレーキ（フェード）。作業道の路肩から機体の幅の半分以上離れる。雨のあとは歩いて見る**
3. **グラップルの範囲・丸太の転がる範囲・ワイヤの内側と引く方向の延長・中折れの前後の間に人を入れない**
4. **離れるときはグラップルを下ろし、ブレーキ、エンジン、ロック、鍵。荷を載せたまま止めない。荷台に人を乗せない**

## 7. 条番号を書いていないところ

docs/19 の決めごとどおり、**条文で確かめた番号だけ書く。**
書いたのは **法第59条第3項／安衛則第36条第6号の3／規程第8条の3** の三つだけ。
隣の教育の条（第7条の3・第8条の2・第9条・第9条の2・第10条）は、規程の全文で確かめたので番号を書いた。

**番号を書かずに中身だけ教えているもの**（主に科目5）：

- 安衛則の車両系木材伐出機械等の各条
  - **作業計画**（運行の経路を含む）、**制限速度**
  - **転落等の防止**（路肩の崩壊、地盤の不同沈下、必要な幅、誘導者）… この機械に一番効く決まり
  - **接触の防止**、**合図**
  - **運転位置から離れる場合の措置**、**とう乗の制限**（荷台に人を乗せない）、**使用の制限**、**修理等**
  - **ヘッドガード等**と、走行集材機械の**運転席後方の防護**
  - **定期自主検査**・**作業開始前点検**、記録3年
  - **悪天候時の作業禁止**
- 安衛則のワイヤロープの各条（玉掛け・集材）… **安全係数**、**不適格なワイヤロープ**（素線切れ10％・直径7％減・キンク・形くずれと腐食）、**フック・シャックルの外れ止めと変形**
- **走行集材機械の定義**（安衛則第36条第6号の3の括弧書き）… 番号は書いたが、括弧書きの字句は写していない
- **油圧の噴出による皮膚の貫通**、**ブレーキのフェード**… メーカーと林業・木材製造業労働災害防止協会の資料の中身
- **玉掛け**の区分、**道路交通法**（公道）
- **労働者死傷病報告**と労災隠し
- **特別教育の記録の3年保存**

いずれも、労働局・林業・木材製造業労働災害防止協会・林野庁の資料と実務で通っている中身に合わせて書いた。
**条番号が確かめられたら、ここに足して、単元の中でも番号を出す。**

## 9. 例の書き方（docs/19 ⑤）

**足場屋の例は1つも入れていない。**
林業と、木を運ぶ仕事が中心なので、業種はこの中で散らした。

- 素材生産の事業体・森林組合・国有林の請負
- 作業道を作る土木の事業体
- 風倒木と災害復旧
- 造成の伐開
- バイオマスの原木生産・竹林の整備

### 入れた事例（8件）

| 単元 | 事例 | 業種 |
|---|---|---|
| 1-1 | 伐木等機械の教育だけで、フォワーダを運転していた | 素材生産 |
| 3-1 | 雨のあとの作業道で、路肩が崩れて積車が転落した | 森林組合 |
| 3-2 | 積載量を超えて積み、下り坂でブレーキが効かなくなった | 素材生産 |
| 3-2 | ワイヤの内側に立っていて、外れたチョーカーが跳ねた | 災害復旧（風倒木） |
| 3-3 | 傾斜を横切って、積車が横転した | 作業道を作る土木の事業体 |
| 3-4 | 荷台に残した一本が転がり、はいの脇の作業員に当たった | バイオマスの原木生産 |
| 5-1 | 作業計画に運行の経路が無く、待避所も決めずに正面衝突 | 国有林の請負 |
| 5-1 | 荷台に人を乗せて下山し、振り落とされた | 竹林の整備 |

# 94　条文で確かめていないものの棚卸し（2026-09-07）

げんきさんの「条文確認を行なって」。**この環境からは条文が取れない**ので、
まず「何が、どの強さで確かめてあるか」を全部数え直した。取りに行く手順は §5。

## 1　この環境からは条文が取れない

e-Gov も厚労省も、外向き通信のポリシーが CONNECT を 403 で止める。
プロキシの状態にも `connect_rejected … policy denial` として記録が残る。
回避はしない（README の決まり）。

    elaws.e-gov.go.jp   だめ
    laws.e-gov.go.jp    だめ
    www.mhlw.go.jp      だめ
    jsite.mhlw.go.jp    だめ

検索は通るが、**検索の要約だけで条番号を書かない**（docs/26 の決まり）。
一度これで間違えている（酸欠第1種を、よその講習の頁を根拠に「直して」しまった。
あとで告示が出てきて、元が正しかった。docs/24）。

## 2　いま、どの強さで確かめてあるか

目録は66行。全部に「時間を確かめた」印（checked）が付いている。
ただし**印の強さは同じではない。**

| 強さ | 意味 | 件数 |
| --- | --- | --- |
| 告示の全文が手元にある（fullText） | 科目名・中欄・時間を一字ずつ突き合わせた | 21 |
| 裏取りの docs がある | 条文に当たった記録が docs に残っている | 65 |
| どちらも無い | | **1** |

`fullText` が false でも、多くは docs に条文で確認した記録がある。
たとえばチェーンソー（no.17）は目録に全文を貼っていないが、
docs/38 に「告示第10条第2項・第3項の表を条文で確認」と残っている。
**全文を貼っていないだけで、見ていないわけではない。**

## 3　いちばん弱いのは、うちの看板だった

**66行のうち、裏取りの記録がまったく無いのは1行。足場（no.63）。**

    no.63 scaffolding_assembly  足場の組立て、解体又は変更の作業に係る業務
      学科 360分 ／ 実技 0分
      根拠  労働安全衛生規則第36条第39号／安全衛生特別教育規程
      出どころ  東京労働局 安全衛生教育の一覧
      裏取りの docs  無し
      告示の全文  無し

安衛則第36条第39号は確かめてある（docs/18 の裏取り表11行目）。
**確かめていないのは、科目と時間を決めている「安全衛生特別教育規程」の何条か。**
だから目録の basis にも条番号を書いていない（前後の行は第21条・第23条・第24条）。

学科6時間そのものは、東京労働局のまとめに載っている数字。
法定教育時間の優先順位（現行省令 → 委任された現行告示 → 労働局の公式まとめ）で
いちばん下の段。**うちがいちばん多く売る講座が、いちばん弱い根拠で立っている。**

同じ出どころはもう1行、ゴンドラ（no.37）。こちらは docs/78 があり、
実技の合図60分が推定であることも §2 に書いてある。

## 5　取りに行く手順（げんきさん、またはGPT）

値段のときと同じやり方。**条文の頁をそのまま写して**もらう。
検索結果の要約は使わない。

### 5-1　足場（最優先）

e-Gov で「安全衛生特別教育規程」（昭和47年労働省告示第92号）を開き、
**足場の組立て等の業務の教育を定めている条**を探す。ほしいものは4つ。

  1. 何条か（第◯条）
  2. その条の**学科の表**（科目＝左欄／範囲＝中欄／時間＝右欄）を、行ごとにそのまま
  3. 実技の項があるか。あれば同じく表のまま
  4. 条文末尾の改正履歴（いつの改正後のものか）

### 5-2　ゴンドラ

「ゴンドラ取扱い業務特別教育規程」（昭和47年労働省告示第121号）**第3条**。
実技の表を、行ごとにそのまま。とくに「合図」の行の時間。

### 5-3　安衛則第36条

「労働安全衛生規則」第36条の**全文**（第1号から最後の号まで）。
号が飛んでいたり枝番（第10号の5 など）があるので、**番号を省略せずに**。

### 5-4　渡し方

写した条文をそのまま貼ってもらえれば、こちらで目録と突き合わせる。
**要約や「◯時間でした」だけは受け取らない。**表の行がほしい。

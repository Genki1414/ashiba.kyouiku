## 1　この環境からは条文が取れない

e-Gov も厚労省も、外向き通信のポリシーが CONNECT を 403 で止める。
プロキシの状態にも `connect_rejected … policy denial` として記録が残る。
回避はしない（README の決まり）。

    elaws.e-gov.go.jp   だめ
    laws.e-gov.go.jp    だめ
    www.mhlw.go.jp      だめ
    jsite.mhlw.go.jp    だめ

検索は通るが、**検索の要約だけで条番号を書かない**（docs/26 の決まり）。
一度これで間違えている（酸欠第1種を、よその講習の頁を根拠に「直して」しまった。
あとで告示が出てきて、元が正しかった。docs/24）。

## 2　いま、どの強さで確かめてあるか

目録は66行。全部に「時間を確かめた」印（checked）が付いている。
ただし**印の強さは同じではない。**

| 強さ | 意味 | 件数 |
| --- | --- | --- |
| 告示の全文が手元にある（fullText） | 科目名・中欄・時間を一字ずつ突き合わせた | 21 |
| 裏取りの docs がある | 条文に当たった記録が docs に残っている | 65 |
| どちらも無い | | **1** |

`fullText` が false でも、多くは docs に条文で確認した記録がある。
たとえばチェーンソー（no.17）は目録に全文を貼っていないが、
docs/38 に「告示第10条第2項・第3項の表を条文で確認」と残っている。
**全文を貼っていないだけで、見ていないわけではない。**

## 5　取りに行く手順（げんきさん、またはGPT）

**告示は e-Gov に載っていない。**e-Gov 法令検索が持っているのは法律・政令・省令で、
安全衛生特別教育規程やゴンドラ取扱い業務特別教育規程は**告示**なので入っていない。
厚生労働省の法令等データベースか、安全衛生情報センター（中災防）を見る。

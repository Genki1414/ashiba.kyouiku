# リリース前の通し確認

売り始める前に、**実機（本物のスマホ）で1回だけ通す**ための台本です。
自動の検証では確かめられないところ（カメラ・電波・指の届く場所）を見ます。

所要 40分ほど。**途中で止まったら、そこで終わりにして構いません。**
どこで止まったかが分かれば直せます。

---

## 0. 準備（10分）

### 0-1 設定を埋める

`/setup` を開いて、赤が消えるまで埋めます。

**要る（これが無いと売れません）**

| 環境変数 | 何を入れるか |
|---|---|
| `EXAM_SECRET` | 長い乱数を1つ。**未設定だと修了試験が動きません** |
| `OWNER_EMAILS` | 中川さんのメール。入金の確認ができなくなります |
| `SITE_URL` | 本番の住所（`https://…`） |
| `SEAT_UNIT_PRICE` | 特別教育の受講コード1枚の値段（税抜・円） |
| `TRAIN_UNIT_PRICE` | 実務トレーニング（第2章以降）1人ぶんの値段（税抜・円）。**未設定だと受講コードと同じ値段になります** |
| `SELLER_CEO` | 代表者。特商法の表示義務 |
| `SELLER_ADDRESS` | 所在地。同上 |
| `SELLER_TEL` | 電話番号。同上 |
| `SELLER_EMAIL` | メールアドレス。同上 |

**任意**

| 環境変数 | 何を入れるか |
|---|---|
| `SELLER_INVOICE_NO` | 適格請求書の登録番号（T＋13桁）。免税事業者なら空のまま |
| `SELLER_NAME` | 販売事業者名。空なら「東北三上機材株式会社」 |
| `SELLER_HOURS` | 電話を受けられる時間。空なら「平日 9:00〜17:00」 |
| `SELLER_CONTACT` | 問い合わせ窓口の名前。空なら「教育事業担当」 |
| `STRIPE_SECRET_KEY` `STRIPE_WEBHOOK_SECRET` | カード払い。無くても請求書払いで売れます |

`EXAM_SECRET` の作り方の例（どの端末でもよい）:

```
openssl rand -base64 48
```

### 0-2 データベースを最新にする

Supabase の SQL Editor に `supabase/apply-all.sql` を貼って実行。
最後に出る `schema_version` が、`src/content/schema.ts` の `NEED_SCHEMA` と
同じであることを確かめます。**違っていれば `/setup` が赤く出します。**

### 0-3 Supabase を速くする（任意・効きます）

- **Settings → JWT Keys**　「Migrate to asymmetric keys」があれば押す。
  ログインの確かめが手元で済むようになり、画面の移り変わりが速くなります。
  既存のログインはそのまま使えます
- **Settings → General**　リージョンが東京（`ap-northeast-1`）か見る。
  違っていると、往復ごとに 150〜250ms 乗ります

### 0-4 Vercel を Pro にする

Hobby は**商用利用ができません**。売る前に切り替えます。

### 0-5 用意するもの

- スマホ2台（1台は受講者役、1台は担当者役）。1台でも通せますが、
  ログインし直しが増えます
- **眼鏡**（かけている人がいる場合）
- 逆光になる場所（窓を背にできるところ）

> ヘルメットは要りません。**学科は座って受けるもの**なので、かぶりません。

## 1. 事業者を作る（担当者役・5分）

1. 本番の住所を開く → **新しいメール**で登録（いつも使っているものとは別に）
2. ホーム →「会社とつなぐ」→ **② 会社を登録する**
3. 事業者名を入れて「この会社を登録する」

> ここで作った会社は **有償** で始まります（無償利用は本部が立てるもの）。
> だから受講コードを買う道がそのまま試せます。
> いつものアカウント（東北三上機材）は無償利用なので、コードの関門を
> 素通りしてしまい、この確認になりません。

**見るところ**
- [ ] 作ったあと、`/admin` の名簿に**自分の名前が出ている**
      （出ていなければ、`apply-all.sql` が最後まで入っていません）
- [ ] 参加コード（8文字）が出ている
- [ ] `/owner` の「事業者と記録」で、その会社が **「有償」** になっている

## 2. 受講コードを買う（担当者役・5分）

1. `/order` を開く → 人数を **2** にする
2. 金額が人数に応じて変わるのを確かめる
3. 「請求書で払う」で申し込む

**見るところ**
- [ ] 受講コードが **2枚**、**文字そのもの**で出ている（`ABCD-2345-6789` の形）
- [ ] 「まとめて写す」で写せる
- [ ] `/owner` の「申込みと入金」に、いま入れた注文が出ている

## 3. 受講者として入る（受講者役・5分）

**別の端末**（または別のブラウザ）で、**別のメール**で登録します。

1. ホーム →「会社とつなぐ」
2. **① 会社をさがす**で事業者名の一部を入れて、申し込む

> ついでに **② 会社を登録する** で、1でつくった会社と**同じ名前**を入れてみてください。
> 「もう登録されています」と出て、そこから申し込みに回れば正しい動きです。
> 全角の（株）や空白の有無を変えても、同じ会社として扱われます。
3. 担当者役の `/admin` に「参加の申し込み 1件」が出る → 許可する
4. 受講者役に戻って、`/join` で受講コード（12文字）を入れる

**見るところ**
- [ ] 申し込んだ直後、**ホームに「許可待ち」の札**が出ている
- [ ] 受講者側の `/join` も「許可待ち」と出ている
- [ ] 許可すると、名簿に「在籍」で入る
- [ ] 受講コードを入れると、`/edu` が開く

> ここで開かない場合は `/setup` の「受講できるか」を見てください。
> 何を根拠に通している／断っているかが出ます。

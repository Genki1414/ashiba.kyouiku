# リリース前の通し確認

売り始める前に、**実機（本物のスマホ）で1回だけ通す**ための台本です。
自動の検証では確かめられないところ（カメラ・電波・指の届く場所）を見ます。

所要 40分ほど。**途中で止まったら、そこで終わりにして構いません。**
どこで止まったかが分かれば直せます。

---

## 0. 準備（10分）

### 0-1 設定を埋める

`/setup` を開いて、赤が消えるまで埋めます。

| 環境変数 | 何を入れるか |
|---|---|
| `EXAM_SECRET` | 長い乱数を1つ。**未設定だと修了試験が動きません** |
| `OWNER_EMAILS` | 中川さんのメール。入金の確認ができなくなります |
| `SITE_URL` | 本番の住所（`https://…`） |
| `SEAT_UNIT_PRICE` | 1人あたりの単価（税抜・円） |
| `SELLER_CEO` `SELLER_ADDRESS` `SELLER_TEL` `SELLER_EMAIL` | 特商法の表示義務 |
| `SELLER_INVOICE_NO` | 適格請求書の登録番号（T＋13桁）。免税事業者なら空のまま |

`EXAM_SECRET` の作り方の例（どの端末でもよい）:

```
openssl rand -base64 48
```

### 0-2 データベースを最新にする

Supabase の SQL Editor に `supabase/apply-all.sql` を貼って実行。
最後に出る `schema_version` が **`0016`** であることを確かめます。

### 0-3 Vercel を Pro にする

Hobby は**商用利用ができません**。売る前に切り替えます。

### 0-4 用意するもの

- スマホ2台（1台は受講者役、1台は担当者役）。1台でも通せますが、
  ログインし直しが増えます
- **ヘルメット**と**眼鏡**（かけている人がいる場合）
- 逆光になる場所（窓を背にできるところ）

---

## 1. 事業者を作る（担当者役・5分）

1. 本番の住所を開く → 新しいメールで登録
2. ホーム →「会社とつなぐ」→「事業者を作る」
3. 事業者名を入れて作る

**見るところ**
- [ ] 作ったあと、`/admin` の名簿に**自分の名前が出ている**
      （出ていなければ、`apply-all.sql` が 0016 まで入っていません）
- [ ] 参加コード（8文字）が出ている

---

## 2. 受講コードを買う（担当者役・5分）

1. `/order` を開く → 人数を **2** にする
2. 金額が人数に応じて変わるのを確かめる
3. 「請求書で払う」で申し込む

**見るところ**
- [ ] 受講コードが **2枚**、**文字そのもの**で出ている（`ABCD-2345-6789` の形）
- [ ] 「まとめて写す」で写せる
- [ ] `/owner` の「申込みと入金」に、いま入れた注文が出ている
- [ ] 登録番号を入れたなら、そこに出ている（請求書に写すため）

---

## 3. 受講者として入る（受講者役・5分）

**別の端末**（または別のブラウザ）で、**別のメール**で登録します。

1. ホーム →「会社とつなぐ」
2. **① 会社をさがす**で事業者名の一部を入れて、申し込む
3. 担当者役の `/admin` に「参加の申し込み 1件」が出る → 許可する
4. 受講者役に戻って、`/join` で受講コード（12文字）を入れる

**見るところ**
- [ ] 申し込んだ直後、受講者側は「許可待ち」と出ている
- [ ] 許可すると、名簿に「在籍」で入る
- [ ] 受講コードを入れると、`/edu` が開く

> ここで開かない場合は `/setup` の「受講できるか」を見てください。
> 何を根拠に通している／断っているかが出ます。

---

## 4. 受講の準備（受講者役・10分）★ここが本番

`/edu/ashiba` →「受講の準備」へ。

### 4-1 顔を登録する

**見るところ**
- [ ] **ヘルメットをかぶったまま**で登録できるか
- [ ] **眼鏡をかけたまま**で登録できるか
- [ ] **窓を背にして（逆光で）**登録できるか

> 逆光で登録できない場合は、**明るい方を向いて**登録し直します。
> それでも駄目なら、そこで止めて教えてください。しきい値の話になります。

### 4-2 受講中の照合

単元を1つ開いて、3分ほど見ます。

**見るところ**
- [ ] **カメラを手で隠す**と、動画が止まる（すぐでなくてよい）
- [ ] 隠すのをやめると、また動く
- [ ] **別の人が顔を出す**と、その場で止まる
- [ ] ヘルメット・眼鏡のまま、**普通に見ているだけでは止まらない**

> ここが**いちばん大事**です。普通に見ているのに何度も止まるなら、
> 現場では使えません。何分で何回止まったかを教えてください。

## 5. 学科を1単元通す（受講者役・5分）

1単元（30分）を最後まで見るのは大変なので、**1単元だけ**通します。

**見るところ**
- [ ] 規定時間に達するまで、確認問題に進めない
- [ ] 達すると確認問題が開く
- [ ] 合格すると、次の単元へ進める
- [ ] `/admin` の名簿で、**その人の「受講中」に進みが出ている**

## 6. 担当者の画面（担当者役・5分）

`/admin` を開きます。

**見るところ**
- [ ] 受講者の名前の下に「実務トレーニング／受講中／取得済み資格」の3つ
- [ ] 「受講中」を押すと、学科の進み・見た時間・いまどこかが出る
- [ ] いちばん下の「過去の受講記録を出す」が開く
- [ ] そこから「表にして保存（CSV）」が落とせて、Excel で文字化けしない

## 7. 資格の申請（受講者役 → 担当者役・5分）

1. 受講者役の `/me` →「取得済みの資格」→「資格を足す」
2. 特別教育から**2つ以上**選んで、受けた所と日付を入れて足す
3. 担当者役の `/admin` を開き直す

**見るところ**
- [ ] いちばん上に「資格の申請 2件」が出ている
- [ ] 「修了証の現物を見た」を押すと、確認済みになる
- [ ] 受講者側の `/me` でも「確認済み」に変わっている

---

## 8. 修了証（担当者役・任意）

学科13単元と修了試験を全部通すのは丸1日かかるので、
**通し確認では飛ばして構いません。**
出す手順だけ確かめたい場合は、`/owner` の「事業者と記録」で
その事業者を無償利用に立て、試験を通してから発行します。

**見るところ**（やる場合）
- [ ] 名簿の「受講中」に「修了証を発行する」が出る
- [ ] 押すと証明番号が出る
- [ ] `/verify` に番号を入れると、**名前が伏せ字**で照会できる

## 止まったときに見るところ

| 症状 | まず見る |
|---|---|
| 教材が開かない | `/setup` の「受講できるか」。根拠が出ます |
| 名簿に出ない | `/admin` の「在籍 ○人／申し込み ○件／抜けた ○人」 |
| 修了試験が動かない | `EXAM_SECRET` が未設定です |
| 何かがおかしい | `/setup`。赤いところが原因です |

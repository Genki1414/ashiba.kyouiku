# 小型車両系建設機械（整地・運搬・積込み用及び掘削用）：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 小型車両系建設機械（整地・運搬・積込み用及び掘削用）の運転の業務に係る特別教育 |
| 対象 | 施行令別表第7の第1号（整地・運搬・積込み用）・第2号（掘削用）の機械のうち、**機体重量3トン未満** |
| 学科 | **7時間**（4科目9単元） |
| 実技 | **6時間**（事業者が自社で行う） |
| 合計 | 13時間 |

3トン以上は技能講習（車両系建設機械運転技能講習）。この特別教育では乗れない。
**アタッチメントを付けた状態の重量で決まる**（本体2.9トン＋ブレーカーで3.1トンなら技能講習）。
講座の中で、科目1・科目2・科目4と実技の段取りで、繰り返し言っている。

## 条番号を書いていないところ

安衛則の**車両系建設機械の各条**（作業計画、作業指揮者、制限速度、転落転倒の防止、
接触の防止、合図、運転位置から離れるときの措置、移送、とう乗の制限、用途外使用の制限、
修理等のときの措置、定期自主検査）と、**掘削作業の各条**は、
**条番号を条文で確かめていないので書いていない。**

科目4では、条番号ではなく**中身**で教えている
（「誰に、どんな義務があるか。それだけです」と最初に言っている）。
条文が手に入ったら、番号を足す。中身は変わらない。

同じ理由で、法第61条（就業制限）も番号を書かず「就業制限という決まり」と呼んでいる。

## 例の書き方

docs/19 ⑤。3トン未満の小型車両系を使うのは、
土木・造成、建築の基礎や外構、解体、造園、農業・畜産、林業、除雪、
産業廃棄物・リサイクル、砂利・砕石、上下水道・ガス・電気・通信の埋設、
鉄道の保線、港湾、グラウンド・ゴルフ場の整備、災害復旧。
**足場屋だけでも、建設だけでもない。農業・林業・除雪・廃棄物が大きい。**

事例21件：造園（ラジエータ）／産廃（高圧の油）／農業（バッテリ）／造成（斜面横断）／
解体（道板）／農業（公道自走）／産廃（バックブザー）／農業（シートベルト）／解体（ヒューズ）／
造成（押す作業）／解体（アタッチメント重量）／土地改良（クイックカプラ）／外構（バケットでつり）／
上下水道（土止め）／除雪（運転席の上）／造園（斜面で横向き）／土地改良（埋め戻しで沈下）／
外構（床付けの掘りすぎ）／設備（埋設ガス管）／解体（無資格）／畜産（上げたバケットの下）。

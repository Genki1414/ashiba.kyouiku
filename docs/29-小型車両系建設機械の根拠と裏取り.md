# 小型車両系建設機械（整地・運搬・積込み用及び掘削用）：根拠と裏取り

docs/19 の手順①の記録。**まだ作りかけ。単元を書いていない。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 小型車両系建設機械（整地・運搬・積込み用及び掘削用）の運転の業務に係る特別教育 |
| 対象 | 施行令別表第7の1号（整地・運搬・積込み用）・2号（掘削用）の機械で、動力を用い不特定の場所に自走できるもののうち、**機体質量3トン未満** |
| 学科 | **7時間** |
| 実技 | **6時間** |
| 合計 | 13時間 |

3トン以上は技能講習（車両系建設機械運転技能講習）。

## 根拠

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 第36条第9号 |
| 科目と時間 | 安全衛生特別教育規程 **第11条** |

## 止まっているところ

> ### 科目ごとの時間が確かめられていない
>
> 合計（学科7時間・実技6時間）は、CIC・労働技能講習協会・コベルコ・住友建機・
> 加藤製作所・産業技能センターで一致した。
>
> **科目ごとの時間は、6回検索しても表が出てこなかった。**
> 記憶では
>
> | 科目 | 時間 |
> | --- | --- |
> | 走行に関する装置の構造及び取扱いの方法に関する知識 | 3時間 |
> | 作業に関する装置の構造、取扱い及び作業方法に関する知識 | 2時間 |
> | 運転に必要な一般的事項に関する知識 | 1時間 |
> | 関係法令 | 1時間 |
> | 実技：走行の操作 | 4時間 |
> | 実技：作業のための装置の操作 | 2時間 |
>
> だが、**高所作業車のとき「装置1時間・原動機3時間」と逆に思い込んでいた。**
> 実際は逆だった。ここも同じことが起きうる。
>
> 7時間の講座で科目の時間を取り違えると、いちばん大きい科目を
> 法定の何分の一かの中身で作ることになる。**表を見るまで単元を書かない。**
>
> `src/content/kogata.ts` に、記憶の割り振りを `_DRAFT` として置いた。
> courses.ts には入れていない。目録の行は `building: true`。

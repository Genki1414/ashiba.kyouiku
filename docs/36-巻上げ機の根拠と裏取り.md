# 巻上げ機（ウインチ）：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | 巻上げ機の運転の業務に係る特別教育 |
| 対象 | 動力により駆動される巻上げ機（電気ホイスト、エアホイスト及びこれら以外の巻上げ機でゴンドラに係るものを除く）の運転の業務（荷の巻上げ・巻卸し） |
| 学科 | **6時間**（3科目10単元） |
| 実技 | **4時間**（運転3時間＋荷掛け及び合図1時間）。事業者が自社で行う |
| 合計 | 10時間 |

クレーンに当たる装置（荷を吊って水平に運ぶ構造）はクレーン等安全規則。5トン未満は特別教育、以上は免許。玉掛けも別。

## 条番号を書いていないところ

安衛則の**巻上げ機の各条**（運転者、合図の統一と合図者の指名、立入禁止、運転位置を離れるときの措置、据付）と
**ワイヤロープの各条**（使用禁止＝断線10%・径7%・キンク・著しい変形腐食、安全係数6、作業開始前点検）、
**動力伝達装置の覆い**は、**条番号を条文で確かめていないので書いていない。**科目3は中身で教えている。

教材の中の数字で、原文で確かめていないもの：
- ワイヤロープの廃棄基準「一よりで素線10%以上の断線」「径7%超の減り」（安衛則・クレーン則）
- 巻上げ用ワイヤロープの安全係数「6以上」（安衛則）
- 捨て巻き「2巻以上」（講習で広く使われる値）
- 二本吊りの角度と力「90度で1.4倍、120度で2倍」「60度以内」（玉掛けの講習の値）
- ワイヤクリップの数・間隔「径の6倍」（メーカー・講習の値）
- クレーンの区分「5トン未満は特別教育」、玉掛け「1トン以上は技能講習」（クレーン則・安衛令）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。

## 例の書き方

docs/19 ⑤。巻上げ機を使うのは、
建設（揚重・鉄骨・設備・電線の延線・杭打ち）、造船、林業（集材）、舞台・イベント（吊り物）、港湾、漁業、
工場の搬送、電力・通信の架線、解体、造園、さく井。**建設だけではない。**足場屋の例は入れていない。

事例22件：覆いの無いチェーン（舞台）／傷んだケーブルで感電・墜落（設備工事）／クラッチを切って荷が落ちた（林業）／
捨て巻きを残さず（さく井）／ブレーキ保持のまま離れた（造船）／過巻防止を外した（鉄骨）／無線が通じないまま（造園・土木）／
キンク（架線）／溶接のアース線（鉄骨）／足場にアンカー（設備工事）／砂地の杭（漁業）／導き滑車が近い（内装）／
二人の合図（舞台）／止めての前に手（内装）／半掛け一本（設備工事）／重心のずれた機械（食品工場）／
クリップの向き（林業）／「動くから良」のブレーキ（機械製造）／試し引き無し（架線）／合図者未指名（港湾）／
クレーンに当たる装置（製材）／記録が無い（造園）。

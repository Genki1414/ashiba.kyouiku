## 1　席に講座を見ていなかった

受講コードは**講座ごとに**売っている。なのに判定は
「席を1枚でも持っていれば通す」だった。

席（`seats`）は `order_id` しか持たず、講座は注文（`orders.course_id`）が
持っている。そこを辿らずに止めていたので、
**足場の受講コード1枚で73講座すべてが開いた。**1講座ぶんの代金で全部見られる。

席 → 注文 とたどって、その講座のものかを見るようにした。

## 2　画面を塞いでも、記録を書く裏口が開いていた

視聴時間・確認問題・修了試験・本人確認・修了証・発行申請は、
どれも `currentEnrollment(courseId)` を通る。ここで権利を見ていなかった。

画面を閉じても、**道具で直接叩けば**持っていない講座の記録が作れた。
作られると、あとで受講コードを買ったときに「もう受け終わっている」状態になる。

**1か所で見る。**呼ぶ側8か所それぞれに書かせると、必ずどれかで忘れる
（現に、学科の画面しか見ていなかった）。

実務トレーニングだけ `requireSeat: false`。第1章は誰でも触れる売り方で、
見張りは別（`src/lib/trainingGate.ts`）。

## 3　無償利用の抜け道（0035）

`companies.trial` を立てた事業者は、在籍者が受講コードなしで全部開けた。撤廃。

**画面側だけ直しても足りない。**修了証の見張り
（`certificates_require_paid`）に「席が無くても、無償利用なら出す」が
残っていた。席の無い受講に修了証を挿せば通ってしまう。0035 で塞いだ。

列は残す。**過去にどこを無償にしたかの記録**であり、消すと後から追えない。

**止まっているほうが、タダで配られるよりまし。**

## 5　資格の選択肢を、講座と同じ細かさに

> 講座と保有資格選択を一致させなければならない。そうしないと除染のような現象が起きる

うちの講座は業務区分・装置・施設ごとに分けてあるのに、資格の側が
1つにまとまっていた。**どれを受けたのかが分からない**ので結べず、
取得済みにできなかった（除染で実際に起きた）。

割ったもの。

| もと | 割った先（講座と1対1） |
| --- | --- |
| 除染等業務 | 土壌等／除去土壌／汚染廃棄物／特定汚染土壌等／同（線量管理外） |
| エックス線・ガンマ線 | エックス線／ガンマ線／両方 |
| 加工施設等の核燃料物質 | 加工／再処理／使用施設等 |
| 事故由来廃棄物の処分 | 破砕等／焼却／埋立て |
| （資格が無かった） | 再圧室の操作 |

- **番号は変えない。**変えると、登録済みの行がどれか分からなくなる。
  割ったほうは `SE-061a` のように字を足す
- まとめていた4件は**選ばせない**（`legacy`）。過去の行の名前は出る
- 学科の時間は、うちの教材に入っている法定時間（除染は区分ごとに4.0／3.5と違う）

**結ばないもの**は SE-044（第一種酸素欠乏）だけ。うちの講座は第二種
（酸素欠乏・硫化水素）で、別の教育。結ぶと硫化水素の教育を受けないまま通す。

## 6　ホーム画面のアプリにログインを持ち込む（0036）

> ホーム画面に追加したのに、ホーム画面に追加した所からログインするとネット版になる

LINEログインは `access.line.me` という**よそのサイト**へ一度出る。
iPhone のホーム画面アプリは、出た時点でブラウザに切り替わって戻らない。
しかも**ホーム画面アプリとブラウザはログインの記憶が別**なので、
ブラウザで入ってもアプリは入っていないまま。
パスワードの決め直し（メールのリンク）でも同じことが起きる。

8文字の引き換えコードで持ち込む。

1. ブラウザでログイン → マイページ → 「アプリに入るコードを作る」
2. アプリのログイン画面 → 「コードで入る」に打つ

- **1回きり。**使ったら消す（写真に撮られても2回目は通らない）
- **5分で切れる**
- 作り直すと前のは消える。同時に生きているのは1本だけ
- 打ち間違えやすい `0 O 1 I L` は使わない（受講コードと同じ31字）
- 断り方を書き分けない（当てずっぽうに手がかりを与えない）

`/api/handoff/use` は**入っていない人が叩く**ので、ログインの手前で通す。
LINE で同じ轍を踏んだので、見張りにも入れた。
**コードを作るほう（`/api/handoff`）は閉じたまま**（本人だけ）。

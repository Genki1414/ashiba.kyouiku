# 第1章「段取りと根がらみ」の判定仕様

`HANDOFF.md` 3章の「現場のルール」を、そのままコードにしたものの対応表です。
監修や、あとから来た人がコードを読まずに突き合わせられるように作ってあります。

実装は3つに分かれています。

| ファイル | 役割 |
|---|---|
| `src/training/ch1/layout.ts` | 割り付け（柱・スパン・内柱の決まり・ジャッキの目標値） |
| `src/training/ch1/queue.ts` | 工程キュー。何を、どの順で、どこに置くか |
| `src/training/ch1/rules.ts` | 判定。工程キューから正しい手／ファールを導く |
| `src/training/ch1/state.ts` | 状態と進行（JSONに落とせる形） |

| `src/components/training/` | 描画（盤面・部品・作業員と親方・4つの場面） |
| `src/app/training/ch1/` | ゲーム画面。判定を呼んで見せ方を決める |

検査は2本あります。

- `npm run test:ch1` … 判定だけを直接叩く（78件）。正しい手順で26工程を通せること、
  下の表のファールが全部出ること
- `npm run test:e2e:ch1` … 実際のブラウザで段取りから完了まで通す
  （`npm run dev -- -p 3100` を先に起動しておく）

## ルールと実装の対応

| HANDOFF 3章 | 判定 | 分類（tag） | 重さ |
|---|---|---|---|
| 1. 段取りの順序：根がらみ手摺 → 内柱箇所の手摺 → ジャッキ | 手摺が1本も無い状態でジャッキ・内柱手摺を置くとファール | 段取りの順序 | ファール |
| 2. 内柱：端部は必ず、中間は2スパンに1本 | 出隅を内柱にする／間隔が空きすぎる／中間の本数超過はファール | 内柱の位置決め・内柱の本数 | ファール |
| 3. ジャッキ合わせ：挿す手前で計算値へハンドルを合わせる | 支柱を立てる前に場面を出す。**ゲーム中2回だけ** | — | 場面 |
| 4. 建方：出隅 → 2方向に根がらみ手摺 → 両隣の柱 | 順を飛ばすとファール。手摺は立っとる柱のコマへ | 建てる順序・根がらみの順序 | ファール |
| 5. 柱ごとの順序：離れ → 水平 → ブラケット（全箇所固定） | 離れの前に水平／水平の前にブラケットはファール | 手順の飛ばし | ファール |
| 6. 水平器は根がらみ手摺の端から少し中 | 端・中ほどを選ぶとファール。候補と作業員は進行方向側に出す | 水平器の置き場所 | ファール |
| 7. 内柱の箇所：内柱 → 600手摺 → 離れ → 水平（支柱に当てる） | 外柱の水平前に内柱を立てるとファール | 手順の飛ばし | ファール |
| 8. ブラケットは外柱から建物側へ張り出す | 内柱の箇所に掛けるとファール。**出隅は面ごとに1枚ずつ要る** | 取付位置の誤り | ファール |

## 重さの区別

`PROMPT.md` 4章のとおりに分けています。

| 種類 | 返り値 | 技能点 |
|---|---|---|
| 安全の問題 | `kind: "foul"` に `why`（なぜ危ないか）を必ず付ける | 減らす |
| 効率の問題・置き直し | `kind: "note"`。親方が一言添えるだけ | 減らさない |

ファールのときは「何が駄目か」ではなく「**なぜ駄目か**」を返します（`why`）。
画面では親方の怒り顔の横にこの文言を出します。

## 判断を仰ぎたいところ

- **中間の内柱を余分に入れたときの重さ**。いまはプロトタイプに合わせて
  ファール（技能点−8）にしています。ただ `PROMPT.md` 4章の区分でいえば、
  余分な内柱は「効率の問題」（材料と手間の無駄）で、危険ではありません。
  一言だけ添えて減点しない、という扱いにもできます。どちらが現場の感覚に
  近いか教えてください。

## 判定に使わなかったこと

- **手摺先行工法（先行手摺）のモード**：プロトタイプにはありますが、
  `HANDOFF.md` 3章のルールに含まれていないため、この実装では入れていません。
  入れる場合は出隅の片側が600スパンになり、出隅のブラケットが無くなります。
- **ハンマーで叩く別モード**：`HANDOFF.md` 5章の残タスクのまま。

## 用語の注意

- 「根がらみ手摺」は名前であって、使う資材は**手摺資材**です。
  落下防止手摺・上さん・中さんと同じ物を指します（`HANDOFF.md` 3章 ルール4）。
- 位置の表記は「コマ」。1コマ＝450mm。

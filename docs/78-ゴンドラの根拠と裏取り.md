# ゴンドラの根拠と裏取り

講座ID `gondola`。目録 no.37。2026年9月5日に作った。

---

## 1. 何を根拠にしたか

| 段 | 何 | 中身 |
|---|---|---|
| 法 | **労働安全衛生法第59条第3項** | 危険又は有害な業務に就かせるときは、事業者が特別の教育を行う |
| 省令 | **ゴンドラ安全規則（昭和47年労働省令第35号）第12条第1項** | **ゴンドラの操作の業務** |
| 告示 | **ゴンドラ取扱い業務特別教育規程（昭和47年労働省告示第121号）第2条（学科）・第3条（実技）** | 科目・範囲・時間 |

**学科（第2条）は、げんきさんからもらった全文で一字ずつ確かめてある**（docs/72）。

**高さや大きさの線が引かれていない。** クレーンの5トン、移動式クレーンの1トン、
玉掛けの1トンのような線が、この業務には無い。**ゴンドラの操作なら、この教育が要る。**

## 2. 科目・範囲・時間

### 学科（第2条）300分 — 告示の全文で確かめた

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| ゴンドラに関する知識 | 種類及び型式　昇降装置　安全装置　ブレーキ機能　取扱い方法 | 二時間 |
| ゴンドラの操作のために必要な電気に関する知識 | 電気に関する基礎知識　電動機　開閉器等電気を通ずる機械器具　感電による危険性 | 二時間 |
| 関係法令 | 労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則及びゴンドラ安全規則中の関係条項 | 一時間 |

### 実技（第3条）240分 — **二つ目の時間だけ、条文で見ていない**

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| ゴンドラの操作及び点検 | 作業床の昇降の操作　機械部分及び電路の点検 | 三時間 |
| ゴンドラの操作のための合図 | 電鈴等による合図の方法 | **60分（条文で見ていない）** |

もらった写しが、ここで切れていた。**60分は**

- 目録の実技240分から、一つ目の180分を引いた数
- 同じ形の建設用リフト（クレーン則の規程第4条）の合図が1時間

の二つから置いた数字であって、**告示で見た数字ではない。**

**だから `src/content/tokubetsu.ts` の no.37 には `fullText` を付けていない。**
`checked` は付けてある（労働局のまとめ・講座マスター・告示の学科がそろっているため）。

**合図の時間が載っているところを、もう一度もらえれば、ここも確定する。**
講座の 3-1（関係法令）でも、受講する人に「この1時間だけ条文で見ていない」と言っている。

### 2026年9月5日に、自分で確かめようとしたこと

- **e-Gov 法令検索には告示が無い**（法律・政令・省令だけ）。docs/24 のとおり。
- **厚労省の法令等データベース（www.mhlw.go.jp/hourei/）は、この環境の網の決まりで開けない**（egress blocked）。
  決まりを回り込むことはしていない。
- **ウェブ検索で出てくるのは民間の講習会社の頁ばかり**で、
  「実技4時間、操作及び点検3時間、合図1時間」と書いてはあるが、
  **民間サイトの一覧表は根拠にしない**という決まり（2026年9月5日）どおり、これは採らなかった。

## 3. 建設用リフトと、形はそっくり・中身は正反対

| | 建設用リフト（クレーン則の規程第4条） | **ゴンドラ（規程第2条・第3条）** |
|---|---|---|
| 学科の形 | 2／2／1 の3科目5時間 | **同じ** |
| 力学の科目 | 無い | **無い** |
| 電気の科目 | 2時間 | **2時間** |
| 実技 | 運転及び点検3時間／合図1時間 | **操作及び点検3時間／合図1時間** |
| 合図 | **電鈴等**による合図の方法 | **電鈴等**による合図の方法 |
| **人** | **乗せてはいけない**（搬器は荷のためのもの） | **人が乗る。しかも操作する人が自分で乗っている** |

**ここを取り違えると、講座がまるごと逆になる。**
建設用リフトの講座（`kensetsulift`）は「人を乗せない」で貫いてある。
ゴンドラは、その真逆から組み立てた。

---

## 4. この講座の軸

1. **自分が乗っている。**
   落ちるのは自分。だから点検は誰かのためではなく、自分のためにやる。
   そして、**支えているものは足元ではなく屋上にあり、乗ってしまえば見えない。**
   実技の一段目を「屋上を見る」にしたのは、これが理由。

2. **親綱と墜落制止用器具は、ゴンドラとは別に取る。**
   この講座でいちばん間違われるところ。
   **ゴンドラを吊っているのと同じ所に取ったら、一緒に落ちる。**
   **フックを作業床の手すりにかけたら、手すりは作業床の一部だから、一緒に落ちる。**
   1-3（安全装置）で「ゴンドラを落とさない装置」と「人を落とさない備え」を分け、
   3-1 の事例（シーリングの打ち替えで、手すりに掛けていた）で、もう一度出している。

3. **上と下で、お互いが見えない。**
   屋上と、地上と、作業床。風とガラスに声が消える。だから**電鈴等**の合図。

科目2に2時間あるのは、**ゴンドラが電気で人を持ち上げている機械**だから。
電気が止まれば人が空中に残り、漏れれば**逃げ場のない、狭い、濡れた箱の中で**感電する。
**感電による危険性を35分といちばん厚く**したのは、
感電そのもので死ぬのと、**手が離せなくなって、そのあと落ちる**のと、二重に危ないから。

## 5. 条文で確かめていない番号（講座に書いていないもの）

**確かめた番号だけを書く**という決まりのとおり、次のものは**番号を書かず、中身だけ**教えている。
3-1 のナレーションでも、受講する人に「番号は確かめていない」と言っている。

- ゴンドラ検査証（検査証を受けていないゴンドラは使ってはならない／備え付け）
- 使用の制限（積載荷重・人数）
- 突りょう等の固定（おもりを決められただけ載せる）
- **安全帯等**（作業床で作業するときは、要求性能墜落制止用器具その他の命綱を使わせる）
- 立入禁止（作業床の下）
- 悪天候時の作業禁止（強風・大雨・大雪）
- 作業開始前の点検
- 操作の合図
- 定期自主検査（1月以内ごとに1回）と、その記録
- 修理等のときの措置
- 労働安全衛生規則第37条・第38条（特別教育の記録の3年保存）

**ゴンドラ安全規則の条文が手に入ったら、番号を入れる。**

## 6. 出来上がり

- **3科目 10単元 計300分**（学科5時間）。実技240分。
- ナレーション 463行 / 11930字、図解 45、事例 1、確認問題 81。
- タップ的の被覆率 **71%**。
- 値段 5,500円（税抜）。建設用リフト・玉掛け・自動車用タイヤと同じ学科5時間なので、同じ値段。
  **よその値段はまだ調べていない。**
- 例に使った業種：窓ガラスの清掃／外壁のタイルの打診と補修／外壁の塗装／
  シーリング（目地）の打ち替え／外壁の防水／サッシとガラスの入れ替え／
  看板の取り付け／外壁の調査／橋梁とダムの点検／船の外板の塗装。
  **足場屋の例は入れていない**（この講座は、どの業種の人も受ける）。

## 7. 隣の教育

- **ロープ高所作業** → `rope`

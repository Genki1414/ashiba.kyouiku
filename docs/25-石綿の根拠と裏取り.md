## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | **石綿使用建築物等解体等業務特別教育** |
| 現場での呼び方 | 石綿取扱い作業従事者特別教育、アスベスト特別教育 |
| 学科 | **4時間30分**（270分） |
| 実技 | 無し。**学科だけで修了する** |

告示の名前が「石綿使用建築物等解体等業務特別教育規程」なので、
教育の名前もそれに合わせる。

## 根拠（渡された一覧は間違っていた）

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 第36条第37号 |
| 石綿則 | **石綿障害予防規則 第27条第1項** |
| 科目と時間 | 石綿使用建築物等解体等業務特別教育規程（平成17年厚生労働省告示第132号） |

渡された一覧（`special_education_course_master_20260901.csv`）は
**「石綿障害予防規則第3条第1項の…」**となっていた。

**第3条は事前調査の条であって、特別教育の条ではない。**
特別教育を義務づけているのは第27条第1項。
そのまま修了証に載せていたら、**根拠の条文が違う紙**が出ていた。

告示は石綿則第27条第2項に基づくもので、平成17年7月1日から適用。

## 科目・範囲・時間（告示の表）

規程の言い回しのまま。言い換えると突き合わせられなくなる（docs/19）。

> 石綿障害予防規則第二十七条第一項の規定による特別の教育は、**学科教育により**、
> 次の表の上欄に掲げる科目に応じ、それぞれ、同表の中欄に掲げる範囲について
> 同表の下欄に掲げる**時間以上**行うものとする。

| 科目 | 範囲 | 時間 |
| --- | --- | --- |
| 石綿の有害性 | 石綿の性状　石綿による疾病の病理及び症状　喫煙の影響 | **0.5時間** |
| 石綿等の使用状況 | 石綿を含有する製品の種類及び用途　事前調査の方法 | **1時間** |
| 石綿等の粉じんの発散を抑制するための措置 | 建築物、工作物又は船舶（鋼製の船舶に限る。）の解体等の作業の方法　湿潤化の方法　作業場所の隔離の方法　その他石綿等の粉じんの発散を抑制するための措置について必要な事項 | **1時間** |
| 保護具の使用方法 | 保護具の種類、性能、使用方法及び管理 | **1時間** |
| その他石綿等のばく露の防止に関し必要な事項 | 労働安全衛生法（昭和47年法律第57号）、労働安全衛生法施行令（昭和47年政令第318号）、労働安全衛生規則（昭和47年労働省令第32号）及び石綿障害予防規則中の関係条項　石綿等による健康障害を防止するため当該業務について必要な事項 | **1時間** |

**合計 4時間30分（270分）。** 実技は無い。

### 「時間以上」であること

告示は「同表の下欄に掲げる**時間以上**」と書いている。
だから**下回ってはいけないが、上回るのは構わない**。

この仕組みでは、単元ごとの視聴時間の関門をこの表のとおりに置く。
教材が表より長くなるぶんには問題ない。**短くしないこと。**

### 調べ直したときの経緯

はじめ、web で見つかる資料では**保護具が 0.5時間 と 1時間 で食い違って**いた。
合計は4時間30分で一致していたので、内訳が合わないまま進めそうになった。

告示の表を見て、**保護具は1時間**と決まった。
0.5時間で作っていたら、その科目だけ法定の半分で先へ進めていた。

**「合計が合っているから大丈夫」は通らない。** 関門は科目ごとに掛かる。

## 例の書き方

docs/19 ⑤の但し書きが効く。

> 特別教育のように**対象の業務が決まっている講座は別**。そこはその業務で書く。

職長教育と違い、この教育を受けるのは**石綿を扱う人だけ**。
だから例は解体・改修の現場から出す。3業種に散らさない。

ただし「石綿＝吹付け材」に寄せないこと。
いま現場で当たるのは、**成形板（レベル3）**のほうが桁違いに多い。
スレート波板、ケイカル板、Pタイル、屋根材。
足場屋が解体の足場を架けるとき、隣にあるのはこれ。

## 単元の割り付け（docs/19 ③）

告示の範囲（中欄）に対応させた。範囲より細かく割ってよいが、
**どの範囲にも単元が1つ以上当たっていること。**
組み立て（`npm run build:ishiwata`）が突き合わせて、当たっていなければ止まる。

| 科目 | 単元 | 分 |
| --- | --- | --- |
| 1 石綿の有害性（30） | 1-1 石綿の性状／1-2 疾病の病理及び症状／1-3 喫煙の影響 | 10・10・10 |
| 2 石綿等の使用状況（60） | 2-1 含有する製品の種類及び用途／2-2 事前調査の方法 | 30・30 |
| 3 発散を抑制するための措置（60） | 3-1 解体等の作業の方法／3-2 湿潤化／3-3 隔離／3-4 その他 | 20・15・15・10 |
| 4 保護具の使用方法（60） | 4-1 種類と性能／4-2 使用方法及び管理 | 30・30 |
| 5 その他ばく露の防止（60） | 5-1 関係条項／5-2 健康障害の防止 | 35・25 |

科目4は範囲が1つ（「保護具の種類、性能、使用方法及び管理」）だが60分ある。
1単元60分は見るほうが持たないので2つに割り、範囲は同じものを指している。

## 中身をどう書いたか（docs/19 ④⑤）

- 科目名・範囲・条文の言い回しは**告示のまま**。言い換えると突き合わせられない
- 数字はそのまま（0.1%、2006年9月、80平方メートル、100万円、40年、6か月、RS3・DS2）
- **解説文は書き下ろし。** テキストは写していない
- 例は解体・改修の現場から。docs/19 ⑤の但し書き（対象の業務が決まっている講座）

### 吹付けではなく、成形板（レベル3）中心

「石綿＝吹付け材」に寄せていない。いま現場で当たるのは
**成形板（レベル3）**のほうが桁違いに多い。
スレート波板、ケイカル板、Pタイル、カラーベスト、窯業系サイディング、仕上塗材。

### 業種を、ひとつに寄せない

> **一度、足場屋に寄せて書いてしまった。直した。**
>
> 「石綿を扱う＝解体や改修＝足場を架ける現場」と考えたのが間違い。
> 「ここは足場屋にいちばん近い落とし穴」「石綿の現場では足場の掛け方が変わる」
> といった書き方をして、事例の主人公も5単元のうち3単元で足場屋だった。
>
> **石綿を扱うのは足場屋だけではない。**
> 解体、内装、設備、電気、塗装、防水、屋根、外装、ビル管理・保全、
> 製造業の設備保全、造船。どの職種も受ける。
>
> 足場屋の話ばかり出てくれば、ほかの職種の人は自分の話として聞けない。
> 職長教育で避けたはずのことを、特別教育でやっていた。
> 決まりは docs/19 ⑤に書き足した。

いまの事例11件の業種。

| | 場面 |
| --- | --- |
| 内装 | 住宅の内装材撤去／店舗の内装解体／事務所ビルの内装解体／倉庫の内装解体 |
| 天井 | 事務所ビルの天井材撤去 |
| 設備 | 共同住宅の給湯設備の入替え／ビルの機械室の改修 |
| 屋根 | 工場の屋根の葺き替え（2件） |
| 床 | 学校の床タイル撤去 |
| 外壁 | アパートの外壁改修 |

**教材の中に「足場」という語は1つも無い**（`grep` で確かめる）。

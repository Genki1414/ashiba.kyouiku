## 根拠（渡された一覧は間違っていた）

| | |
| --- | --- |
| 法 | 労働安全衛生法 第59条第3項 |
| 則 | 労働安全衛生規則 第36条第37号 |
| 石綿則 | **石綿障害予防規則 第27条第1項** |
| 科目と時間 | 石綿使用建築物等解体等業務特別教育規程（平成17年厚生労働省告示第132号） |

渡された一覧（`special_education_course_master_20260901.csv`）は
**「石綿障害予防規則第3条第1項の…」**となっていた。

**第3条は事前調査の条であって、特別教育の条ではない。**
特別教育を義務づけているのは第27条第1項。
そのまま修了証に載せていたら、**根拠の条文が違う紙**が出ていた。

告示は石綿則第27条第2項に基づくもので、平成17年7月1日から適用。

## 科目・範囲・時間（告示の表）

規程の言い回しのまま。言い換えると突き合わせられなくなる（docs/19）。

> 石綿障害予防規則第二十七条第一項の規定による特別の教育は、**学科教育により**、
> 次の表の上欄に掲げる科目に応じ、それぞれ、同表の中欄に掲げる範囲について
> 同表の下欄に掲げる**時間以上**行うものとする。

| 科目 | 範囲 | 時間 |
| --- | --- | --- |
| 石綿の有害性 | 石綿の性状　石綿による疾病の病理及び症状　喫煙の影響 | **0.5時間** |
| 石綿等の使用状況 | 石綿を含有する製品の種類及び用途　事前調査の方法 | **1時間** |
| 石綿等の粉じんの発散を抑制するための措置 | 建築物、工作物又は船舶（鋼製の船舶に限る。）の解体等の作業の方法　湿潤化の方法　作業場所の隔離の方法　その他石綿等の粉じんの発散を抑制するための措置について必要な事項 | **1時間** |
| 保護具の使用方法 | 保護具の種類、性能、使用方法及び管理 | **1時間** |

**合計 4時間30分（270分）。** 実技は無い。

### 「時間以上」であること

告示は「同表の下欄に掲げる**時間以上**」と書いている。
だから**下回ってはいけないが、上回るのは構わない**。

この仕組みでは、単元ごとの視聴時間の関門をこの表のとおりに置く。
教材が表より長くなるぶんには問題ない。**短くしないこと。**

### 調べ直したときの経緯

はじめ、web で見つかる資料では**保護具が 0.5時間 と 1時間 で食い違って**いた。
合計は4時間30分で一致していたので、内訳が合わないまま進めそうになった。

告示の表を見て、**保護具は1時間**と決まった。
0.5時間で作っていたら、その科目だけ法定の半分で先へ進めていた。

**「合計が合っているから大丈夫」は通らない。** 関門は科目ごとに掛かる。

## 例の書き方

docs/19 ⑤の但し書きが効く。

> 特別教育のように**対象の業務が決まっている講座は別**。そこはその業務で書く。

職長教育と違い、この教育を受けるのは**石綿を扱う人だけ**。
だから例は解体・改修の現場から出す。3業種に散らさない。

ただし「石綿＝吹付け材」に寄せないこと。
いま現場で当たるのは、**成形板（レベル3）**のほうが桁違いに多い。
スレート波板、ケイカル板、Pタイル、屋根材。
足場屋が解体の足場を架けるとき、隣にあるのはこれ。

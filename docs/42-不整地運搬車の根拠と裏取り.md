## 1. 何という教育か

**不整地運搬車（最大積載量1トン未満）の運転の業務に係る特別教育**

不整地運搬車は、**舗装されていない所で荷を運ぶために作られた車**。
荷台を傾けて荷を降ろす。走る所が、ぬかるみ・砂利・伐採地・田畑・雪の上。

- **クローラ式** … 履帯で走る。クローラダンプ（キャリアダンプ）。軟らかい地面に沈みにくい
- **ホイール式** … 太いタイヤで走る。速く走れて、地面を傷めにくい

## 5. よその教育との違い（ここが要）

### ① 「最大荷重」ではなく「最大積載量」

| 教育 | 線引きに使う言葉 |
|---|---|
| フォークリフト（第7条） | **最大荷重** 1トン |
| ショベルローダー等（第7条の2） | **最大荷重** 1トン |
| **不整地運搬車（第7条の3）** | **最大積載量** 1トン |

荷台に載せてよい重さのこと。書類を書くときも間違えやすいので、科目1と科目4で二度言っている。

### ② 科目3（力学）の中欄が5つしかない

| | 中欄の項目 |
|---|---|
| フォークリフト・ショベルローダー等 | 力／重量／重心及び物の安定／速度及び加速度／荷重／**応力**／**材料の強さ**（7つ） |
| **不整地運搬車** | 力／重量／重心及び物の安定／速度及び加速度／荷重（**5つ**） |

**応力と材料の強さは、この条の中欄には無い。足していない。**
条文の表のとおり、5単元にした。この点は科目4の中でも受講者に説明している。

### ③ 科目2は装置だけではない

中欄は「荷役装置及び油圧装置の構造及び取扱いの方法**並びに荷の積卸し及び運搬の方法**」。
装置の話だけでなく、**積んで降ろして運ぶやり方**まで、この科目に入っている。
だから3単元（装置／積卸し／運搬）に割った。

## 6. 単元の割り付け

**科目1（120分・3単元）**
- 1-1 種類（クローラ式・ホイール式）と、原動機・動力伝達装置（40分）
- 1-2 走行装置（クローラ）・操縦装置・制動装置（40分）
- 1-3 電気装置・警報装置と、走行に関する附属装置の取扱いの方法（40分）

**科目2（120分・3単元）** — 中欄の「並びに」で切って割った
- 2-1 荷役装置（ダンプ装置・あおり）と油圧装置（40分）
- 2-2 荷の積卸しの方法（40分）
- 2-3 荷の運搬の方法（40分）

**科目3（60分・5単元）** — 中欄が5つなので、1つずつ
- 3-1 力（15分）／3-2 重量（10分）／3-3 重心及び物の安定（15分）／
  3-4 速度及び加速度（10分）／3-5 荷重（10分）

**科目4（60分・1単元）**
- 4-1 法、令及び安衛則中の関係条項（60分）

合計 **12単元・360分**。

### 実技の手引き（うちの案・360分）
1. 乗る前の点検と、乗り降り（40分）
2. 基本操作（発進・停止・変速・旋回）（60分）
3. 定められたコースによる基本走行（60分）
4. 応用走行（不整地・坂・軟弱地・狭い所）（80分）　← ここまで走行の操作 240分
5. 荷の積卸しの基本操作（60分）
6. 定められた方法による荷の運搬（60分）　← 荷の運搬 120分

## 7. この機械で人が死んでいる三つの形

講座の軸にしたところ。

1. **荷台に人を乗せる** — 不整地の荷台は跳ねる。手すりも座席もない。振り落とされて轢かれる
2. **上げた荷台の下に入る** — 張り付いた荷をつつく。油圧が抜けて落ちてくる。安全支柱を掛けない
3. **坂を横切る／坂の途中で変速する** — 横に倒れる。動力が切れて滑り落ちる

## 8. 条番号を書いていないところ

docs/19 の決めごとどおり、**条文で確かめた番号だけ書く。**
確かめられていないものは、番号を書かずに中身だけ教えている。

科目4（関係法令）で、**番号を書かずに中身だけ教えているもの**：

- 車両系荷役運搬機械等の **作業計画**（場所・運行経路・作業の方法を定めて周知する）
- **制限速度**（地形・地質に応じた速度を定め、超えて運転させない）
- **転落等の防止**（路肩の崩壊・地盤の沈下の防止、誘導者）
- **接触の防止**（危険のある箇所に労働者を立ち入らせない）
- **合図**（誘導者を置くときは合図を定め、その合図によらせる）
- **運転位置から離れるときの措置**（荷役装置を下ろす、原動機を止める、走り出さないようにする）
- **とう乗の制限**（乗車席以外に人を乗せない＝**荷台に人を乗せない**）
- **用途外使用の制限**
- **修理等のときの安全支柱・安全ブロック**
- **作業開始前点検**（制動装置、操縦装置、荷役装置、油圧装置）
- **定期自主検査・特定自主検査**（記録の保存、検査標章）
- **就業制限**（1トン以上は技能講習）
- **特別教育の記録の3年保存**
- 積み降ろし（道板・搬器）の条
- 道路交通法の**大型特殊免許**の条

いずれも、労働局・中災防の資料と実務で通っている中身に合わせて書いた。
**条番号が確かめられたら、ここに足して、単元の中でも番号を出す。**

## 10. 例の書き方（docs/19 ⑤）

**足場屋の例は1つも入れていない。**
1トン未満の不整地運搬車を使うのは、建設よりも林業と農業が大きい。

- 林業（間伐材の集材と搬出）
- 農業（果樹園・畑・ハウス・畜産）
- 造園／ゴルフ場
- 災害復旧／砂防と林道
- 除雪
- 産業廃棄物
- 太陽光発電所の造成
- 漁港

### 入れた事例（15件）

| 単元 | 事例 | 業種 |
|---|---|---|
| 1-1 | 技能講習だと思って1.5トン機に乗せた | 林業 |
| 1-1 | 荷台に乗せて運び、振り落とされた | 農業 |
| 1-2 | 坂を横切って走り、横に倒れた | 造成（太陽光） |
| 1-2 | その場で回って、後ろにいた人に当てた | 造園 |
| 1-3 | 排気管にたまった枯れ草から火が出た | 農業 |
| 1-3 | 荷で後ろが見えず、後進で人をひいた | 災害復旧 |
| 2-1 | 張り付いた土を落とそうと、上げた荷台の下に入った | 砂防・林道 |
| 2-1 | 枝で擦れたホースが破れ、油が手に入った | 林業 |
| 2-2 | 傾いた所でダンプアップして横に倒れた | 造園・造成 |
| 2-2 | 縛らない丸太が動いて、機械ごと傾いた | 林業 |
| 2-3 | 往復でわだちが深くなり、縁から落ちた | 災害復旧 |
| 2-3 | 坂の途中で変速して、荷ごと滑り落ちた | 除雪 |
| 4-1 | 作業計画も誘導者も無いまま、道で人をひきかけた | 林業・土木 |
| 4-1 | 道板が短く、積み込みで転倒した | 造園 |
| 4-1 | 実技をやらないまま修了とした | 農業 |

# 職長教育の教材 — 根拠と裏取り

この教材は**売り物**です。法令の条文番号と数字が間違っていると、
受けた人が間違ったことを覚え、こちらは間違ったことを教えた事業者になります。

## 何を見て書いたか

最初の下書きは、外部の資料を見ずに書きました（書き手の知識と、げんきさんの仕様と、
既存の足場の教材の形だけ）。**そのままでは売れない**ので、
あとから公開されている条文に当てて、一つずつ確かめました。

確かめたのは、公開されている法令の条文です。
法令そのものには著作権がありません（著作権法第13条）。だから条文は引用できます。
一方、厚労省や建災防のテキストの**解説文は書き写していません**。
写すと著作権の問題になり、売り物にできません。文章はすべて書き下ろしです。

### 8 について（唯一、言い切れていないもの）

「足場の組立図は法令の義務ではない」は、**無いことを示す主張**です。
条文が見つからなかった、というだけで、無いと証明したわけではありません。

型枠支保工には、安衛則第240条に「組立図を作成し、かつ、当該組立図により組み立てなければならない」
とはっきり書かれています。足場には、これに当たる条文が見つかりませんでした。

教材では、断定を避けて、こう書いてあります。

> 足場の組立図そのものは、型枠支保工のように「組立図を作れ」と条文で書かれているわけではありません。
> しかし、実際の現場では、元請から仮設計画書と組立図の提出を求められます。

**実務としてはどちらでも同じ結論**（図に従って組む、勝手に変えない）なので、
受講者が困ることはありません。それでも、げんきさんが一度 e-Gov で確かめてくれると安心です。

## 法定の細目（安衛則第40条第2項の表の左欄）

**単元は、この細目に1つずつ対応させています。** 細目の数＝単元の数です。
こうしておくと、12時間ぶんの中身がそろっているかを、
元請にも監督署にも、そのまま示せます。
`src/content/shokucho.ts` の `saimoku` が正本で、
組み立てのとき（`npm run build:shokucho`）に単元と突き合わせます。ずれていれば止まります。

## テキストを写していないこと

職長教育のテキストは、（一財）中小建設業特別教育協会などが**中身を web で公開**しています。
今回は、その**目次と、扱っている項目**を見ました。
何を扱うべきかという骨組みは、上の法定の細目そのものなので、どのテキストも同じです。

**本文は一行も写していません。** テキストの解説文には著作権があります。
写せば、売り物にできません。
この教材の文章は、法定の細目という骨組みに、足場屋の現場の話を載せて書き下ろしたものです。

> なお、この作業環境からは外のページを直接開けません（ネットワークの方針）。
> 見られたのは検索の結果に出る題名と抜粋までです。
> だから「テキストを読んで書いた」のではなく、
> **「法定の細目に合わせて、こちらで書いた」**が正確なところです。

## 裏の取り方

条文そのものに当てます。テキストの解説ではなく、原文です。

1. e-Gov 法令検索で、労働安全衛生法・労働安全衛生法施行令・労働安全衛生規則・年少者労働基準規則を開く
2. 上の表の条文番号を引いて、書いてある中身と教材の文を突き合わせる
3. 合っていれば「済」に変える。違っていれば教材を直し、上の「直したところ」に足す

「済」は、**条文を載せている公開のページで確かめた**という意味です。
e-Gov の原文そのものには当てていません（この作業環境から開けないため）。

数字（高さ・日数・時間・人数）は、一つずつ声に出して確かめてください。
目で追うと、10と5、30日と60日を読み飛ばします。

## 科目を書き足したら

**新しい単元を書いたら、その単元の法令の主張をこの表に足します。**
足さずに進めると、あとから何を確かめればよいか分からなくなります。

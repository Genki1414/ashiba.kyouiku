# 職長教育の教材 — 根拠と裏取り

この教材は**売り物**です。法令の条文番号と数字が間違っていると、
受けた人が間違ったことを覚え、こちらは間違ったことを教えた事業者になります。

## 何を見て書いたか（正直に）

外部の資料は見ていません。使ったのは三つです。

1. げんきさんが決めた仕様（科目・法定時間・討議方式・オンライン討議の条件）
2. 既存の足場（学科）の教材 — 形式と文体の見本として
3. 書き手（Claude）の知識 — 安衛法令と建設現場の実務

**つまり、条文番号も数字も記憶から書いています。**
だから、下の表で一つずつ裏を取ります。

厚労省のテキストや建災防のテキストを**書き写してはいません**。
写すと著作権の問題になり、売り物にできません。文章はすべて書き下ろしです。
裏を取るのは、条文そのもの（法令の原文）に当てるという意味です。

### 7・8・9・10 を先に確かめる理由

- **7** … 届出の要否は数字がそのまま結論になります。10mか、5mか。60日か、30日か。ここを間違えると、届け出るべき現場を届け出ないことになります。
- **8** … 「法令の義務ではない」と言い切っています。もし条文があれば、**逆のことを教えることになります。** いちばん危ない主張です。
- **9・10** … 十八歳未満をどこまで使えるか。実務で毎年出てくる話で、間違えると人を違法に就かせることになります。

> 8 については、最初「つり足場・張出し足場・高さ5m以上の足場は、あらかじめ組立図を作り、
> その図に従って組み立てなければならない」と書いていました。
> これは型枠支保工（安衛則第240条）と混同した可能性が高いので、
> 「法令の義務ではないが、実務では求められる」に直してあります。
> **どちらが正しいかは、まだ確かめていません。**

## 裏の取り方

条文そのものに当てます。テキストの解説ではなく、原文です。

1. e-Gov 法令検索で、労働安全衛生法・労働安全衛生法施行令・労働安全衛生規則・年少者労働基準規則を開く
2. 上の表の条文番号を引いて、書いてある中身と教材の文を突き合わせる
3. 合っていれば「済」に変える。違っていれば教材を直し、直した日を書く

数字（高さ・日数・時間・人数）は、一つずつ声に出して確かめてください。
目で追うと、10と5、30日と60日を読み飛ばします。

## 科目を書き足したら

**新しい単元を書いたら、その単元の法令の主張をこの表に足します。**
足さずに進めると、あとから何を確かめればよいか分からなくなります。

# チェーンソー：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月2日）。教材を作った。**

## 何という教育か

| | |
| --- | --- |
| 正式な呼び方 | チェーンソーを用いて行う立木の伐木、かかり木の処理又は造材の業務に係る特別教育 |
| 対象 | チェーンソーを用いて行う立木の伐木、かかり木の処理、造材の業務 |
| 学科 | **9時間**（4科目12単元）※うちでいちばん長い学科 |
| 実技 | **9時間**（伐木等5／操作2／点検整備2）。事業者が自社で行う |
| 合計 | 18時間 |

**2019年（令和元年）8月1日から、大径木とその他の区分が無くなり、木の太さに関係なくこの一本**
（平31厚労告32で規程第10条が改正。改正年の表記は条文末尾の改正履歴で確認）。
同時に**下肢の切創防止用保護衣の着用が義務**になった。

**実技は事業者が自社で行う。**うちは学科を出し、実技の手引きと実施記録の様式を付ける
（`/edu/chainsaw/drill`）。5つの段取り（60／60／180／120／120）は**うちの案であって告示ではない。**

## 条番号を書いていないところ

安衛則の**伐木作業等の各条**（伐倒の合図、立入禁止、退避場所の選定、受け口・つる、
かかり木の速やかな処理と危険な処理方法の禁止、下肢の切創防止用保護衣、保護帽、
チェーンソーの規格、悪天候時の作業禁止）は、**条番号を条文で確かめていないので書いていない。**科目4は中身で教えている。

**振動障害の予防**（特殊健康診断、作業時間の管理）は通達・指針によるもので、条番号は書いていない。

教材の中の数字で、原文で確かめていないもの：
- 受け口の深さ「伐根直径の1/4以上」、追い口の高さ「受け口の下端から受け口の高さの2/3程度」、
  つるの幅「伐根直径の1/10程度」（安衛則。**現場と講習で広く使われている値**）
- 退避の目安「木の高さの1/2以上」「立入禁止は木の高さの2倍」（講習・ガイドラインの慣行）
- 振動作業「一連続10分以内、一日2時間以内」（チェーンソー取扱い作業指針・通達）
- 特殊健康診断「6か月以内ごとに1回」（通達）
- 上刃目立て角「30度前後」、ヤスリを刃の上に出す量「径の1/5」（メーカー・講習の値）
- 「2019年8月1日」の施行日（改正告示の附則）

いずれも講習で広く教えられている値だが、原文が手に入れば docs/24 と同じ手順で突き合わせる。
**特に受け口・追い口・つるの寸法は安衛則に規定があるはずなので、条文が手に入り次第、条番号と数字を突き合わせる。**

## 例の書き方

docs/19 ⑤。チェーンソーを使うのは、
林業（素材生産・造林）、造園（樹木の伐採・剪定）、電力・通信の支障木処理、道路・河川の管理、
鉄道の沿線、農地の防風林、社寺林、災害復旧の倒木処理、公園と街路樹、太陽光の用地、さく井。
**林業だけではない。木を切る仕事ぜんぶ。**足場屋の例は入れていない。

事例27件：つるを切って逆方向（電力の支障木）／腐れで折れて跳ね返り（造園）／浅い受け口（農業の防風林）／
合図せず隣の人に（林業）／無線が届かず返事を待たず（林業）／真後ろに退避して蹴り上げ（林業）／
蔓に足を取られ逃げ遅れ（道路の維持管理）／かかり木の元玉切り（林業）／かかり木の放置で翌日の人が（林業）／
かかられている木の伐倒（造園）／緊張側から切って挟まれ脚を切創（林業）／支え枝を先に切って転動（造園）／
土の上で切って刃をだめにしキックバック（災害復旧）／保護衣なしで太もも出血死（林業）／
一度当たった保護衣を使い続け（道路の維持管理）／空中始動（造園）／先端を枝の裏に入れて顔（林業）／
緩んだチェーンが外れ腕に（林業）／防振ゴム切れで振動障害（林業）／左右不揃いで挟まれ手首（造園）／
「歳のせい」で十年（林業）／切れない刃で若くして発症（造園）／時間を決めず班の半数に（林業）／
症状を言えず悪化（造園）／季節雇いに教育なし（林業）／強風の日に伐倒（道路の維持管理）／
止血帯が無く死亡（林業）。

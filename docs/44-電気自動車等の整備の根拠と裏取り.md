## 1. 何という教育か

**電気自動車等の整備の業務に係る特別教育**

対象は、安衛則第36条第4号の2に掲げる業務（電気自動車等の整備の業務）。
告示は、対象の車を「**安衛則第三十六条第四号の二の自動車**」と呼んでいる。
この講座でも、その呼び方に合わせた。

**令和元年に追加され、令和6年に一部改正された、新しい教育。**
改正の施行は **2024年10月1日**（目録の `from` もその日）。

## 3. 科目と時間（告示第6条の2第2項・学科）

告示の表そのまま。

| 科目 | 範囲（中欄） | 時間 |
|---|---|---|
| 電気に関する基礎知識 | 電気の危険性　短絡　漏電　接地　電気絶縁 | 一時間 |
| 電気装置に関する基礎知識 | 安衛則第三十六条第四号の二の自動車の仕組みと種類　コンバータ及びインバータ　配線　駆動用蓄電池及び充電器　駆動用原動機及び発電機　電気使用機器　保守及び点検 | 二・五時間 |
| 安全作業用具に関する基礎知識 | 絶縁用保護具、絶縁用防具、絶縁工具及び絶縁テープ　検電器　その他の安全作業用具　管理 | 〇・五時間 |
| 自動車の整備作業の方法 | 充電電路の防護　作業者の絶縁保護　停電の方法　停電電路に対する措置　作業管理　救急処置　災害防止 | 一時間 |
| 関係法令 | 法、令及び安衛則中の関係条項 | 一時間 |

**合計 6時間（360分）。**

**科目3の中欄の1つ目は「絶縁用保護具、絶縁用防具、絶縁工具及び絶縁テープ」で、これで1項目。**
読点でつながっているので分けていない。だから科目3は4項目＝4単元。

## 4. 実技（告示第6条の2第3項）

> 第一項の実技教育は、安衛則第三十六条第四号の二の自動車の整備作業の方法について、
> **一時間以上**行うものとする。

**1時間。事業者が自社で行う。**短いが、やらなければ修了にならない。
うちが出すのは学科だけ。実技の手引き（うちの案）と実施記録の様式を
`/edu/ev/drill` から印刷できるようにしてある。

実技が1時間しかないので、手引きは**3つの段取り**に絞り、
**「切る・確かめる・待つ」の一本の流れだけを、実車で体に入れる**作りにした。

## 5. 低圧（第6条）・高圧（第5条）との違い

この講座だけの特徴が三つある。ここを軸にした。

| | 内容 |
|---|---|
| **直流** | 交流と違って向きが変わらないので、**掴んだ手が離れなくなる（離脱不能）。**「感電したら手を引けばいい」が通らない |
| **車の側に電源がある** | 工場の設備なら大元の開閉器を切れば終わり。**車は違う。**電源が車に積んである |
| **切っても電気を持ったまま** | 駆動用蓄電池は、**切っても、取り外しても、電気を持っている。**外せない電源 |

そのほか、この講座ならではの中身：

- **サービスプラグ**（電池の中の回路を途中で断つ部品）。抜いたら**持って離れる**
- **待つ**（インバータ・コンバータのコンデンサの残留電荷。要領書の時間、多くは5〜10分）
- **フローティング**（高電圧の回路は車体から絶縁されている。一か所目の壊れに気付けない）
- **モーターは外から回されると発電する**（牽引、タイヤを回す）
- **熱暴走**（消えてもまた燃える。有毒ガス。消防を呼ぶ）
- **車種ごとに場所も手順も待つ時間も違う**（触る前に整備要領書を開く）

## 6. 単元の割り付け

**中欄の項目の数だけ単元を作った。**低圧・高圧と同じ作り。

- 科目1（60分・**5単元**）… 危険性16／短絡11／漏電11／接地11／電気絶縁11
- 科目2（150分・**7単元**）… 仕組みと種類30／コンバータ及びインバータ25／配線20／駆動用蓄電池及び充電器30／駆動用原動機及び発電機20／電気使用機器12／保守及び点検13
- 科目3（30分・**4単元**）… 保護具等12／検電器8／その他5／管理5
- 科目4（60分・**7単元**）… 防護10／絶縁保護10／停電の方法10／停電電路に対する措置10／作業管理8／救急処置7／災害防止5
- 科目5（60分・**1単元**）

合計 **24単元・360分**。

### 実技の手引き（うちの案・60分）
1. その車を知る（整備要領書と、高電圧の通り道）（15分）
2. 切る・確かめる・待つ（サービスプラグと検電）（30分）
3. 作業と、戻し方と、もしものとき（15分）

## 7. 条番号を書いていないところ

docs/19 の決めごとどおり、**条文で確かめた番号だけ書く。**
書いたのは **法第59条第3項／安衛則第36条第4号の2／規程第6条の2** の三つだけ。

**番号を書かずに中身だけ教えているもの**（科目5）：

- 電気機械器具の**囲い等**（充電部分に人が触れないように囲うか、絶縁で覆う）
- **停電作業を行う場合の措置**（施錠・通電禁止の表示・監視人／**残留電荷を確実に放電させる**）
- **絶縁用保護具等の定期自主検査**（6か月以内ごとに1回、記録は3年間保存）
- **作業を指揮する者**を定めること
- **電気機械器具等の使用前点検**
- **就業制限と特別教育**、**特別教育の記録の3年保存**
- **道路運送車両法**の自動車整備士・整備主任者（分解整備／特定整備）の条
- **電気工事士法**の条

**数値で、条文以外の出どころによっているもの**：

- **高電圧の電圧の目安**（ハイブリッド200〜300ボルト、電気自動車300〜800ボルト）
  … メーカーの資料と実務で通っている値。条文の数値ではない
- **待ち時間の目安**（多くは5〜10分）
  … 車種ごとに整備要領書で決まる。この講座では「**要領書の時間を待つ**」と教えている
- **オレンジ色が高電圧の印**であること
  … 業界の取り決めによるもの。条文の定めとしては確かめていない

**条番号と根拠が確かめられたら、ここに足して、単元の中でも出す。**

## 8. 値段

**7,000円（税抜）＝ 7,700円（税込）。**
コードの既定値（`src/lib/pricing.ts`）に置いただけで、Vercel の環境変数は触っていない。

- **よその値段はまだ調べていない。**
- 学科6時間はフォークリフト・ショベルローダー等（6,000円）と同じ長さ。
- ただし、**2024年10月1日から対象が広がった新しい教育**で、受ける人が急に増えている。
- 中身も電気の教育に近いので、**低圧電気（7時間・7,000円）と同じ 7,000円**に置いた。
- よその相場が分かったら、ここを見直す。

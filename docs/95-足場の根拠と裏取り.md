# 95　足場：根拠と裏取り

docs/19 の手順①の記録。**告示の条文で確認済み（2026年9月7日）。**
げんきさんが安全衛生特別教育規程の全文を写して渡してくれた。

**この講座は、うちがいちばん多く売る講座でありながら、
きのうまで66行のうち唯一「裏取りの記録が無い行」だった**（docs/94 §3）。
学科6時間の出どころが東京労働局のまとめで、科目と時間を決めている
規程の何条かも分かっていなかった。それが解消した。

## 4　条文と突き合わせて直したこと

告示が手元に来て初めて、うちの講座の**中欄**を条文と比べられた。2か所ずれていた。

**科目3の4つ目**
    直す前  感電防止のための措置**、**その他作業に伴う災害及びその防止方法
    直した後 感電防止のための措置**　**その他作業に伴う災害及びその防止方法
告示では別々の範囲で、全角スペースで区切られている。読点でつないでいた。

**科目4の2つ目**
    直す前  事業者及び労働者の義務、記録の保存
    直した後 法、令及び安衛則中の関係条項
**この言葉は告示の中欄に無い。**うちが足したもの。
関係法令の中欄は「法、令及び安衛則中の関係条項」だけ。

どちらも**中欄（法令から引いた範囲の文字）を直しただけで、教える中身は変えていない。**
事業者と労働者の義務も、記録の保存も、そのまま教えている。
「法、令及び安衛則中の関係条項」の中に入る話だから。

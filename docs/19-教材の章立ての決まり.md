# 教材の章立ての決まり

**講座を足すときは、必ずこの順でやること。** 職長教育も、これから足す特別教育も同じ。

## 決まり

> **章立ては、法令の細目と、公開されている講習の章立てから作る。**
> **完全な自作はしない。ただし、文章はそのまま写さない。**

## なぜ

章立てを頭だけで決めると、必ずずれる。実際にずれた。

職長教育で、最初はこちらで勝手に14単元に割った。
そのあと法令の細目（安衛則第40条第2項の表）に当てたら、
**「設備、作業等の具体的な改善の方法」が単元として無かった。**
4時間の科目の三本柱の一本が抜けていた。

さらに、公開されている講習の章立てに当てたら、
**安全衛生責任者教育の2時間がまるごと抜けていた。**
講座の名前は「職長・安全衛生責任者教育」なのに、中身は職長の12時間だけ。
そのまま出していたら、受けていない教育の名前が修了証に載っていた。

自作は、抜けに気づけない。だから決まりにする。

## 手順

### ① 法令の細目を取る

その教育の科目と細目が書いてある条文を引く。

| 教育 | どこに書いてあるか |
|---|---|
| 特別教育 | 安全衛生特別教育規程（科目・範囲・時間） |
| 職長教育 | 労働安全衛生規則第40条第2項の表 |
| 能力向上教育 | 厚生労働省の指針・通達 |

細目の**言い回しはそのまま使う**。言い換えると、突き合わせられなくなる。
条文に著作権は無い（著作権法第13条）ので、ここは写してよい。

### ② 公開されている講習の章立てを見る

同じ教育を実際にやっているところが、章立てを公開している。

- （一財）中小建設業特別教育協会 … テキストの中身を web で公開
- 各都道府県労働局・労働基準協会 … 講習の科目と時間
- 建災防・中災防 … 講習案内の科目

見るのは**目次と、扱っている項目まで**。
「法令の細目のどれを、どういう順で、どこまで細かく扱っているか」を取る。

### ③ ①と②を突き合わせて、単元を割る

- 単元は、法定の細目に**1つずつ対応**させる
- ②で細目より細かく割られていれば、そこは単元を分けるか、単元の中の節にする
- ②にあって①に無いものが出たら、**それは別の教育かもしれない**。要確認
  （職長教育の「統括安全衛生管理」がこれだった。安全衛生責任者教育のぶん）

### ④ どこまで合わせて、どこから書くか

ここがいちばん間違えやすいので、線を引いておく。

| 種類 | 扱い | なぜ |
|---|---|---|
| 法令の条文・細目の言い回し | **そのまま使う** | 法令に著作権は無い（著作権法第13条）。言い換えると突き合わせられない |
| 章・節の見出し、扱う項目 | **そのまま合わせる** | 短い題名と、何を扱うかという事実。ここを変えると実際の講習とずれる |
| 数字・基準・手順の段数 | **そのまま使う** | 事実。10分間平均風速10m/s、教え方の4段階、KYの4ラウンド |
| 定着した枠組みの名前と中身 | **そのまま使う** | 4ラウンドKY、5つのチェック項目（安全・品質・能率・原価・環境）、リスクの見積り方など。業界で共通の道具で、特定の本のものではない |
| テキストの解説文・言い回し・例え話 | **写さない。文末だけ変えるのも駄目** | 著作権は表現に及ぶ。語尾を変えても複製。ここが売り物のいちばんの弱点になる |

**「完全な自作」もしない。** 自作すると実際の講習とずれる。
上の4つを全部そのまま使えば、扱う中身は実際の講習と同じになる。
そのうえで、**説明の文章だけを書き下ろす。**

つまり、**骨と数字と道具の名前は合わせ、肉づけは自分の言葉で**。

### ⑤ 例は、業種を偏らせない

職長教育は建設業ぜんぶが受ける。足場だけの例で埋めると、
鉄筋も型枠も設備も塗装も、自分の話として聞けなくなる。

- 例は**複数の業種から**出す（土工・鉄筋・型枠・設備・塗装・解体・足場）
- 足場は「そのうちの一つ」。得意なぶん濃く書けるが、そこに寄せない
- 特別教育のように**対象の業務が決まっている講座は別**。そこはその業務で書く

> ### 「対象の業務が決まっている」＝「ある業種向け」ではない
>
> ここを読み違えた。石綿の教材で、
> 「石綿を扱う＝解体や改修＝足場を架ける現場」と考えて、
> **足場屋に寄せて書いてしまった。**
>
> - 「ここは足場屋にいちばん近い落とし穴です」
> - 「石綿の現場では、足場の掛け方そのものが変わる」
> - 事例の主人公が、5単元のうち3単元で足場屋
>
> **石綿を扱うのは足場屋だけではない。**
> 解体、内装、設備、電気、塗装、防水、屋根、外装、ビル管理・保全、
> 製造業の設備保全。どの職種も受ける。
>
> 足場屋の話ばかり出てくれば、ほかの職種の人は自分の話として聞けない。
> **職長教育で避けたはずのことを、特別教育でやっていた。**
>
> 「対象の業務」とは、その教育が必要になる**作業**のことであって、
> 特定の業種のことではない。
> 石綿なら「石綿等を取り扱う作業」であって「足場を架ける作業」ではない。
>
> 判断の目安：**その講座を受ける人に、どの業種が含まれるかを先に数える。**
> 2つ以上あるなら、例はその全部から出す。

### ⑥ 出どころを残す

`src/content/syllabus.ts` に1件足す。
どの条文から細目を取ったか、どこの章立てを参考にしたかを書く。
法令の主張は `docs/18` の形で一覧にして、裏を取る。

## 機械で止まること

- 細目と単元がずれていたら、組み立ての手前で止まる（`npm run build:shokucho`）
- 時間の合計が法定と違えば止まる
- `syllabus.ts` に出どころが無い講座は、テスト（`npm run test:contenttext`）が落ちる

## やってはいけないこと

| だめ | なぜ |
|---|---|
| 章立てを頭だけで決める | 細目が抜ける。抜けたことに気づけない |
| テキストの本文を写す | 著作権。売り物にできない |
| **文末だけ変えて写す** | それも複製。著作権は表現に及ぶ。いちばんやってはいけない |
| 全部を自作する | 実際の講習とずれる。骨と数字と道具の名前は合わせる |
| 例を一つの業種に寄せる | ほかの業種の人が、自分の話として聞けなくなる |
| 細目の言い回しを変える | 突き合わせられなくなる。監督署にも示せない |
| 出どころを残さない | 後から確かめられない。人が変わったら終わり |
| 「だいたい合っている」で進める | 教育は時間と中身が法律で決まっている。だいたいは無い |

```
件名：特別教育の月額プラン（法人会員）のご案内

毎月の会費（税抜）の2倍の額が、チケットとして毎月付きます。

■ プラン（税抜・月額 → 毎月のチケット）
```

## B. 営業パートナー募集（資材屋・元請の担当者・個人あて）

### 短い版（LINE・オプチャ）

```
【法人会員を紹介すると、会費の30%が毎月】
足場屋革命ー教育の「営業パートナー」を募集します。

・あなたの紹介 URL（またはコード）から申し込んだ会社の月額会費（税抜）の30%
・その会社が払い続けるかぎり、毎月。入金のあった月ごとに確定
・例：スタンダード（月1万円）を10社 → 月3万円・年36万円
・個人でも法人でも。登録は無料、月末締め・翌月末払い

くわしく → https://kyouiku.ashibase.jp/partners
登録はアプリのマイページ「営業パートナー」から。承認後に紹介 URL と QR が出ます。
```

### 長い版（メール・DM）

```
件名：営業パートナーのご案内（特別教育の法人会員の紹介）

○○様

東北三上機材の中川です。
特別教育をスマホで受けられる「足場屋革命ー教育」の法人会員制度を、紹介してくださる方を探しています。

■ 報酬
紹介した会社が支払う月額会費（税抜）の30%。
その会社の入金が確認された月ごとに確定し、会員でいるかぎり毎月続きます。
例：スタンダード（月1万円）を10社紹介 → 月3万円・年36万円。

■ 条件
・月末締め・翌月末払い。5,000円未満の月は翌月に繰越。振込手数料は当社負担
・消費税込みの額。源泉徴収はしません（ご自身で申告）
・紹介元は契約成立時に固定。紹介の紹介（多段）はありません
・ご自身の会社は紹介できません
・パートナーをやめた月までの確定分はお支払いします。以後は発生しません

■ 流れ
1. アプリのマイページ「営業パートナー」から登録（お名前・連絡先）
2. 業務委託契約書を取り交わし、当社が承認
3. 紹介 URL・コード・QR が画面に出ます。渡した先が申し込むと、あなたの紹介になります
4. 画面で「確定」「見込み」「支払済」をいつでも確認できます

案内：https://kyouiku.ashibase.jp/partners
契約書（PDF）：https://kyouiku.ashibase.jp/legal/partner-agreement.pdf

東北三上機材株式会社　中川元基　TEL 022-738-7913
```

## 貼るときの注意

- 「報酬を分けるから入って」と言って勧誘しない（連鎖販売に見える。契約書第6条）。
- 税抜で書く。税込を書くときは「税込 11,000円」と明記。
- 条件を変えたら、ここと /members・/partners・契約書を同じ日に直す（字は `src/lib/membership.ts` の TERMS）。

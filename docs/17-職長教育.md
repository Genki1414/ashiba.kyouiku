# 職長教育（職長・安全衛生責任者教育）

足場の特別教育とは**別の制度**です。取り違えると、無効な紙を売ることになります。

| | 特別教育 | 職長教育 |
|---|---|---|
| 根拠 | 労働安全衛生法 **第59条第3項** | 労働安全衛生法 **第60条** |
| 誰に | 危険有害な業務に就く人 | 新たに職長になる人（作業中の労働者を直接指導・監督する者） |
| 中身 | 講義（一方向でよい） | 講義＋**討議（グループ演習）** |

---

## 1. 決めたこと

### 討議は、オンラインの同時双方向でやる

職長教育には、講義を聞くだけでは足りない科目があります。
この仕組みでは **オンラインの同時双方向**（顔と声が通じる状態）で行います。
録画を見せるのは討議になりません。

そのため、**討議だけは日時を決めて集まる**形になります。
学科（一方向でよい部分）は、いままでどおり各自がいつでも進められます。

### 建設業なので、安全衛生責任者教育と一体でやる

建設業では、職長教育と安全衛生責任者教育を続けて行い、
「**職長・安全衛生責任者教育**」として1つの修了証を出すのが普通です。
講座もその形にしてあります（`src/content/courses.ts` の `shokucho`）。

---

## 2. できていること

- 講座に**種類**を持たせた（`CourseKind`：`special` / `foreman`）
- ホームの札が種類で変わる（「特別教育（学科）」／「職長教育」）
- **修了証の表題・結びの文・根拠条文が、講座から出るようになった**

  前は「労働安全衛生法第59条第3項…に基づく特別教育を修了したことを証する」と
  決め打ちしていました。そのまま職長教育を足すと、**条文が嘘の紙**が出ます。
  号の違う特別教育を足したときも同じでした。
- 講座を `ready: false` で置いてあるので、ホームに名前だけ出ます

---

## 3. まだ決まっていないこと（これが無いと進めない）

### ① 科目と時間

**令和5年4月の改正後**のもので入れます。古い表を使うと足りません。

| 要るもの | 入れる先 |
|---|---|
| 科目ごとの名前と時間 | `content/courses/shokucho.json` の `subjects[].legal_min` |
| 合計時間 | `src/content/courses.ts` の `totalMin` |
| 根拠条文 | 同 `basis`（いまは「安衛法第60条／安衛則第40条」で仮置き） |

### ② どの科目が討議か

科目ごとに「一方向でよい」「討議が要る」を分けます。
討議の科目は、日時を決めて集まる回になります。

### ③ 討議をどう残すか

やった証明が要ります。少なくともこれは残す必要があります。

- 誰が、いつ、何分出たか
- 誰と一緒だったか（同じ回に出た人）
- 進行した人（講師）は誰か

学科の視聴記録と同じ考え方ですが、**同時双方向なので作りは別**になります。
どの道具でつなぐか（アプリの中／外の会議ツール）も、ここで決めます。

### ④ 講師

職長教育には、教える側の要件があります。誰が担当するかを決めます。

---

## 4. カリキュラムが来たらやること

`docs/13-講座を増やす.md` と同じ手順です。

1. `content/courses/shokucho.json` を書く
2. `src/content/courses.ts` の `shokucho` を `ready: true`、`totalMin` を入れる
3. `npm run build:sql` → SQL Editor で `supabase/apply-all.sql` を実行

討議の仕組みは、これとは別に作ります（③が決まってから）。

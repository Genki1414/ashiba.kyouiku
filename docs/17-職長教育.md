# 職長教育（職長・安全衛生責任者教育）

足場の特別教育とは**別の制度**です。取り違えると、無効な紙を売ることになります。

| | 特別教育 | 職長教育 |
|---|---|---|
| 根拠 | 労働安全衛生法 **第59条第3項** | 労働安全衛生法 **第60条** |
| 誰に | 危険有害な業務に就く人 | 新たに職長になる人（作業中の労働者を直接指導・監督する者） |
| 中身 | 講義（一方向でよい） | 講義＋**討議（グループ演習）** |

---

## 1. 決めたこと

### 討議は、オンラインの同時双方向でやる

職長教育には、講義を聞くだけでは足りない科目があります。
この仕組みでは **オンラインの同時双方向**（顔と声が通じる状態）で行います。
録画を見せるのは討議になりません。

そのため、**討議だけは日時を決めて集まる**形になります。
学科（一方向でよい部分）は、いままでどおり各自がいつでも進められます。

### 討議は、講座に1回だけ。45分

科目ごとに討議を置くと、**科目の数だけ日を合わせて集まる**ことになります。
受ける人にも講師にも重すぎるので、**45分の回を1度だけ**にしました。

その45分は12時間の**中に入り**、科目3（危険性又は有害性等の調査）の
時間として数えます（`src/content/shokucho.ts` の `TALK_MIN` / `TALK_SUBJECT`）。
12時間＋45分ではありません。

### つなぎ先は Zoom。URL は「入る」を押したときだけ渡す

回ごとに Zoom の URL を登録します（`live_sessions.room_url`）。

**一覧には URL を出しません。** 出すと、申し込んでいない人にも渡ってしまいます。
「入る」を押したときにサーバが渡し、渡した時点で入室が記録されます。
渡すのは**始まる15分前から、終わって30分後まで**です。

### 顔の照合は、学科の受講中とまったく同じ

- 受講の準備（同意・顔の登録）が済んでいない人は、討議に入れません
- 討議中も3秒ごとに照合し、2回続けて外れたら止めます
- 顔の特徴量は**端末の中だけ**にあり、サーバへは送りません
- 外れた記録・通った控えは、学科と同じ `verify_logs` に残ります

### 建設業なので、安全衛生責任者教育と一体でやる

建設業では、職長教育と安全衛生責任者教育を続けて行い、
「**職長・安全衛生責任者教育**」として1つの修了証を出すのが普通です。
講座もその形にしてあります（`src/content/courses.ts` の `shokucho`）。

## 2. カリキュラム（法定）

| 科目 | 名前 | 法定 |
|---|---|---|
| 1 | 作業方法の決定及び労働者の配置に関すること | 2時間 |
| 2 | 労働者に対する指導又は監督の方法に関すること | 2時間30分 |
| 3 | 危険性又は有害性等の調査及びその結果に基づき講ずる措置に関すること | **4時間** |
| 4 | 異常時等における措置に関すること | 1時間30分 |
| 5 | その他現場監督者として行うべき労働災害防止活動に関すること | 2時間 |
| | **合計** | **12時間** |

中身と討議のお題は `src/content/shokucho.ts`。

### 章立て（公開されている講習の章立て＋法定の細目）

章立ては、こちらで自作していません。**法定の細目**（安衛則第40条第2項の表）と、
**公開されている講習の章立て**（（一財）中小建設業特別教育協会の web テキスト、全11章）
の両方に当てて作っています。決まりは `docs/19-教材の章立ての決まり.md`。

| 単元 | 内容 | 細目 | 時間 |
|---|---|---|---|
| 1-1 | 職長の職務と、作業手順の定め方 | 作業手順の定め方 | 60分 ✓ |
| 1-2 | 部下（作業者）の適正配置 | 労働者の適正な配置の方法 | 60分 ✓ |
| 2-1 | 部下に対する指導・育成 | 指導及び教育の方法 | 75分 |
| 2-2 | 作業中の監督と指示 | 作業中における監督及び指示の方法 | 75分 |
| 3-1 | 危険性又は有害性等の調査の方法 | 同左 | 65分 |
| 3-2 | 調査の結果に基づき講ずる措置 | 同左 | 65分 |
| 3-3 | 設備、作業等の具体的な改善の方法 | 同左 | 65分 |
| 4-1 | 異常時における措置 | 同左 | 45分 |
| 4-2 | 災害発生時の措置・災害調査と分析 | 災害発生時における措置 | 45分 |
| 5-1 | 保守管理と安全衛生点検 | 作業に係る設備及び作業場所の保守管理の方法 | 60分 |
| 5-2 | 災害防止への関心の保持と創意工夫 | 労働災害防止についての関心の保持及び労働者の創意工夫を引き出す方法 | 60分 |
| **6-1** | **安全衛生責任者の職務と作業間の連絡調整** | 安全衛生責任者教育 | **60分** |
| **6-2** | **安全施工サイクルによる安全衛生活動** | 安全衛生責任者教育 | **60分** |

職長教育のぶんが675分、これに討議45分を足して**12時間**。
さらに安全衛生責任者教育の120分を足して、**合計14時間**です。

### 12時間ではなく14時間

建設業では、職長教育（12時間）と安全衛生責任者教育（2時間）を続けて行い、
**14時間**で「職長・安全衛生責任者教育」として1枚の修了証を出します。

最初は12時間だけで組んでいました。
公開されている講習の章立てに当てて、**第11章「統括安全衛生管理の進め方」が
まるごと抜けている**ことに気づきました。ここが安全衛生責任者教育の2時間です。

そのまま出していたら、**受けていない教育の名前が修了証に載る**ところでした。

単元は `content/shokucho/<単元>.json` に1つずつ書き、
`npm run build:shokucho` で1本にまとめます。
細目とずれていれば、まとめる手前で止まります。
根拠と裏取りは `docs/18-職長教育の根拠と裏取り.md`。

### 時間の持ち方

「動画12時間＋別途討議」にはしません。
**各科目の中に**「講義」「討議」「演習」を持ち、本部の画面から割り振りを変えます。

いまの割り振り（`src/content/shokucho.ts`）：

| 科目 | 法定 | 講義 | 討議 | 演習 |
|---|---|---|---|---|
| 1 | 2時間 | 1時間30分 | ― | 30分 |
| 2 | 2時間30分 | 1時間50分 | ― | 40分 |
| 3 | 4時間 | 2時間 | **45分** | 1時間15分 |
| 4 | 1時間30分 | 1時間 | ― | 30分 |
| 5 | 2時間 | 1時間20分 | ― | 40分 |
| | **12時間** | | **45分** | |

討議は科目3の中の45分だけです。残りの科目は、お題を**演習**として出します
（お題そのものは全科目にあります）。

```
講義 → 課題 → 個人回答 → その場の討議 → 講師の解説
```

**3つの合計が、その科目の法定最低時間を下回ったら公開しません**
（`src/lib/hours.ts` の `judgeHours`）。合計が12時間を下回っても同じです。

## 3. できていること

- 講座に**種類**を持たせた（`CourseKind`：`special` / `foreman`）
- ホームの札が種類で変わる（「特別教育（学科）」／「職長教育」）
- **修了証の表題・結びの文・根拠条文が、講座から出るようになった**

  前は「労働安全衛生法第59条第3項…に基づく特別教育を修了したことを証する」と
  決め打ちしていました。そのまま職長教育を足すと、**条文が嘘の紙**が出ます。
  号の違う特別教育を足したときも同じでした。
- 講座を `ready: false` で置いてあるので、ホームに名前だけ出ます
- **討議の回**（0022）：1回15人まで。入退室・離席・課題への回答・講師の確認を残す
- **討議の画面**（`/edu/shokucho/talk`）：回の一覧・申し込み・お題への答え・入退室
- **Zoom の受け渡し**：一覧に URL を出さず、「入る」を押したときだけ渡す
- **討議中の顔の照合**：学科の受講中と同じ作り

### 討議を終えたと見てよい条件

3つそろって、はじめて修了です（`src/lib/hours.ts` の `judgeTalk`）。

1. **実際に居た時間が45分以上**（入り直しは足し、離席は引く）
2. **お題に答えを出している**（居ただけでは通さない）
3. **講師が「討議に参加していた」と確認している**（最後は人が見る）

## 4. まだ出来ていないこと

### ① 講義の中身（いちばん大きい）

台本・図解・災害事例・確認問題。足場の特別教育は台本1,683行・図解74枚でした。
職長教育は12時間なので、それ以上になります。**ここが一番時間を食います。**

### ② 講師と本部の画面

受講者の側は出来ています。残っているのは：

- 回を立てる（日時・Zoom の URL・定員・講師）
- 出欠を見て、離席の分を引き、講評を書く（講師）
- 科目ごとの時間の割り振り（本部）
- 名簿に討議の参加状況を出す（教育担当者）

`/api/live` の PUT が、その入口の置き場所です（いまは 501 を返します）。

### ③ 講師の要件（誰が担当するか）

職長教育は教える側にも要件があります。誰が担当するかを決めます。

## 5. 討議の回を立てる（いまのやり方）

回を立てる画面はまだないので、Supabase の SQL Editor で1行入れます。

```sql
insert into public.live_sessions
  (course_id, subject_id, company_id, starts_at, minutes, capacity, teacher, room_url, note)
values
  ('shokucho', 3, null,                    -- company_id が null なら誰でも申し込める回
   '2026-09-10 09:00+09', 45, 15,
   null,                                   -- 講師（public.users.id）
   'https://us06web.zoom.us/j/…',          -- Zoom の URL
   '第3回');
```

- `subject_id` は 3（討議を数える科目）
- `minutes` は 45
- `capacity` は 15 まで（それ以上はデータベースが拒みます）
- ある会社だけの回にするなら `company_id` に会社の番号を入れます

## 6. カリキュラムが来たらやること

`docs/13-講座を増やす.md` と同じ手順です。

1. `content/courses/shokucho.json` を書く
2. `src/content/courses.ts` の `shokucho` を `ready: true`、`totalMin` を入れる
3. `npm run build:sql` → SQL Editor で `supabase/apply-all.sql` を実行

討議の仕組みは出来ています。回を立てるところだけ、
いまは5章の SQL でやります。

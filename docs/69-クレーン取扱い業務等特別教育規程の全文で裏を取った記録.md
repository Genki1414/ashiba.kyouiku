## 1. これが何か

**うちが告示の全文で裏を取った、初めての規程。**

これまでの裏取りは「げんきさんの講座マスターと、労働局のまとめの数字が一致した」
という二段構えだった（docs/68）。**今回は条文そのもの。**一段強い。

目録に `fullText` という印を足した。**この印が付いた行は、条文が手元にある。**

告示の頭にある委任文も取れた。

> クレーン等安全規則（昭和四十七年労働省令第三十四号）**第二十一条第三項、第六十七条第三項、
> 第百七条第三項、第百八十三条第三項及び第二百二十二条第三項**の規定に基づき、
> クレーン取扱い業務等特別教育規程を次のように定め、昭和四十七年十月一日から適用する。

だから根拠に**法令番号（昭和47年労働省令第34号）と「第1項」**まで入れられた。
各条の本文が「クレーン則**第二十一条第一項**の規定による特別の教育は」と書いているので、
**教育そのものの根拠は第1項、告示への委任は第3項。**

## 2. いちばん大事な発見 — 移動式クレーンの科目2

**据置きのクレーン（第1条）と移動式クレーン（第2条）は、
「原動機及び電気に関する知識　3時間」という同じ科目名なのに、中欄がまったく違う。**

| | 中欄 |
|---|---|
| クレーン（第1条） | 電気に関する基礎知識　電動機　**開閉器、コントローラー等電気を通ずる機械器具**　**電路の点検及び補修**　感電による危険性 |
| **移動式クレーン（第2条）** | **内燃機関　蒸気機関　油圧駆動装置**　感電による危険性 |

**走って動く機械だから、電気ではなく原動機の話になっている。**

**この条文をもらう前に移動式クレーンを作っていたら、
クレーンの科目2をそのまま流用して、法定の範囲を外した講座になっていた。**
危ないところだった。デリック（第3条）のほうは、クレーンと同じ中欄。

## 3. 講座の字を、告示に合わせた

告示は古い書き方をしている。**docs/19 の決まり（条文・細目・見出しはそのまま合わせる）**
に従って、講座の科目名と中欄を直した。**本文（ナレーション）の言葉は直していない。**
受ける人に読みやすいほうがいいので、本文は「フック」「デリック」のまま。

| 直した所 | 前 | 後（告示のまま） |
|---|---|---|
| クレーン 科目3の中欄／単元3-4の題 | ワイヤロープ、**フック**及びつり具の強さ | ワイヤロープ、**フツク**及びつり具の強さ |
| 玉掛け 科目1の名前 | クレーン、移動式クレーン及び**デリック**に関する知識 | クレーン、移動式クレーン及び**デリツク**に関する知識 |
| 玉掛け 科目3の中欄 | 基本動作(安全作業方法を含む) | 基本動作(安全作業方法を含む**。**) |
| 玉掛け 実技の中欄 | 手、小旗等を用いて**行う**合図の方法 | 手、小旗等を用いて**行なう**合図の方法 |
| 両方 科目4の中欄 | …及び**クレーン等安全規則**中の関係条項 | …及び**クレーン則**中の関係条項 |

最後の「クレーン則」は、告示の第1条第1項で
「クレーン等安全規則（以下「クレーン則」という。）」と決めている略称。
**告示の中欄はその略称で書いてあるので、そのまま合わせた。**
（4-1の本文では「クレーン等安全規則」と言っているので、意味は通る）

## 4. 見張りを足した

`tests/tokubetsu.ts` に、**告示の全文を見た行と、作ってある講座を一字ずつ突き合わせる**
テストを入れた。

- 告示を見た行には、**科目と中欄と読んだ日**が入っている
- **講座の科目の数が、告示と同じ**
- **科目名が告示のまま**
- **科目ごとの時間が告示のまま**
- **単元に割り付けた中欄を並べ直すと、告示の中欄と一字も違わない**

**これがずれたら、法定の範囲を外した講座を売っていることになる。**
いまは crane と tamakake の8科目が対象。移動式クレーンを作ったら、そこにも当たる。

## 6. e-Gov では告示が引けない（分かったこと）

げんきさんが e-Gov 法令検索で

- 核燃料物質等取扱（法令名）
- 事故由来廃棄物等処分業務（キーワード）
- 除染等業務特別教育（キーワード）

を引いて、**3つとも0件**だった。

**e-Gov 法令検索は、法律・政令・省令（規則）を載せている。告示は載っていない。**
だから「○○特別教育規程」は、e-Gov では出てこない。

**告示は、厚生労働省の法令等データベースサービスのほうにある。**
うちの目録が出典に持っている `https://www.mhlw.go.jp/web/t_doc?dataId=…` の形が、それ。

| 引きたいもの | どこで |
|---|---|
| 電離放射線障害防止規則（**省令**） | e-Gov 法令検索でよい |
| 高気圧作業安全衛生規則（**省令**） | e-Gov 法令検索でよい |
| クレーン等安全規則（**省令**） | e-Gov 法令検索でよい |
| **○○特別教育規程（告示）** | **厚労省 法令等データベース**（https://www.mhlw.go.jp/hourei/） |

まだ欲しい告示は3つ。

- **核燃料物質等取扱業務特別教育規程**（平成12年労働省告示第1号）… no.48
- **事故由来廃棄物等処分業務特別教育規程**（平成25年厚生労働省告示第140号）… no.50
- **除染等業務特別教育及び特定線量下業務特別教育規程**（平成23年厚生労働省告示第469号）… no.61・62

**とくに最後のは、業務区分ごとの時間が要る。**
「除染等業務＝全員一律」にしないための表が、そこにある。
